# FPGA 后续测量与优化

## 固定目标

完整 `soc_top` 面向 `xc7a200tfbg484-3`，使用 `config/npu_fpga.mk` 的生产配置。目标为物理LUT位置不超过50,000、寄存器间最长组合路径不超过15级和150 MHz。保持16×16阵列、8个向量PE、全部数值精度与运算、64位总线、7个8 KiB共享银行、原始INT32部分和、16个帧以及完整PicoRV32和256 KiB CPU RAM。

生产量化使用两个计算通道及512行整组缓存，持续输出间隔为8个周期。NPU缓存数组折合124,313.5字节，满足128 KiB的数组容量预算。

## 已完成的完整SoC测量

固定源码 `7ef39f01` 已完成合法布局，共49,828个物理LUT位置，其中逻辑47,360、RAM LUT 2,444、SRL 24。面积余量172。该映射网表最长组合路径为18级，同一RTL的86个完整NPU任务和216,348项INT32检查通过。详情见 [第23轮测量](fpga_round23_measurement.md)。

全部106,313个实现单元具有唯一BEL。55,204个普通逻辑LUT的INIT、230,937个输入及55,204个输出逐项检查通过。86个任务的数值和周期字段均与参考版本一致，83项容量检查及通用/FPGA结构检查通过。

## 组合路径处理顺序

第23轮使用完整寄存器连接图，200组导出路径中有6组超过15级。各项优化保留生产配置、公开输出、无效周期字段和同周期事件优先级，并控制组合逻辑的面积增量。

| 第23轮起止位置 | 级数 | 处理方向 |
|---|---:|---|
| 前端通道索引 → 核索引 | 18 | 平衡完整组范围判断，使晚到结果直接进入快速接收末级 |
| 窗口占用状态 → 前端状态 | 17 | 检查归约坐标范围与控制选择的实际连接 |
| DMA读上下文计数 → 向量错误状态 | 17 | 并行准备与中止条件相关的授予和空闲资格 |
| 缓存配置空闲 → 前端通道状态 | 16 | 缩短配置接受与通道选择条件，保留原优先级 |
| DMA读上下文计数 → 向量输入预留 | 16 | 检查完整读取就绪、故障、开始及预留条件 |
| 窗口缓存响应错误 → 向量累加结果 | 16 | 检查公共错误来源与向量局部写入资格 |

局部测量应包含实际寄存器来源及所有中间表达式。对前端组范围，需要同时包含保存的通道、列数和通道上限；对DMA状态，需要包含上下文计数、读取保护、读通道选择和配置接受。模块形式与数值检查完成后，固定整合源码重新测量完整SoC。

## 每轮执行

1. 固定参考提交，将独立模块交给不同智能体，明确文件范围、参数和公开输出。
2. 按 `rtl-design` 与 `synthesizable-rtl-style` 修改，显式处理位宽、符号、优先级和实例连接，编写中文注释。
3. 完成涉及的全输入算术或完整状态证明，运行数值及逐周期接口检查，用相同参数测量资源和路径。
4. 固定整合源码，使用实际FPGA分支及官方原语模型运行86项完整NPU任务，核对容量和完整生产结构。
5. 综合完整SoC，验证ABC9网络与所选DSP参数，检查所有单元已分类、连接图无组合环及最长路径不超过15级。
6. 对同一份固定网表完成合法布局，重新统计逻辑、RAM LUT、SRL及全部物理位置，确认面积不超过50,000。
7. 使用完整目标器件延迟模型完成布局布线时序分析，按6.667 ns周期检查150 MHz及实际最差路径。

小存储器继续使用 `regfile` 表达端口与读取周期，物理实现由综合工具选择。LUT配对保存真值和功能单元检查；DSP分配同时检查内部寄存边界和外部组合级数。

## 当前工具与恢复

完整综合使用Yosys 0.71、ABC9和740个DSP预算。物理实现可使用 `NEXTPNR_HEAP_MAX_ITERS` 和 `NEXTPNR_REFINE_MAX_ITERS` 控制位置搜索与细化次数，全部位置合法性检查仍执行。第23轮使用种子1、两次分析布局及一次细化。开源工具的目标器件时序模型覆盖不完整，150 MHz结果保留为未确认状态，完整器件实现脚本继续使用6.667 ns约束。

交接包含固定源码、完整差异、所需Git对象与历史提交、工具摘要、实际网表、资源及功能报告。应用补丁后核对完整源码树，使用Git包恢复后核对固定提交，并验证压缩网表解压后的SHA256。每次测量同时保存固定源码清单，避免在运行期间修改被测文件。
