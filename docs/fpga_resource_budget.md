# FPGA 资源与时序规划

## 整体目标

完整 `soc_top` 的布局前 LUT 目标为 **45,000**，目标器件为 Artix-7 `xc7a200tfbg484-3`，工作频率为 **150 MHz**，周期约束为 **6.666667 ns**。寄存器间组合路径最多包含 **10 个组合单元**；重点路径按少于 7 级的方向优化。建立时间和保持时间使用实际器件布局布线结果检查。

LUT 统计包含逻辑 LUT、分布式 RAM 和 SRL，资源范围包括 NPU、PicoRV32、CPU RAM 接口、AXI 互连及外设。触发器、DSP、RAMB36 和 RAMB18 分别报告。布局前原语数量和布局后 Slice LUT 数量分别保存。当前测量、源码摘要和各项目标状态见 [完整 SoC 检查](fpga_150mhz_optimization.md)。

## 生产配置

| 项目 | 配置 |
| --- | --- |
| 计算阵列 | 16 × 16，共 256 个计算单元 |
| FPGA 向量并行度 | 8 个 PE |
| 数据流与精度 | WS、IS，INT8、INT16，INT32 部分和 |
| 总线 | 64 位，读取和写入各 4 个在途事务 |
| 共享存储 | 7 × 8,192 字节 |
| im2col 缓存 | 4,096 字节，128 字节缓存行 |
| 部分和 | 16 帧，49,152 字节 RAW 存储空间 |
| 量化 | 2 个计算通道，16 个元素分 8 批处理，512 行输入缓冲 |
| CPU | PicoRV32，乘除法启用，256 KiB RAM |

配置由 [config/npu_fpga.mk](../config/npu_fpga.mk) 和生产顶层参数共同确定。功能、计算规模、数据位宽、缓存容量与公开接口行为保持明确的检查记录。

## 模块优化方法

| 范围 | 主要检查内容 |
| --- | --- |
| im2col | 坐标递推、符号与边界判断、窗口选择、预取状态 |
| 量化 | 统一单通道算术、参数广播、分时控制、移位与舍入 |
| 数据加载 | DMA 完成条件、命令准备、同步参数读取、索引位宽 |
| 向量计算 | 操作数存储、固定 PE 分组、标量运算共享、写回选择 |
| 部分和与缓存 | 同步读取、按组写入、有效状态、数据与元数据寿命 |
| 调度与配置 | 尾部尺寸、容量计算、已保存条件与输出使能 |
| SoC | AXI 请求与响应、地址生成、存储端口和处理器接口 |

独立模块测量用于分析具体表达式。完整 SoC 测量用于计算总资源和最长组合路径；跨模块共用逻辑单独统计，独立模块面积不直接相加。候选方案同时检查 LUT、FF、DSP、RAM 和路径变化。

## RTL 组织

每个设计模块或 package 使用独立源文件，NPU 文件以少于 1,500 行为维护目标。同一字段的流水寄存器使用数组，各阶段保留明确的更新条件。位宽、符号或数值含义不同的中间结果分别声明。

算术、选择、比较、移位和存储使用普通可综合 RTL，由工具映射资源。同步存储的读使能、输出保持和写掩码参与功能验证。说明性注释使用中文，模块职责与接口见 [模块组织](rtl_module_layout.md)。

## 验证与实现

每个算术变换先检查完整输入范围及必要的四态行为，再执行相关模块和完整 NPU 功能检查。集成任务覆盖 WS/IS、逐张量/逐通道、INT8/INT16、尾部尺寸、非对齐传输、总线等待、复位和错误恢复。

综合分析保存源码摘要、完整参数、工具版本、映射资源和连接路径。FPGA 时序由目标器件布局布线结果确认。ASIC 使用独立的 **3,500,000** 总单元面积目标和相同的 150 MHz 频率要求，生产配置与运行入口见 [ASIC 综合配置](asic_npu_r16_150.md)。
