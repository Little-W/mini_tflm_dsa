# FPGA 资源与时序规划

## 实现目标

完整 SoC 使用 Artix-7 `xc7a200tfbg484-3`，核心时钟为 150 MHz，周期为 6.667 ns。实现采用直接 INT32 部分和存储，保留 WS、IS、INT8、INT16、硬件 im2col、深度卷积、池化、Add 和 Softmax 功能。完整 SoC 的 LUT 占用要求低于 50,000，内部规划为 49,000 LUT。

资源统计包含计算阵列、片上存储接口、DMA、缓存、向量计算、寄存器接口、处理器和 SoC 互连。LUTRAM 计入 LUT 总量，BRAM、DSP 和触发器分别报告。PicoRV32 可保留除法扩展，NPU 使用计数器、移位和分阶段运算完成控制与地址生成。

下表为优化目标，各项预算覆盖互不重叠的逻辑范围。

## 向量单元组织

向量单元采用主状态机协调以下控制器和数据通路：

- `vector_config_check` 顺序检查描述符和存储范围，并共用配置乘法器。
- PE 操作数寄存器将数据选择与乘加分开，主状态机分别控制操作数接收和结果写入。
- `vector_round_shift` 使用六级固定移位与舍弃位归并结构，完成有符号最近偶数舍入。
- `vector_softmax` 使用固定规格化、固定移位和分阶段 Q31 舍入，复用向量单元的标量乘法器。
- `vector_writeback` 保存写事务的地址、长度和字节偏移，通过窄计数器控制数据打包与写响应。

结果保留在主单元的结果存储中，写回控制器接收事务后，主单元保持该存储稳定，直到写响应完成。写请求、数据传输及响应分别由独立状态控制。

## RTL 编写方法

固定并行结构使用 `generate` 明确实例数量、连接关系和数据位宽。重复控制任务使用计数器和状态机执行。组合逻辑中的选择范围由真实容量决定，地址、索引和长度分别采用对应的最小位宽。

存储器采用同步读取模板，通过流水线传递数据有效标志。宽数据寄存器仅在接收数据时更新，状态寄存器独立控制事务有效性。面积与时序分析逻辑放置在测试平台中。

## 验证与综合

每次修改需要完成算术检查、接口等待检查和相关功能回归。配置和数据通路的验证覆盖边界尺寸、尾块、非对齐传输、随机总线等待以及错误恢复。固定 MAC 数、数据位宽、缓存容量和接口配置后比较周期与面积。

独立综合检查最差的 100 条路径，按照数据选择、运算、寄存器使能和地址生成分析延时。完整 SoC 使用工程原有的时钟与接口约束检查资源和时序，最终实现报告还需包含布局布线后的时序结果。
