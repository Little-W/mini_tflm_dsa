# 第22轮完整SoC综合、布局与功能验证

固定RTL源码提交为 `b20921b3b1fc3351b1f6447dd688af12ac60ef19`，源码树为 `dbf53c7cb0ed1ff9f2e729f0f6ced653797136e3`。顶层为 `soc_top`，目标器件为 `xc7a200tfbg484-3`，时钟周期约束为6.667 ns。

本轮固定设计已通过86个完整NPU任务、216,348项INT32数值检查、83项容量检查及通用与FPGA两种结构检查。全部任务统计与第19轮参考版本一致。选中的DSP算术参数已通过100组全输入SAT证明。

实际合法布局占用 **49,536个物理LUT位置**，满足50,000的面积要求，剩余464个位置。最长寄存器间组合路径为 **16级**，导出的200组不同路径中有11组超过15级。150 MHz需要完整厂商布局布线后的静态时序分析确认，当前尚未确认。

## 当前设计

生产配置保持16×16阵列、8个向量PE、INT8/INT16输入和INT32累加与部分和、64位AXI总线、4 KiB im2col缓存、7个8 KiB共享银行、16个部分和帧以及256 KiB CPU RAM。部分和直接保存INT32，量化使用两个计算通道和512行整组缓存。

### IA加载许可

`ia_loader_ctrl.sv` 分别计算普通组、尾组及已保存预取组的边界关系，再选择当前组的结果。配置值保持先转换为 `count_t`、再转换为 `LOAD_CNT_W` 的顺序；预取上界保持原有位宽。

FPGA分支将递增游标的相等关系拆为独立分组：第一组检查最低三个结果位，后续各组利用相邻低位确定进位，检查两个结果位，再归约得到相等结果。生产配置的七位游标使用两级LUT完成比较，并保留模 `2^LOAD_CNT_W` 的回绕行为。

槽号对应的忙碌位与有效位分别选择，再与状态及剩余请求条件合并。IA加载器提前计算缓存资格，将 `request_lookup_ready` 与 `ext_dma_start` 接入最终请求LUT；授予逻辑单独合并对应条件。状态寄存器数量与公开接口周期保持一致。

### 前端S8偏移

各通道分别计算输入字节与偏移低字节的和及进位，共享偏移高字节的原值、递增值和递减值，再根据输入符号和低字节进位选择高字节。结果保留全部16位模加语义，覆盖任意16位 `input_offset`。缓存容量、写入掩码、数据格式和握手周期保持一致。

### 向量配置描述符

`vector_engine` 在 `CONFIGURE` 状态持续置位 `dma_cfg_valid`，配置接受事件为 `dma_cfg_valid && dma_cfg_ready`。状态机在接收边沿进入 `TILE_INIT` 或 `VECTOR_INIT`，配置等待期间保持描述符稳定。该结构消除 `ready` 到 `valid` 的组合依赖。

单元归纳证明从复位后的状态检查配置等待性质，外部输入不增加取值限制。仲裁与DMA的组合比较以 `CONFIGURE` 期间没有客户端请求为条件；实际完整NPU任务同时检查普通客户端和向量请求的互斥状态。两部分的验证范围分别记录在模块报告中。

### 前端递增通道范围

`LANES <= 4` 时，前端预计算增量0至 `LANES` 的低四位加法等式。加数第3位恒为零，低四位相等成立时，传入第4位的进位由 `ch_q[3] && !target[3]` 确定。四个组末阈值的高十二位关系独立准备，与低位等式共同保持完整16位回绕结果。

实际有效通道掩码仅控制最终两级优先选择，始终采用最后有效通道对应的增量，覆盖全零和非连续掩码。组通道数与短组条件进入末级选择，`group_range_next[5]` 的三个范围合并输出分别使用单级LUT。其它通道来源、时序状态和接口周期保持一致。

## DSP技术映射

DSP预算为740，包含370个原有DSP和从478个算术候选中选出的370个单元。候选位宽为8至48位，选择时检查选中DSP之间以及与原有未寄存DSP之间的组合依赖，同一组合路径最多包含一个选中的组合DSP。

所选算术对应100组位宽和符号参数，合计3,366个确定输入位。全部通过官方Yosys `$alu` 与 `DSP48E1` 模型的全输入SAT证明，比较 `X`、`Y` 和全部 `CO` 位。DSP选择报告SHA-256为 `96821fb06d2b364902e155336a895b8395ed573eeb12d65f77505189d033df06`，证明摘要为 `c87bfae9bcb39b85e3cf741acd463775553f1f325d1f0a581f4da8eeb40fd666`。

`pre_lut` 阶段耗时410.75秒，所选DSP参数证明耗时22.82秒。LUT映射耗时163.09秒，ABC9网络等价检查通过。布局采用固定程序 `nextpnr-xilinx.10357cc430a78c45`，程序SHA-256为 `10357cc430a78c45842554a01c0c6d0ec62d9cba3e656815aae0523560a035b3`。
