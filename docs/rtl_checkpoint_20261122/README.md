# R7 RTL 导出版本

日期：2026 年 11 月 22 日。

本版本包含已经完成模块验证、完整 NPU 仿真和真实 CPU 固件仿真的 RTL。`rtl/`、`config/` 和 `test/monitors/` 中的 119 个文件均与测试使用的固定源码副本一致，逐文件 SHA-256 见 [source_hashes.json](source_hashes.json)。RTL 使用算术表达式、数组和时序过程描述硬件，未实例化 LUT、BRAM 或 DSP 原语。新增硬件注释使用中文。

## 完整 SoC 综合结果

生产配置使用 `soc_top`，阵列尺寸为 16，AXI 数据宽度为 64，向量计算单元数量为 8，启用共享存储及原始 32 位部分和。完整参数和工具输入记录见 [synthesis_manifest.json](synthesis_manifest.json)。

资源数量来自开源综合流程在器件资源装入之前的统计，包含逻辑 LUT、分布式 RAM 和移位寄存器的名义占用。与采用同一统计方法的 R6 结果 56,603 LUT 相比，本版本减少 2,210 LUT，约 3.90%。详细结果见 [soc_metrics.json](soc_metrics.json) 和 [status.json](status.json)。

当前还需要减少至少 4,393 LUT，并将最长组合路径从 15 级缩短至 10 级。150 MHz 对应约 6.667 ns 的时钟周期，当前 RTL 尚无 Vivado 布局布线结果。组合单元级数检查覆盖寄存器的数据输入和同步控制输入；实际时钟频率需要结合目标器件的单元延迟与布线延迟计算。

当前最长路径涉及 `ia_loader_ctrl.ps_frame_final` 到请求启动与状态寄存器、配置复用参数到 `ps_window_scheduler.phase`，以及 S16 输出有效列数量到 DMA 写数据字节使能。报告保留每条路径经过的器件单元和起止寄存器，供后续优化使用。

## 当前硬件结构

- DMA 前端共享描述符算术与历史存储，IA 写入路径共享数据处理并分别保存两个端口的地址、掩码和使能。
- 卷积窗口队列保存当前有效位置；内核加载器并行计算允许启动的条件，调度器共享配置算术。
- 向量计算、Add 与 Softmax 共用输入存储的读取结构；Softmax 指数结果使用独立数组保存。
- 输出 FIFO 在配置阶段保存容量阈值；量化 DMA 共用参数偏移计算；偏置加载器共享行地址和组地址算术。
- CPU 地址运算共享扩展比较结果；SoC RAM 并行计算读取边界；生产配置先接收并保存 CPU RAM 写地址，再接收第一拍写数据。
- DMA 读地址和写数据各通过两个条目的寄存器缓冲传递，分别保存完整地址描述和数据、字节使能与结束标志。复位清除缓冲有效状态，正常传输保持 AXI 接收顺序。
