## 1. 前端接收条件与通道位置更新

`conv_im2col_frontend.sv` 将组范围判断中的低位进位、高位大小关系和模加等式合并到一个 LUT6。高位加一等式采用固定比较结构，`incoming_group_fits` 直接参与快速接收的最终判断，坐标资格和单行条件并行计算。

描述符当前组比较共用已有分组结果。当前字地址和返回字地址等式保留完整 32 位模加语义，普通步长与换行步长分别准备低两位进位，描述符随后选择已完成的进位结果。通道位置先计算流式推进和 Q 解码结果，再由同周期接受的快速描述符进行最终选择；相邻两个数据位共用 LUT6_2 完成该选择。复位、错误返回、无效描述符、状态更新和接口周期均保持原有行为。

## 2. DMA 中止条件与任务接收

`kernel_loader.sv` 通过一位组合输出 `o_prefetch_quiescent` 提供原有后台空闲条件，包含预取状态、正在传输标志、等待比较的请求、DMA 忙状态和响应位置占用状态。`axi_block_dma_arbiter.sv` 通过一位组合输出 `o_kernel_eligible` 提供权重命令资格，即命令位置可用且当前命令属于 `C_KERNEL`。

令 `Q` 为后台空闲，`R` 为加载器原始 `load_weight_req`，`G` 为权重命令资格，`A` 为其余接收条件。原有授予仍检查当前 `abort`，最终就绪条件采用等价关系：

```text
kernel_granted = !abort && G
kernel_prefetch_idle = Q && !(R && kernel_granted)
sa_ready = A && Q && (abort || !(R && G))
```

顶层提前计算 `R && G`，使 `abort` 直接进入最终 LUT6。原有授予、DMA 开始、预取空闲、完成输出和状态更新保持原有语义。公开 `calc_start` 的任意输入行为，以及生产 clock-gating 下 AXIL 开始请求包含 `sa_ready` 的实际连接，均纳入证明和测量。修改增加 0 位状态寄存器、0 个接口周期。

## 3. DMA 返回标签选择

`axi_dual_block_dma.sv` 将前端返回、窗口占用和卷积完成条件与标签位选择合并。每个标签位的逻辑为：

```systemverilog
((fe_wr_valid && !win_frontend_active) || conv_done_r)
    ? conv_tag_q : linear_response_tag
```

FPGA 实现对每个标签位采用一个 LUT6，保留全部标签位以及无效周期的输出行为。通用实现采用相同条件表达式。修改增加 0 位寄存器、0 个接口周期。

实际局部模型包含缓存响应错误数组选择、前端 `wr_valid`、返回标签和仲裁器 `dw_raw_valid` 译码。各测量在同样的输入、输出处设置寄存器。

## 4. 向量 Softmax 累加器写入资格
