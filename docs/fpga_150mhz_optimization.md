# 完整 SoC RTL 与综合结果

当前设计使用普通可综合 RTL 描述算术和同步存储。完整 SoC 的 FPGA 目标为布局前 LUT 合计不超过 **45,000**，最长寄存器间组合路径不超过 **10 个组合单元**，工作频率为 **150 MHz**。生产 NPU 的 DC cell area 目标为 **3,500,000**。

## 当前设计

NPU 的 112 个源文件均少于 1500 行，最长为 1488 行。顶层、im2col 前端、向量引擎和量化运算按职责分别使用独立模块；连续阶段的同类字段使用数组。当前设计说明见 [模块组织](rtl_module_layout.md)、[im2col 前端](im2col_frontend.md) 和 [统一量化](unified_requant.md)。

完整 SoC 包含 16 × 16 NPU 阵列、8 个向量 PE、64 位总线、PicoRV32、256 KiB CPU RAM、AXI 互连和 UART。矩阵量化使用两个 `requant_compute_lane` 和 512 行输入缓冲，逐张量及逐通道参数共用七级算术流水，INT8/INT16 由模式选择。容量与接口参数见 [FPGA 资源配置](fpga_resource_budget.md)。
