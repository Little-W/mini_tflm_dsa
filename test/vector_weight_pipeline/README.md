# 向量权重写入与累加读取

## 当前结构

共享权重写入接口在接收 DMA 返回数据时，一起保存 128 位数据、16 位字节掩码和存储地址。有效请求在下一周期发布到共享 RAM；每个周期可以接收并发布一个请求。存储错误或 `FAILED` 状态会取消尚未发布的请求，完成和错误排空条件包含该寄存阶段的有效状态。

权重返回标签和缓存标签按三个地址位分组比较，然后合并各组结果及有效位。每个保留的中间信号都参与实际标签匹配。输入银行的有效位与银行写入存在标志在同一个边沿更新，完成条件使用已保存的存在标志。

串行归约与量化共用累加存储的读取选择器。归约起始周期读取第一项，后续周期提前读取下一项，累加操作的接收和提交周期保持一致。全局池化在执行周期保存是否还有下一个像素，提交周期使用该结果。

## 功能验证

| 参数配置 | 任务数量 | 正确输出数量 | 案例周期总数 |
| --- | ---: | ---: | ---: |
| 8 PE，64 位总线，8 个窗口通道，私有向量量化，共享权重及部分和存储 | 616 | 170,743 | 3,422,533 |
| 16 PE，32 位总线，4 个窗口通道，共享量化，私有权重及部分和存储 | 616 | 170,743 | 3,711,728 |
| 8 PE，64 位总线，固定等待性能测试 | 40 | 103,743 | 1,071,159 |

生产配置使用七个共享银行，每个银行 8,192 字节，其中两个银行用于输入。两种参数配置均启用 RTL 控制和数据断言，并使用独立的有符号整数参考计算。各项测试的全部周期统计与比较版本一致。逐案例结果、来源散列和执行程序散列保存在 `validation.json`。

生产回归检查了 2,015 次权重接收和发布，包括 592 次连续周期发布、1,171 个行末拍和 101 个最后卷积核位置的末拍。逐拍检查比较地址、完整数据、字节掩码和发布时刻。预取检查同时覆盖 RAM 返回数据、缓存数据、暂停、无效坐标跳过、计算位置变化和作业切换。

错误测试覆盖权重读取首拍、跨页位置、中间位置、最后位置，以及上一输出事务出错时下一组权重正在读取的情况，并检查后续作业恢复。独立写入阶段测试运行 20,000 周期，包含 9,364 次有效发布、968 次错误取消、3,504 次连续发布和 78 个复位周期。

六种地址及卷积核索引宽度完成了全部二值输入的标签等价证明；写入阶段完成了八周期任意输入序列的 SAT 证明。四态测试比较了 196,608 组标签结果。测试直接提取当前 RTL 的标签表达式和写入寄存阶段。

## 运行方法

```bash
python test/vector_weight_pipeline/run.py \
  --source-root . --out build/vector_weight_pipeline

python test/vector_engine/run.py \
  --source-root . --out build/vector_weight_pipeline_production \
  --pes 8 --tile 16 --jobs 1 \
  --cache-sets 16 --cache-policy 3 --cache-line-bytes 128 \
  --bus-width 64 --window-lanes 8 --shared-storage \
  --shared-bank-bytes 8192 --shared-bank-count 7 --shared-ia-banks 2 \
  --check-weight-write-stage --rtl-assertions --stable-stimulus --xilinx
```

在相同构建命令后增加 `--skip-build --perf` 可以运行固定等待性能测试。通用配置使用 `--pes 16 --bus-width 32 --window-lanes 4 --shared-quant`，并保留 `--rtl-assertions --stable-stimulus`。
