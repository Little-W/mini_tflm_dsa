# AXI 分段读取的页末截短与地址递增

`conv_axi_span_reader` 在当前页的最后一个最大突发范围内计算页余量。
较高地址位并行判断是否进入该范围，低位减法计算精确剩余字节数，
保留字节读取和非整字页余量的处理。地址位数达到完整页宽时，直接使用
12 位页内地址。突发长度仍同时受请求剩余长度、DMA 上限和 4 KiB 边界约束。

32 位读取地址采用两个 16 位部分相加。高半地址并行计算有进位和无进位的
结果，低半地址的进位只控制最后的选择。地址保留原有的模 2³² 递增行为，
请求接收、响应交接和状态更新使用原有时钟边沿。

## 完整状态等价

`run_formal.py` 从提交 `51c390c51884c686bc1a08e1b32f40f9047b7b1b`
读取比较源文件，对完整模块执行 SAT 和时序归纳。54 组参数共比较
24,121 个状态及信号位，全部通过。证明包含所有公开输出及无效周期输出，
输入没有附加对齐、范围或握手限制。

参数包括 32、64、128 和 1024 位总线，请求上限覆盖 1 至 65,535 字节及
完整字前后边界，DMA 上限覆盖 1 至 256 个总线传输拍。

## 数值与协议测试

`run_protocol.py` 复用现有的独立数值检查程序，并启用 RTL 断言：

- 32 位总线完成 452 个分段请求、1,168,092 字节和 448 次相邻请求同边沿交接。
  覆盖字节前缀、字节后缀、4 KiB 边界、最大长度、地址末端、随机反压和 22 次响应错误。
- 64 位缓存完成四组需求队列和缓存路数组合的 48 项协议测试。
  共接收 761 个请求，返回 750 个请求，另外 11 个请求由测试中的复位取消。
  连续命中的接收及返回间隔均为一个周期。

## 普通 RTL 综合

两组测量使用相同公共源文件、参数及综合选项。分段读取器配置为
64 位总线、16 字节请求上限；缓存配置为 128 组、2 路、16 字节缓存行、
4 项需求队列。测量结果保存在 `measurement.json`。

| 模块范围 | 比较版本逻辑 LUT | 当前逻辑 LUT | 比较版本最长级数 | 当前最长级数 |
|---|---:|---:|---:|---:|
| 分段读取器 | 167 | 163 | 11 | 9 |
| 包含分段读取器的缓存 | 3584 | 3481 | 13 | 12 |

分段读取器保留 78 个寄存器；缓存保留 1807 个寄存器、25 个 RAMB18 和
256 个分布式存储 LUT。两组综合均使用普通 RTL 推断，DSP 数量均为零。
缓存还有 12 级控制路径需要继续处理。这里的级数来自完整映射图，
器件频率和实际 LUT 使用量由整机 Vivado 综合与实现报告核对。

## 复现

在仓库根目录运行，环境中需要提供 Pyosys、Slang 和 Verilator：

```bash
python test/span_page_clip/run_formal.py --out build/span_page_clip/formal
python test/span_page_clip/run_protocol.py --out build/span_page_clip/protocol --verilator verilator-modern
python test/span_page_clip/measure.py --out build/span_page_clip/measurement
```

协议测试顺序编译并保留每组报告与可执行文件。综合脚本在每个配置完成后
压缩中间网表，以限制临时文件占用。
