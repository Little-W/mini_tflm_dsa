# 量化参数 DMA 地址运算

量化参数读取共用通道块与当前装载偏移的加法。乘数参数和移位参数分别与字节偏移相加，最后按读取阶段选择地址。表达式采用 `max(REG_WIDTH, 32)` 位保存中间结果，保留原有运算扩展、定宽截断和未知态传播。两种读取阶段共用下一次装载偏移。所有运算使用普通 RTL 加减与乘法表达式，适用的宽运算由综合属性选择算术资源。

32 组配置通过全部二态输入的组合形式证明，寄存器位宽包括 1、8、17、24、32、40、48、64 位，通道数量包括 1、3、16、32。每组同时比较实际地址和偏移结果。四态仿真对 10,000 组输入运行全部配置，共完成 320,000 次严格结果比较，覆盖输入数据、计数和阶段选择中的 X/Z。

```sh
python test/requant_dma_arithmetic/run.py --out build/requant_dma_arithmetic
```

`validation.json` 保存被测源码 SHA-256 和各配置结果。
