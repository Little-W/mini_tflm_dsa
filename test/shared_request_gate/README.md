# 共享存储请求与错误资格

`ia_ps_channel_ram` 并行形成部分和地址范围、目标银行和同地址读写关系，再通过 `ps_channel_write_enable` 直接生成写入资格。`ps_channel_request_fault` 对每个通道分别检查访问许可、地址范围和读写冲突，随后汇总容量故障。物理存储数组、地址、写入掩码、写数据和同步读取时序保持相同。

两个辅助模块使用普通组合 RTL。控制包含未知值时保留逐位逻辑和原有条件语句的四态语义。

## 完整通道测量

参数为每块 8192 字节、总容量 57344 字节，启用共享写数据、有效非空写入、配对 IA 端口和独立通路返回数据。两次测量采用相同参数、依赖和 `physical-cost` 设置：最大 LUT 输入数 8、布线延迟 300 ps、目标周期 6667 ps。

| 项目 | 参考实现 | 当前实现 |
|---|---:|---:|
| 逻辑 LUT | 1152 | 1148 |
| FF | 10 | 10 |
| RAMB36 | 34 | 34 |
| 全部寄存器路径最大级数 | 9 | 10 |
| 部分和写请求到共享 RAM EN/WE | 6 | 3 |
| 部分和读请求到共享 RAM EN/WE | 6 | 4 |
| 部分和读写请求到容量故障寄存器 | 6 | 4 |
| 全局访问使能到共享 RAM EN/WE | 1 | 1 |

输入端口路径使用只参与分析的边界节点，未改变综合网表。完整 SoC 的跨模块路径由整机综合报告另行统计。

## 验证范围

- 5 组参数分别覆盖通用与 FPGA 编译方式，共 10 项时序归纳证明。首次采样复位，之后所有功能输入及复位自由变化。
- 对每个物理存储实例逐位比较所有读写使能、地址、写入掩码和写数据。每个存储输出使用独立、逐周期自由的共享返回值，同时比较公开输出、配置状态、故障状态和返回选择状态。
- 使用实际数组进行 5 组参数、两种编译方式的 81920 个周期比较。每拍检查全部物理存储字及全部公开返回，包含并行读写、暂停、配置切换、非法访问、未知值和高阻态控制。

通用形式配置显式使用 `-USYNTHESIS -UXILINX_FPGA`，FPGA 形式配置使用 `-DSYNTHESIS=1 -DXILINX_FPGA=1`。

```bash
python test/shared_request_gate/run.py --out build/shared_request_gate
```

`validation.json` 保存参数、源码和日志摘要；`measurement.json` 保存资源统计和指定输入到实际寄存器或 RAM 端口的完整连接路径。
