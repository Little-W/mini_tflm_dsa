# 共享 IA 存储的写数据寄存级

`ia_loader_cache_mgr` 的 `p_shared_write_stage` 参数启用共享 IA 存储的数据输出。该参数默认关闭，适用于 `SIZE=16`、`DATA_WIDTH=16` 的外部存储配置。生产顶层通过 `ia_loader` 将 `ram_shared_wr_data` 连接到 `ia_ps_channel_ram.i_ia_shared_write_data`。

写命令边沿保存原始输入通道、有效位、列起点、紧凑格式标志、偏移字节及第二端口选择。寄存器输出随后完成字节恢复、列移位和存储格式选择。原始输入数据与后续排列运算之间存在时钟边界，`ram_shared_wr_data` 仍在同一个写命令采样边沿更新。

S8 紧凑模式将输入数据减去偏移，保留低八位，按列位置放入 128 位存储字。无效位置保存零数据对应的紧凑字节。S16 模式保留完整十六位数据，选择实际写入端口对应的半行。八个输入通道支持全部十六个列起点，超过当前行末的数据自然移出，有效位决定实际写入位置。

两个写端口分别在各自的写使能边沿保存原始通道数据、有效位和列位置，随后形成对应端口的存储字。第一端口同时保存紧凑格式和偏移字节。地址、掩码和使能保留原有采样边沿，各端口的数据也在同一边沿更新。没有写命令时，各端口及共享写数据分别保持已有内容。写使能按原有周期复位。上述寄存级分配保持存储写入和读取周期；参数关闭或使用本地存储时，共享数据输出为零。

## 功能验证

| 检查 | 当前结果 |
| --- | ---: |
| 共享数据与实际存储写入关系 | 5 项性质通过复位检查和无界归纳 |
| 四态数据、格式、有效位和列位置 | 100,004 组输入，357,976 次比较通过 |
| 所有八位数据与偏移组合 | 65,536 组通过 |
| 八通道任意列起点的实际写入 | 20,000 次随机写入通过 |
| 未写入端口及共享数据的保持行为 | 全部写入周期同时检查 |

归纳证明只要求第一个采样边沿复位，其余输入均可任意变化。五项性质分别检查第二端口数据选择、仅第一端口有效时的数据选择、第二端口地址最低位、双端口同时写入时第一端口地址最低位，以及实际共享存储块接收的全部 128 位数据。

四态检查从实际 RTL 提取写命令寄存和共享数据逻辑，使用 `0/1/X/Z` 数据，包含未知格式、未知有效位、未知偏移位和未知列位置。每个周期同时检查两个写端口的数据及共享数据，包含无效周期、独立保持周期和复位周期。

实际写入测试覆盖紧凑格式和宽格式、八个输入通道、全部列起点、任意有效掩码、行末裁剪、端口选择和数据保持。每次时钟更新后同时检查共享数据及两个原有端口的地址、数据、掩码和使能。

```sh
python3 test/ia_shared_write_stage/run_formal.py --out build/ia_shared_write_formal
python3 test/ia_shared_write_stage/run_four_state.py --out build/ia_shared_write_four_state
python3 test/ia_shared/run_receive_write.py --fpga --out build/ia_receive_write
python3 test/dma_source_layout/cache_layout_formal.py --out build/ia_layout_formal
```
