# 共享 IA 存储的写数据寄存级

`ia_loader_cache_mgr` 的 `p_shared_write_stage` 参数启用共享 IA 存储的数据输出。该参数默认关闭，适用于 `SIZE=16`、`DATA_WIDTH=16` 的外部存储配置。生产顶层通过 `ia_loader` 将 `ram_shared_wr_data` 连接到 `ia_ps_channel_ram.i_ia_shared_write_data`。

两个写端口共用一组输入寄存器，逐拍保存原始通道数据、有效位、列起点、紧凑格式标志和偏移字节。寄存器输出随后完成字节恢复、列移位和存储格式选择。各端口的写使能、地址和字节掩码确定该拍的实际存储写入，端口数据与对应命令使用同一个采样边沿。

S8 紧凑模式将输入数据减去偏移，保留低八位，按列位置放入 128 位存储字。无效位置保存零数据对应的紧凑字节。S16 模式保留完整十六位数据，两个端口分别提供低半行和高半行。八个输入通道支持全部十六个列起点，超过当前行末的数据自然移出。

共享数据根据已保存的第二端口写使能选择相应半行。原始输入与后续排列运算之间有时钟边界，写入和读取的有效周期保持不变。地址和掩码仅在对应端口存在写命令时更新，写使能在复位时清零。参数关闭或使用本地存储时，共享数据输出为零。

## 功能验证

| 检查 | 当前结果 |
| --- | ---: |
| 共享数据与实际存储写入关系 | 5 项性质通过复位检查和无界归纳 |
| 四态数据、格式、有效位和列位置 | 100,004 组输入，188,990 次有效数据比较通过 |
| 所有八位数据与偏移组合 | 65,536 组通过 |
| 八通道任意列起点的实际写入 | 20,000 次随机写入通过 |
| 空闲命令与地址、掩码保持 | 数值测试逐周期检查 |
| 完整 IA 控制与有效写入数据 | 三种配置共 27,739 位时序对应关系通过 |

无界归纳证明只要求第一个采样边沿复位，其余输入均可任意变化。五项性质分别检查第二端口数据选择、仅第一端口有效时的数据选择、第二端口地址最低位、双端口同时写入时第一端口地址最低位，以及实际共享存储块接收的全部 128 位数据。

四态检查从实际 RTL 提取写命令和输入寄存逻辑，使用 `0/1/X/Z` 数据，包含未知格式、未知有效位、未知偏移位和未知列位置。每个端口在其写使能为已知有效值时比较数据，共享数据在任一写端口有效时比较；复位和空闲周期检查写命令资格。

实际写入测试覆盖紧凑格式和宽格式、全部输入通道和列起点、任意有效掩码、行末裁剪及端口选择。每次时钟更新后检查端口使能、有效写入数据、共享数据及已保存的地址和掩码。

```sh
python3 test/ia_shared_write_stage/run_formal.py --out build/ia_shared_write_formal

python3 test/ia_shared/run_receive_write.py --fpga --out build/ia_receive_write
python3 test/dma_source_layout/cache_layout_formal.py --out build/ia_layout_formal
```
