# 向量请求准备与地址组合路径

寄存器更新事件的设计与检查见 [tap_updates.md](tap_updates.md)，参数行数准备与完整引擎检查见 [address_updates.md](address_updates.md)。

窗口范围和槽位资格分别计算。空闲槽位资格与同拍释放资格在独立末级汇合，权重返回引起的计算发射直接参与该末级选择。横纵坐标使用两项完整十七位差值比较，并同时检查坐标高位。

三项读地址保持十八位低段、十六位高段的普通算术表达。高段按四位独立形成传播条件，各组直接接收低段进位和低位组条件。参数数组的严格地址次序将完整地址相等比较与差值进位并行归并，等距关系独立形成单比特结果；窗口位置和偏置数组次序使用完整三十二位分段比较。配置字段按其数值范围检查高位扩展与低位边界。

## 完整向量引擎综合

参照提交为 `548bda54`，配置为 16 个通道、8 个 PE、64 位总线、8 个窗口通道、共享存储和本地量化。两组结果使用相同的预综合和映射设置：6667 ps 目标、300 ps 连线成本、最大 8 输入 LUT 成本模型，并完成 ABC9 映射等价检查。

| LUTRAM 名义位置 | 176 | 176 |
| 逻辑与存储 LUT 合计 | 9,978 | 9,932 |
| 触发器 | 6,307 | 6,307 |
| 推断 DSP | 39 | 42 |

端口路径沿实际映射连接统计，接收边界只用于计算路径长度，不加入资源统计。完整记录见 `measurement.json`。器件频率由布局布线后的时序报告确认。

## 功能与四态验证

`run.py` 显式设置 generic、SYNTHESIS、XILINX_FPGA 和两宏同时启用四种配置。未启用 SYNTHESIS 的形式任务明确撤销工具默认宏。

- 完成 20 项形式等价检查。其中 8 项比较完整 `vector_engine_address`，覆盖生产配置与 32 位总线配置；8 项比较三十四位读地址和最高进位，覆盖两种分组配置；4 项比较完整 `vector_config_check`。所有外部输入均无约束，全部公开输出参与逐周期比较。
- 完成 1,507,328 次四态结果比较，覆盖窗口资格、窗口坐标、完整读地址、参数数组地址关系和完整配置检查。窗口资格穷举七项条件的全部四态组合。配置仿真按成员声明使用显式位宽和 signed 类型，保持嵌套 packed struct 的标准读取语义。
- 普通仿真的读地址未知输入回退及选择表达式与参照逐字一致，已知输入由完整接口形式等价覆盖。SYNTHESIS 模式直接比较全部四态地址与最高进位。
- `vector_engine` 及其余依赖源码与参照逐字一致。完整地址模块和配置检查模块的接口等价适用于生产父模块的全部连接，状态更新、请求周期、计算容量和并行度保持相同。

形式结果、四态结果与输入文件摘要见 `validation.json`。
