# 参数行数准备与完整向量引擎检查

参数数组的二维读取描述符在配置检查周期保存。完整三十二位减法计算行步长和最高进位，独立地址比较计算零步长条件。严格递增条件只归并这两个单比特结果。偏置、乘数和移位数组的等距关系独立完成后，再与地址次序及偏置有效条件合并，形成三行读取资格。

输入含未知位时，严格次序判断保留原有关系运算。数据宽度、配置保存边沿、行数选择和 DMA 请求时序保持一致。

## 功能检查

```bash
python test/vector_request_timing/check_address.py --reference 57b61b24 --out build/vector_request_timing/address
python test/vector_request_timing/check_engine.py --reference 57b61b24 --out build/vector_request_timing/engine --jobs 2
```

地址模块覆盖 generic、仅 `SYNTHESIS`、仅 `XILINX_FPGA`、两个宏同时定义，以及寄存读取阶段启用和关闭的八种组合。24,060 个等价点覆盖全部公开输出和共有寄存状态。四态检查直接比较参照模块与当前模块的参数行描述符计算，共 524,288 次比较。

完整 `vector_engine` 在四种宏模式下分别检查 8 和 16 个处理单元，共 172,456 个等价点。比较保留完整地址、控制、存储、运算和写回的连接，全部外部功能输入不增加约束。配置、存储返回、反压和错误输入均参加逐周期比较。

## 综合结果

完整引擎采用 16 个结果通道、8 个处理单元、8 个窗口通道、64 位总线、共享操作数存储和独立量化。映射设置为 6,667 ps 目标、300 ps 连线估计和最多八输入逻辑映射，映射过程执行功能验证。

| 项目 | `57b61b24` | 并行事件及参数关系 |
|---|---:|---:|
| 逻辑 LUT | 9,756 | 9,776 |
| LUTRAM 名义位置 | 176 | 176 |
| 逻辑与存储 LUT 合计 | 9,932 | 9,952 |
| 最长寄存器间组合级数 | 10 | 10 |
| 包含外部端口的最长组合级数 | 10 | 10 |
| `tap` 到预取位置和输入纵坐标 | 10 | 9 |
| 配置寄存器到三行读取资格 | 9 | 7 |

独立地址模块中，参数输入到三行读取资格的路径从 11 级降至 8 级，逻辑 LUT 从 1,703 降至 1,701。完整向量引擎的实际连接用于检查最终组合深度。

完整结果与源码 SHA-256 保存在 `address_validation.json`，父模块形式结果分别保存在 `results/address.json` 和 `results/engine.json`。
