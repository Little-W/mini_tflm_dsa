# 偏置分组推进

`npu_output_bias_advance` 保留完整分组地址位宽与回绕规则。低段接收分组行数，地址推进与范围比较分别计算。范围比较先将当前低段、分组行数和边界反码压缩为和位与进位，再由最高距离位判断次序。高段通过逐位进位一致性检查相邻边界，最后一组判断直接选择已经完成的高段关系。

`npu_output_bias_mask` 通过并行低位全零条件形成减一结果。`npu_output_bias_row_select` 将组首清零资格放在行索引的最终选择级。三个模块均保存原有四态传播行为。

## 运行检查

```sh
python3 test/output_bias_advance/run.py --out build/output_bias_advance
```

检查直接提取生产 `npu_output_pipeline` 中的完整偏置分组状态和读取索引。与提交 `8b3728c008e6093095c8ade34aa4516145bc6005` 逐周期比较，覆盖 16、32、64 位地址配置及普通、综合两种条件编译方式，共 8 项无输入约束的形式证明。另有 7 项独立组合形式检查覆盖地址、大小关系和相等关系的全部输入，包含单个位宽高段、完整位宽和宽于地址的行数输入。四态仿真在两种条件编译方式下分别执行 6003 个周期，包括未知控制、未知配置、初始化与分组切换同时出现的情况。

Yosys 对完整偏置控制进行独立综合，按整机使用的 LUT 资源权重映射得到 332 个 LUT、103 个触发器，最长寄存器间结构路径为 9 个组合单元。默认器件映射得到 360 个 LUT、103 个触发器，最长路径为 8 个组合单元。两项统计均包含初始化、分组推进和读取索引逻辑。
