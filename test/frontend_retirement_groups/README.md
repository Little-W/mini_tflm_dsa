# 缓存行释放位置的分组进位

条件递增将 17 位行号划分为五位小组，分别计算组间传播条件和组内传播条件。
保留组传播信号后，多个输出位共用有明确分组的进位条件。行释放计算的两个端口
在同一周期完成输入选择、补边相加、右移、条件递增、上限限制和使能选择。

## 等价检查

`run.py` 从当前前端和指定参考版本提取实际计算块，并检查其余前端源码完全相同。
完整计算覆盖 164 个自由输入位，比较两个结果及中间计算的 202 位输出；
独立条件递增覆盖 18 个输入位及 18 位结果。

普通定义和 FPGA 定义分别完成递增块与完整计算块的已定义输入证明，共四项。
另两项证明使用 `-enable_undef` 和 case equality，允许任意输入位为未知，
同时比较输出值和已知状态。两类证明覆盖全部已定义及未知输入情况。
六项证明均通过，输出位宽、截断方式和组合周期保持一致。

## DSP 上下文测量

`--padded-row-dsp` 将两个补边加法映射到组合 DSP，每个加法的参数为
`A_WIDTH=16`、`B_WIDTH=16`、`Y_WIDTH=17`，两个操作数均无符号。
其余算术使用普通进位实现。该设置对应 R6 行释放计算中实际选择的 DSP 运算。

输入和输出两侧放置寄存器，采用 xc7、ABC9、最多六输入 LUT、500 ps 连线延迟
和 6667 ps 目标周期。两个版本均使用 2 个 DSP、4 个 CARRY4 和 142 个触发器，
所报告寄存器路径最多经过一个 DSP。各次 LUT 映射均通过 ABC 网络等价检查。

| 五输入及以下 LUT 面积成本 | 参考 LUT | 分组 LUT | 参考最长组合级数 | 分组最长组合级数 |
| --- | ---: | ---: | ---: | ---: |
| 1 | 189 | 186 | 10 | 9 |
| 0.75 | 193 | 193 | 9 | 9 |

上述数据是两个行释放计算端口的局部测量结果。`measurement.json` 保存源码摘要、
六项证明、DSP 参数和四次映射结果。

## 运行方法

```sh
python3 test/frontend_retirement_groups/run.py \
  --reference 8720e2c729c6468d668193460e78a9254be1db3d \
  --padded-row-dsp \
  --out /tmp/frontend_retirement_groups
```

默认比较成本 1 和 0.75，可通过 `--lut-costs` 指定其他成本。
`--skip-synthesis` 只运行六项等价检查；省略 `--padded-row-dsp` 则使用普通算术
映射，分别测量独立递增块和行释放计算的两个完整端口。
