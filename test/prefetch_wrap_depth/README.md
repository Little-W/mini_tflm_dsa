# 预取跨行起点的组合路径

`conv_im2col_prefetch` 在既有第一准备阶段保存跨越输入行后的起点。完整运算关系为：

```systemverilog
prefetch_wrap_base = 32'(accepted_coordinate_q[0]) - 32'(i_c.input_w);
```

输入行宽为 16 位。实现并行计算两个 16 位段的普通差值，并以低位借位修正高位结果。预取状态、寄存器数量、请求周期和全部公开输出保持一致。存在未知输入时，计算保留原分组加法的四态传播结果。

参考提交为 `92d1c609d57eea25b39b4831ab10d1bdbfd1ad26`，当前 RTL 提交为 `e0a25349f2e15d2894bd0ad05f35e6ccc94449dc`。

## 复现

在仓库根目录运行，Python 环境需包含 `pyosys`、Slang 插件，四态仿真使用 Icarus。

```bash
python test/frontend_address_arithmetic/run.py \
  --reference 92d1c609 \
  --out /tmp/prefetch_wrap_verification

python test/prefetch_wrap_depth/measure.py \
  --reference 92d1c609 \
  --validation /tmp/prefetch_wrap_verification \
  --out /tmp/prefetch_wrap_mapping
```

`measure.py` 先测量完整模块，再筛选目标寄存器的实际连接路径。`--report-only` 可以对已生成且 SHA-256 与当前源码一致的映射目录重新报告目标路径。映射使用 6,667 ps 目标、300 ps 连接延迟模型，以及最多 8 输入的 LUT 分解。

`validation.json` 保存完整模块及公共算术检查结果，`measurement.json` 保存资源和目标寄存器路径。
