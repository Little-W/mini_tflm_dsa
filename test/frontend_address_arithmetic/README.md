# 前端完整地址与预取纵坐标

本目录验证三类定宽运算：输入基址、像素通道乘积和通道组偏移组成的完整组基址，行像素乘积与输入横坐标之和，以及预取核行和跨步窗口的纵坐标。

组基址先将三个加数压缩为两个操作数，再并行计算高低位段。像素求和复用 `conv_full_address_add`。预取核行加一采用分组进位，窗口纵坐标采用并行位段加法。全部计算保持原有位宽、回绕结果、未知值传播和寄存器阶段。

## 功能检查

```bash
python test/frontend_address_arithmetic/run.py \
  --out build/frontend_address_arithmetic/validation
```

完整算术在普通编译与 FPGA 编译两种模式下，对任意二态输入证明全部 131 位结果相等。组基址覆盖完整 32 位基址、32 位乘积、16 位通道组偏移和两种元素宽度；像素与纵坐标均保留完整地址回绕。脚本还检查正式 `conv_im2col_geometry` 实例的五个端口连接。

完整 `conv_im2col_prefetch` 使用两种请求寄存参数以及两组尺寸与缓存行参数，在两种编译模式下完成八组无界状态等价检查。比较对象包含全部公开输出和真实寄存器，组合中间信号不作为状态对应条件。外部输入不附加稳定性或取值限制。

四态检查按实际展开端口宽度生成刺激，每一输入位均覆盖 `0`、`1`、`X`、`Z`，运行时再次检查声明位宽。时钟边沿前后均比较全部预取公开输出。

| 检查范围 | 完成数量 |
|---|---:|
| 完整算术形式证明 | 2 组 |
| 完整预取状态及输出等价 | 8 组 |
| 算术四态结果比较 | 266,400 次 |
| 预取四态运行周期 | 60,116 个周期 |
| 预取公开输出四态比较 | 2,524,872 次 |
| 定向核行及跨步窗口坐标 | 8 个 |
| 定向预取请求输出 | 8 个 |

算术模型包含 133 位独立输入，预取模型每组包含 1,709 位非时钟、非复位输入。定向运行分别检查核行加一和跨步窗口的坐标值、保存阶段及最终预取请求。

## 寄存器路径测量

```bash
python test/frontend_address_arithmetic/measure.py \
  --validation build/frontend_address_arithmetic/validation \
  --out build/frontend_address_arithmetic/mapping
```

测量使用项目 FPGA 综合、ABC9 映射和完整组合图分析脚本，保留推断的 DSP、进位资源及全部真实连接。每次映射均进行功能等价检查。组基址和像素求和的全部输入与完整结果设置寄存器边界；预取测量实例化完整模块，并对其公开组合输入和输出设置寄存器边界。

| 运算范围 | 参考逻辑 LUT | 当前逻辑 LUT | 参考最长路径 | 当前最长路径 |
|---|---:|---:|---:|---:|
| 完整组基址 | 48 | 86 | 11 级 | 5 级 |
| 完整像素求和 | 32 | 23 | 9 级 | 4 级 |
| 已保存预取纵坐标至全部后续寄存器 | 完整模块 1,113 | 完整模块 1,157 | 11 级 | 7 级 |

三个测量实例的寄存器数量均保持不变。组基址与像素求和各推断一个 DSP；完整预取模块的 DSP 数量从八个增加到九个。组基址和像素求和的测量分别包含 113 个、96 个寄存器；完整预取测量含公开端口寄存器，共 2,328 个。

完整预取模块的所有输入路径中，通道位置至预取距离的路径在两份实现中均为 12 级。上表的预取结果检查了每一条从实际纵坐标寄存器出发的路径，包含坐标保存和坐标有效条件；整颗 SoC 的组合级数由完整连接后的测量报告提供。

`validation.json` 保存参数、输入覆盖、源码摘要及形式证明结果。`measurement.json` 保存每个测量实例的资源、完整路径和映射功能检查结果。运行脚本默认使用固定参考提交 `e28e9d3fe5b530337238d7915c4a8606918b240a`，可通过 `--reference` 指定同类参考源码。
