# IA 槽位有效列数的块 RAM 映射

`ia_loader_cache_mgr` 的 `slot_written_cols` 保存每个逻辑槽位的有效列数。该数组采用 `ram_style="block"`，写入过程和同步读取过程保持原样。生产配置有 64 个逻辑槽位，每项 5 位，共 320 位。

## 功能与端口检查

删除新增存储属性后，当前源文件与参考提交 `c96e9378` 的源文件逐字节一致。所有接口、参数、数据宽度、复位、读取使能和读写过程保持原有 RTL 语义。

实际映射使用一个 `RAMB18E1`：A 端口写入，B 端口同步读取，两个端口共用时钟，并采用 `READ_FIRST`。六位读写地址完整保留，五位有效列数由块 RAM 直接输出，未增加额外输出寄存器。同步复位清零输出寄存器，存储内容保持原值。

测试脚本检查实际原语端口、地址和输出连接，并对复位与读取使能的四种组合计算映射后的逻辑。正常读取关闭时，输出保持；复位时，读取端同步清零输出。

## 局部资源

测量固定 `SIZE=16`、`BUS_WIDTH=64`、`CACHE_BLOCKS=32`、`COMPACT_S8=1`、`EXTERNAL_RAM=1`，并启用生产 DMA 数据排列和共享写入寄存阶段。使用 `physical-cost`、`small-lut-area-cost=1`、6 输入 LUT、500 ps 连线成本和 6667 ps 映射目标。

| 资源 | 参考实现 | 当前实现 | 变化 |
|---|---:|---:|---:|
| 组合逻辑 LUT | 1496 | 1477 | −19 |
| 分布式 RAM LUT 位置 | 8 | 0 | −8 |
| 配对前 LUT 位置合计 | 1504 | 1477 | −27 |
| 触发器 | 482 | 477 | −5 |
| RAMB18E1 | 0 | 1 | +1 |
| 寄存器间最大组合级数 | 11 | 11 | 0 |

这些数值来自独立 IA 缓存模块的映射结果。完整 SoC 的物理 LUT 数量和组合级数由完整设计的最终测量结果给出。

python3 test/ia_extent_bram/run.py --out /tmp/npu_ia_extent_bram
