# IA 预取尾列计算检查

IA 加载器在接收配置时计算下一列分块的有效宽度。三个模宽加数先压缩成两项，再由分组加法器完成求和；尺寸为二的幂时，高位是否为零决定采用完整分块宽度或尾部宽度。

测试从 `ia_loader.sv` 提取实际计算语句，同时检查完整 `REG_WIDTH` 位剩余列数和最终尾列宽度。两个输入均不受约束，包含无符号边界及回绕情况。12 组参数覆盖 1、4、8、16、32、64 位，以及尺寸 1、2、3、4、16、64。

```bash
python3 test/ia_column_depth/run_formal.py --out /tmp/npu_ia_column
```

结果记录生产源码和公共加法器的 SHA-256，并保存每组证明脚本与日志。
