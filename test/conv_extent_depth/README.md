# 配置阶段的张量范围计算

张量大小与 DMA 地址范围复用八个配置准备相位。16 位部分乘积的分段和由独立寄存器保存，后续相位只合并已保存的进位。四个 DMA 末地址寄存器的低 24 位和高 9 位分别使能，段间进位独立保存。输入范围检查使用同样的分段计算。

| 相位 | 计算内容 |
|---|---|
| 0 | 部分乘积的分段和与进位 |
| 1 | 完整张量大小及块存储布局 |
| 2 | 地址范围低位、进位和维度检查 |
| 3 | 地址范围高位与越界检查 |
| 4 | 配置有效性 |
| 5 | 分块有效性 |
| 6 | 帧配置错误码 |
| 7 | 等待控制器和调度器就绪并提交配置 |

配置提交与数据运行周期保持。移位、截断和扩展地址位按原有位宽处理。

```sh
python3 test/conv_extent_depth/run_formal.py --out build/conv_extent/formal
python3 test/conv_extent_depth/run_npu.py \
  --out build/conv_extent/npu --verilator verilator-modern --jobs 1
```

形式检查直接提取实际相位计数器和赋值过程，在第 2 级入口保存任意部分乘积与配置字段，证明每个配置消费相位的张量大小、四个末地址及错误状态与完整参考算术相等。6 组参数覆盖 `SIZE=1/2/3/4/16/32`。复位首个采样周期后，复位、装载和两项就绪信号均可任意变化。

完整 NPU 回归同时检查配置消费和 DMA 初始化时的实际范围值，包含现有数值、复位、等待、部分和容量、量化与总线错误测试。

## 局部综合

相同生产参数和普通 RTL 映射下，完整配置范围计算从 14 级降至 8 级，逻辑 LUT 从 351 变为 355。进位与分段结果使用独立寄存器，各位段分别使能。测量包括全部张量大小、四个地址范围及有效性检查；完整 SoC 结果单独记录。详细数据见 [measurement.json](measurement.json)。
