# 预测器坐标与页范围组合路径

预测器的高位借位结果采用定宽恒等式 `A-B-1 = ~(B-A)`，其中两个操作数和结果均为 18 位。高、低部分仍独立计算，再由低位借位选择高位结果，所有寄存边沿和输出周期保持原样。

读取保护器使用二位加法的生成项和传播项计算页进位。相邻两组分别生成高、低部分的结果，再组合最终跨页条件。分组结果通过综合保留属性保持明确的计算边界，RTL 使用普通布尔表达式。

## 等价验证

坐标运算从实际源码提取，覆盖 130 个自由输入位及 174 位完整坐标和中间结果。完整预测器另外比较 1,952 位公开输出和对应状态。两个高位减法结果已包含在组合证明中，完整模块证明展开它们的共同算术输入。读取保护器比较七组地址宽度、数据宽度和拆页配置，共通过 5,562 个对应位。全部检查不限制输入取值。

```sh
python3 test/frontend_cost1_paths/predictor_formal.py \
  --reference 0df4e9fc4ceef8745d1f308f448aee64b32e5e90 \
  --out /tmp/frontend_cost1_predictor_formal

python3 test/conv_guard/run_control_formal.py \
  --reference-ref 0df4e9fc4ceef8745d1f308f448aee64b32e5e90 --fpga \
  --out /tmp/frontend_cost1_guard_formal
```

## 局部资源与路径

当前和参考版本使用相同公共 RTL 与工具配置。综合采用 xc7、普通算术映射、ABC9、最多六输入 LUT、LUT 面积成本 1、连线延迟 500 ps 和目标周期 6667 ps。读取保护器参数为 32 位地址、64 位数据、4 个在途事务并启用页拆分。

| 项目 | 参考版本 | 当前版本 |
|---|---:|---:|
| 预测器普通 LUT | 1,773 | 1,773 |
| 预测器 CARRY4 | 153 | 153 |
| 预测器 DSP48E1 | 13 | 13 |
| 预测器寄存器 | 1,129 | 1,129 |
| 预测器最长寄存器组合路径 | 14 | 14 |
| DSP 到坐标有效结果的最长组合路径 | 13 | 13 |
| 高半乘积输出到坐标有效结果的组合路径 | 12 | 11 |
| 读取保护器普通 LUT | 845 | 850 |
| 读取保护器 CARRY4 | 73 | 73 |
| 读取保护器寄存器 | 392 | 392 |
| 读取保护器最长寄存器组合路径 | 10 | 10 |

高半乘积路径从实际 DSP 的 `P` 输出开始计算；完整 DSP 路径还包含其内部寄存器之后的组合运算。局部预测器的最长坐标路径来自低半乘积。完整 SoC 使用独立的 DSP 资源分配和映射，其最长路径须由整机报告确定。
