# 输出写回地址共享与准备周期验证

## 当前设计

`oa_writer` 保存当前列的首地址 `column_base_addr`。该值始终等于行组首地址加列偏移，随列推进、组推进、配置载入和任务回绕更新。行内推进保留当前列首地址。

行、列和组的下一地址共用两项操作数。请求准备期间选择对应起点与步长，同时保存低字节的和值及进位；高位在下一周期使用同一组操作数完成求和。`S_WRITE` 消费准备完成的地址，分别更新块首地址、列首地址和行组首地址。地址加法保留全部 `REG_WIDTH` 位结果及原有模回绕语义。

既有 `S_IDLE`、`S_REQ`、`S_START`、`S_WRITE` 和 `S_DONE` 的转换条件保持不变。DMA 请求、输入就绪、完成脉冲、配置和复位优先级保持原有周期。

## 形式验证

`run_formal.py` 从实际 RTL 构建当前设计与提交 `2297cb12` 的比较模型，逐周期比较全部公开输出和 73 项内部观察信号。验证同时包含下列实际状态关系：

- 列首地址等于行组首地址加列偏移。
- WS 合并输出期间，当前块首地址等于当前列首地址。
- 保存的低字节及进位等于同拍保存操作数的低字节求和。
- `S_WRITE` 使用的地址起点与步长属于当前行、列或组推进分支。
- 请求准备周期中的索引、范围和后继控制保持有效。

11 组参数全部通过。覆盖 `VLEN=4/8/16/32`、32/64 位总线、4～32 位计数器，以及 4、8、9、32 位地址宽度。配置数值、握手和暂停输入均不施加范围限制。

## 实际模块协议比较

`run_equivalence.py` 同时实例化实际当前模块与参考模块，逐周期比较 21 项公开输出，包括无效周期输出。8 组参数共运行：

| 检查内容 | 数量 |
|---|---:|
| 配置场景 | 4,096 |
| 比较周期 | 4,178,136 |
| DMA 命令 | 128,375 |
| 合并输出组 | 19,793 |
| 任务完成 | 2,214 |
| 运行期间配置载入 | 1,429 |

测试覆盖 WS/IS、INT8/INT16、行列尾部、组推进、合并输出、握手暂停和连续任务。每组运行完成后保留可执行文件，并删除可重新生成的编译目录。

## 原生 RTL 综合

生产参数为 `VLEN=16`、`BUS_WIDTH=64`、`COUNT_WIDTH=29`、`REG_WIDTH=32`，完整公开接口保留。采用原生 Xilinx 算术映射，ABC9 的六种 LUT 输入宽度成本均为 1。

| 项目 | `2297cb12` | 当前设计 |
|---|---:|---:|
| 逻辑 LUT | 1397 | 1310 |
| FF | 851 | 940 |
| CARRY4 | 155 | 132 |
| DSP48E1 | 0 | 0 |
| 地址相关最长寄存器路径 | 12 | 8 |
| 完整模块最长寄存器路径 | 12 | 10 |

完整模块剩余的 10 级路径来自 `co_dma_rows/stride/len` 描述符选择、末尾索引生成及行组索引更新。该报告保存当前模块的完整结果，整机组合深度与 150 MHz 时序由集成后的器件报告确认。

## 运行

需要 Python 3、提供 `read_slang` 的 Yosys Python 包 `pyosys`、Verilator 和 C++ 编译器；相应工具应已加入当前环境。

```sh
python test/oa_writer_address/run_formal.py \
  --out /tmp/oa_writer_address/formal

python test/oa_writer_address/run_equivalence.py \
  --out /tmp/oa_writer_address/numeric --verilator verilator-modern

python test/oa_writer_address/measure.py \
  --out /tmp/oa_writer_address/mapping
```

各步骤顺序执行。`measurement.json` 保存正式结果、源码摘要、参数组合和主要路径；完整网表以 gzip 格式保存在测量目录。
