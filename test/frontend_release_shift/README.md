# 缓存接收寄存之后的行释放移位

`conv_im2col_frontend` 先计算行偏移加法及限幅条件，将被移位数和移位控制保存在已有的缓存接收寄存级中。`conv_windowed_cache` 在 `work_request` 和 `offer_retire_q` 之后完成变量右移，再使用完整的 32 位行释放位置更新需求和预取元数据。

`conv_read_cache` 与 `conv_windowed_cache` 的参数 `p_defer_retire_shift` 默认为零，默认输入继续表示完整的 32 位行释放位置。前端自身的策略 3 缓存实例启用该参数，采用以下字段格式：

| 元数据位 | 含义 |
|---|---|
| `[17:0]` | 18 位被移位数 |
| `[21:18]` | 右移量，范围 0 至 15 |
| `[22]` | 禁止释放标记，解码结果为 `32'hffff_ffff` |
| `[31:23]` | 保留位，前端写入零 |

限幅时，前端保存最后一个输出行号并将移位量置零。普通请求保存带偏移坐标及配置移位量。需求队列、预取队列、存储深度和所有公开端口宽度保持原值。接收寄存、请求出队及预取消费使用原有使能条件。

## 形式检查

```bash
python test/frontend_release_shift/run_formal.py --out build/frontend_release_shift_formal
```

默认参考提交为 `1df45da1`，可通过 `--reference-ref` 指定。13 项检查均通过：

- 实际前端编码与实际缓存解码共同参与 164 位自由输入、64 位输出的数值等价证明。生成时检查 18、4、1、9 位字段和 32 位总宽度，并证明前端写入的保留位为零。
- 在通用和实际 FPGA 分支中，分别使用需求队列深度 1、2、4、8，证明有效队列项、`work_request`、`offer_retire_q`、需求保存、命中写入和预取入队的数值关系，共 8 项状态归纳。
- 默认关闭参数下，四组完整缓存比较覆盖全部状态和公开输出，共证明 21,402 位等价。

状态检查展开实际缓存 RTL，以接收时解码的参考值作为影子状态，并随相同的队列写入、读取和工作项选择保存。队列位置关系、有效项、元数据解码值和消费结果共同通过无界归纳。复位、同时入队和出队、背压、预取取消及重新配置均由实际控制代码参与证明；子模块输出及无关数据判断作为自由输入。

脚本同时核对前端的配置准备寄存逻辑保持一致，并核对缓存所有存储声明和控制代码保持一致。源码摘要和每项结果保存在输出目录的 `summary.json`。

## 协议、数值和持续吞吐

```bash
python test/frontend_release_shift/run_protocol.py \
  --out build/frontend_release_shift_protocol --verilator verilator-modern
```

该入口复用完整 `test/window_dma` 回归，前后模型共用相同的当前缓存源码。参考前端使用默认元数据参数，当前前端启用寄存后移位。全部 FPGA 存储模型、协议检查和数值参考保持相同。

原有 15 类窗口场景包含读取错误、任务取消、配置等待、预取期间配置、普通读取并发及复位恢复。新增 64 组参数覆盖输出高度 1、3、8、17，步长 1、2、3、4，补边 0、3，以及通道数 3、16。步长 3 覆盖禁止释放的配置行为。

| 检查项目 | 结果 |
|---|---:|
| 新增参数组合 | 64 |
| 新增接收及完成请求 | 1,536 |
| 新增数值比较 | 12,967 |
| 新增逐周期记录 | 85,867，全部相同 |
| 连续命中场景 | 128 个请求、512 个返回拍、1,534 个周期 |
| 连续命中最大返回间隔 | 3 个周期，前后相同 |
| 最大在途请求数 | 4，前后相同 |

因此，本次拆分保持已测窗口协议的延迟、事务顺序和持续吞吐。

## 完整前端普通 RTL 测量

```bash
python test/frontend_release_shift/measure.py --out build/frontend_release_shift_measurement
```

测量使用生产前端内部 32 位 AXI 接口、16 列、4 个输出通道、128 个缓存集合、2 路、16 字节缓存行。两版源码共用全部其他依赖和综合选项。算术由普通 RTL 推断。

| 指标 | 修改前 | 修改后 |
|---|---:|---:|
| 完整前端逻辑 LUT | 12,528 | 12,698 |
| 分布式 RAM 的名义 LUT 位置 | 248 | 240 |
| FF | 6,044 | 6,046 |
| DSP | 43 | 43 |
| RAMB18 | 23 | 23 |
| 坐标及配置系数到缓存元数据保存 | 12 级 | 8 级 |
| 缓存元数据保存到消费存储 | 1 级 | 5 级 |
| 完整前端最长组合路径 | 15 级 | 15 级 |

两个行释放寄存阶段均不超过 9 级。完整前端仍有其他较长路径，整机继续按完整图检查。`measurement.json` 保存形式结果、协议统计、源码摘要及路径详情。实际 Slice LUT 数量和器件时序使用 Vivado 报告确认。
