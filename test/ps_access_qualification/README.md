# 部分和存储访问与容量计算

`ps_frame_store` 分别形成帧完成、下一帧准备和读取资格，容量错误状态在读取事件的末端参与判断。首行读取检查同拍最后一次写入与单行帧的地址冲突；持续读取检查队列余量、元数据清空和取消事件。

当解码队列深度为二的幂时，预取余量比较使用低段取反值。设深度为 `2^k`、已解码行数为 `a`、等待返回行数为 `b`，所需条件为 `a+b < 2^k-1`。两个计数的最高位均为零后，该条件等价于 `b[k-1:0] < ~a[k-1:0]`。其他队列深度使用完整求和比较。

请求首先从帧目录中选择剩余容量，再由两个比较器检查实际行数和预留行数。非法或未知帧编号保留逐项比较的四态选择语义。配置阶段将存储池行数与固定帧编号对应的负偏移共同压缩，末级使用一次高低半段并行求和。目录乘积需要截断回绕的参数配置保留定宽逐级计算。

容量错误置位将接受命令的错误资格和在途错误分别计算，接受脉冲只参与最终选择。已知控制状态使用并行资格，未知值或高阻值使用完整四态顺序表达式。端口、帧接收、RAM 访问、回放和完成事件的周期保持一致。

## FPGA 连接测量

测量连接保留 `ps_frame_store`、矩阵与向量端口选择以及七个 8192 字节共享存储块。帧存储参数为 256 行、16 帧、49152 字节部分和空间，使用固定通道布局。

| 指标 | 检查点实现 | 当前实现 |
| --- | ---: | ---: |
| 逻辑 LUT | 4358 | 4058 |
| 触发器 | 1003 | 1047 |
| DSP48E1 | 2 | 18 |
| RAMB36E1 | 26 | 26 |
| RAMB18E1 | 15 | 15 |
| 容量错误寄存器起点最长组合路径 | 11 级 | 9 级 |
| 全部寄存器起点最长组合路径 | 12 级 | 12 级 |

当前实现的目录间隔输入至可用行数寄存器为 8 级，帧接受输入至容量错误状态为 1 级。这两项按输入端口边界测量；整机路径还包括输入端口上游逻辑。

当前实现相对检查点减少 300 个逻辑 LUT。两份实现使用相同的普通 RTL 综合和物理成本 LUT 映射，目标周期为 6667 ps，连线估计为 300 ps。连接图完整，LUT 映射功能检查通过。150 MHz 的器件时序结果需在目标器件完成布局布线后检查。完整统计与源码摘要见 `measurement.json` 和 `validation.json`。
