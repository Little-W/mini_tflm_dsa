# 共享存储读写资格

部分和读取的地址范围、目标存储块和配置资格独立形成，读取请求在 `ia_ps_role_ram` 的端口使能处合并。`i_a_read_allowed` 表示端口 A 的读取地址及配置允许访问，默认值为一。

输入数据的两个端口先分别比较所属存储分段，再按第一端口优先的顺序选择访问资格。`ia_channel_segment_enable` 同时合并分段匹配、请求、碰撞及访问许可。未确定的控制信号采用完整四态地址选择表达式。

存储容量、地址端口、同拍并行操作、同步返回周期和保持行为均保持一致。

## 完整模块测量

比较提交 `d9f7f15a` 与当前实现，顶层为完整 `ia_ps_channel_ram`。参数包括七个 8192 字节物理块、两个 IA 端口、四个部分和通道、预先选择的 IA 写数据、非空写入资格和配对 IA 端口。映射采用 `physical-cost`、最大八输入查找结构、300 ps 连线估计及 6667 ps 目标周期。

| 项目 | 比较版本 | 当前实现 |
|---|---:|---:|
| 逻辑 LUT | 1148 | 1158 |
| LUTRAM / SRL | 0 / 0 | 0 / 0 |
| 触发器 | 10 | 10 |
| DSP48E1 | 0 | 0 |
| RAMB36E1 / RAMB18E1 | 34 / 0 | 34 / 0 |
| 完整模块内部最长组合路径 | 10 | 8 |
| 部分和读取请求到共享 RAM `ENARDEN` | 4 | 1 |
| IA 写入请求到共享 RAM `ENARDEN` / `WEA` | 9 / 9 | 6 / 6 |
| IA 读取请求到共享 RAM `ENBWREN` | 5 | 3 |

路径统计根据实际映射后连接图计算。部分和读取请求参与同址读写碰撞检查，因此它到其他物理端口的路径单独保存在测量报告中。

## 验证范围

五种参数配置分别使用通用及 FPGA 编译方式，覆盖 2048 和 8192 字节物理块、六至九个存储块、普通及配对 IA 端口、写数据预选和两种返回保持设置。

完整命令证明在首次采样复位后允许全部功能输入和复位自由变化。每个 RAM 的实际读取使能、写入使能、地址、写数据及掩码逐位比较。部分和端口的读取请求与读取资格共同形成实际读取使能。各存储块的返回数据分别自由变化，并检查所有公开返回、容量故障、配置状态和返回选择状态。

真实数组测试每种配置运行 8192 个周期，两种编译方式共 81920 个周期。全部物理存储字和所有公开输出在每个周期比较，包含未使能时的保持、配置切换、暂停、复位、部分掩码、同拍独立访问、越界、碰撞及 X/Z 输入。

## 重新运行

```sh
python3 test/shared_read_write_qualification/run.py --out build/shared_read_write_qualification/validation
python3 test/shared_read_write_qualification/run_measurement.py --out build/shared_read_write_qualification/measurement
```

`validation.json` 保存十项完整命令证明、真实数组检查以及对应源码和日志摘要。`measurement.json` 保存完整模块的成对资源统计、指定端口路径级数和网表摘要。
