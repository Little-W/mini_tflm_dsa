# IA 分通道加法验证

`select_add` 的 `p_split_12bit` 参数在 48 位接口上提供四个独立的 12 位模加通道。通道内进位和未知位相互隔离，普通定宽 RTL 算术由综合工具映射。

紧凑写入将四个输入字节零扩展到 12 位，计算后取低八位。紧凑读取将有符号字节和偏移符号扩展到 12 位，再把结果按所需位宽符号扩展到阵列输入。生产配置使用九位偏移，完整求和结果为十位。

```sh
python test/ia_packed_add/run.py --out build/ia_packed_add
```

六项完整输入空间证明覆盖八位和十二位独立加法、一位到十一位有符号偏移恢复，并检查通道填充位。四态仿真覆盖 100,002 组输入，其中包含进位边界、符号边界、独立通道的未知位和高阻位。
