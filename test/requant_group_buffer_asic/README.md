# 量化行缓冲的 ASIC 存储结构检查

`requant_group_buffer` 的 ASIC 分支将整行数据和完成标志共同保存到 `smic40_sram_1r1w`。宏深度固定为 128，按行数扩展 bank、按位宽扩展 16 位通道；写地址、读地址和读取周期保持一致。

对于 `p_lanes=16`、`p_rows=512`：

| 项目 | 检查结果 |
| --- | ---: |
| 逻辑行宽 | 513 bit |
| 逻辑存储容量 | 262,656 bit |
| bank 数量 | 4 |
| 每个 bank 的宏数量 | 33 |
| `RAMTP128X16` 总数 | 132 |
| 物理存储容量 | 270,336 bit，33 KiB |
| 填充容量 | 7,680 bit，960 byte |
| ASIC 分支推断存储 | 0 |
| 优化展开后的控制触发器 | 41 |

每行的 16 个 32 位数据和 1 位完成标志全部进入 SRAM。各 bank 最后一个宏只使用数据位 0，其余 15 位写数据为零、低有效写使能为一。

## 检查内容

脚本同时展开实际 `ASIC_SRAM` 分支和 `XILINX_FPGA` 分支。ASIC 检查采用项目中的 SRAM 接口黑盒，逐个核对宏类型、数量、端口位宽、时钟、模式输入、行地址和所有写数据及掩码位。

读取检查把每个 SRAM 输出位视为独立符号，对每一个有效 bank 验证全部 513 位输出对应关系。读写 bank 独立遍历，核对两种使能状态下的每一个宏选择信号。`read_bank` 的正边沿寄存器只在读取使能有效时更新，地址取自原有行地址的高位。控制触发器总数受地址、计数和 bank 选择位宽限制，ASIC 分支不得保留推断存储或 `regfile` 子实例。

FPGA 分支检查一个同步读写存储器，默认宽度 513、深度 512。读使能、写使能和时钟与缓冲控制相连，同址读写保留写入前的数据。

13 组参数分别执行 ASIC 与 FPGA 展开，共 26 项检查通过。覆盖 `p_lanes=1/3/16` 和 `p_rows=1/15/16/17/127/128/129/511/512/513/1024/2048/2049`，包含单行、非二次幂深度及跨 bank 边界。

该检查统计结构和完整数据位连接。事务周期、输出保持与合法事务的同址互斥由 `test/requant_group_buffer_memory/` 的功能比较和时序归纳检查。

## 复现

```sh
python3 test/requant_group_buffer_asic/check_structure.py \
  --out build/requant_group_buffer_asic
```

`--source-root` 可指定另一工作目录；`--profiles` 接收 `通道数:行数`。输入快照、逐项日志和压缩网表保存于输出目录，完整记录见 [measurement.json](measurement.json)。
