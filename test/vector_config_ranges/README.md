# 激活范围与向量配置检查

`vector_config_check` 使用符号扩展一致性检查两个激活端点是否可由 INT8 表示，再比较低八位的有符号次序。该检查用于图像操作和 Add 的配置接收，保持公开输出及各阶段的周期关系。

## 运行

```sh
python3 test/vector_config_ranges/run.py --out build/vector_config_ranges
```

默认参考提交为 `4dee27ffec4dc891daf2681379f8b3fd27fd41f2`，可通过 `--reference` 指定其他 Git 提交。程序读取实际 RTL，保存参与验证的源文件和 SHA-256，并在验证结束时核对当前文件。

验证包括四项形式化证明：

1. 对两个 32 位端点的全部输入组合，证明范围表达式的等价性。
2. 对 `TILE=4` 的完整配置检查器，证明公开输出和共同寄存状态逐周期等价。
3. 对 `TILE=16` 执行相同检查。
4. 对 `TILE=64` 执行相同检查。

完整模块检查执行组合等价证明和时序归纳，并要求所有比较点均完成证明。结果保存为输出目录中的 `summary.json`，各项证明的脚本和日志保存在同一目录。
