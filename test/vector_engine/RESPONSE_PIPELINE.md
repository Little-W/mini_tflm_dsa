# 向量响应寄存与标量乘法器

## 当前结构

引擎在接口处同时保存 DMA 读写完成事件及其错误位，内部状态更新、结果槽位释放和写回处理使用对应的寄存事件。读数据仍按有效拍接收；最后一个数据拍在完成事件被消费前写入目标存储。排空条件包含尚未消费的读完成事件。

任务初始化在现有 CHECK 状态统一清除输入就绪、预留信息、权重暂存和深度卷积结果状态。`dma_cfg_valid`、`rd_req`、`ready`、`done_valid` 与状态寄存器共同更新，输出值在整个周期内保持稳定。窗口末拍同时保存元素数量检查结果，内部控制使用已保存的检查结果。

标量乘法器把两个符号扩展的交叉部分积相加，再与高低部分积组合相加。FPGA 分支用两个普通 RTL 加法表达式及 `use_dsp` 属性表达运算；通用分支保留分组进位实现。完整输出为 64 位有符号乘积，A、B 输入寄存和统一使能参数保持独立。默认配置经过两个有效时钟边沿得到结果，持续使能时每周期接收一组操作数。

## 验证结果

| 检查 | 结果 |
|---|---:|
| 生产配置功能用例 | 615 项通过 |
| 独立数值比较 | 170,668 次通过 |
| 窗口末拍错误及恢复 | 32 项，其中 16 次错误注入、16 次恢复任务 |
| 乘法器全部参数组合时序等价 | 8 种配置通过 |
| 乘法器四态输入 | 23,091 组样本、184,728 次比较通过 |
| 乘法器独立整数参考比较 | 1,134,340 次通过 |

生产配置采用 TILE=16、8 PE、64 位总线、8 路窗口、独立量化，7 个共享存储银行，每个银行 8,192 字节，其中 2 个用于输入数据。功能测试开启权重地址与内容检查、暂停保持检查和 RTL 断言。错误测试覆盖输出排队、量化在途、总线等待、地址偏移、结束后静默和后续任务完整结果。

读写完成响应增加一个接口寄存周期。数据拍的接受和写回总线连续传输能力保持原有形式。乘法器有效周期数和启动间隔保持不变。

## 独立综合结果

完整向量实例映射得到 12,838 个逻辑 LUT、12,894 个包含分布式存储的名义 LUT、6,685 个触发器、52 个 DSP 和 9 个 RAMB18。完整连接图包含 33,376 个节点，寄存器间最长组合路径为 10 级。目标时钟周期为 6.666667 ns；频率结果由器件延迟及布线时序分析给出。
