# 无符号和值上限检查

`unsigned_sum_le` 计算两个无符号数的完整和值是否不超过给定上限。三个输入先通过逐位和与进位表示 `a+b+~limit`，随后以三位为一组并行计算最高进位。计算保留完整溢出信息；存在未知位时使用扩展一位的加法和关系比较，保持 SystemVerilog 的四态传播。

任务配置模块用该计算检查卷积通道区间。模块的配置接收周期、状态更新周期和公开接口均保持一致。

## 验证

- 16 组参数覆盖 1、2、4、7、8、16、17、32 位操作数以及三位、四位分组，形式检查不限制外部输入。
- 524,288 次四态比较覆盖随机值、范围边界、溢出和逐位 X/Z 输入。
- 完整任务配置模块在通用编译方式下通过 3,015 个状态和输出比较，在 FPGA 编译方式下通过 3,027 个状态和输出比较。

```bash
python3 test/unsigned_sum_le/run.py --out /tmp/unsigned_sum_le
python3 test/unsigned_sum_le/run_parent.py --out /tmp/unsigned_sum_le_parent
```

## 组合路径

采用普通 RTL 推断和 ABC9 物理成本映射，16 位独立检查需要 32 个逻辑 LUT，输入寄存器到结果寄存器为 5 级。完整任务配置模块中的卷积配置输入到检查结果寄存器为 8 级。该模块其他独立计算仍有更长路径，完整 SoC 的路径统计单独保存。

映射清单、资源数量和路径统计见 `measurement.json`；形式检查及四态比较结果见 `validation.json`。
