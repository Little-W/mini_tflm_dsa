# 向量 PE 的第二乘数选择

无效通道的第一乘数和累加输入为零，第二乘数直接选择权重或右操作数。统一 `vector_pe` 在接收边沿保存操作码和输入，全部八种操作在这组无效通道输入下的数值结果为零。

## 形式检查

`run_formal.py` 复用实际向量接入检查，覆盖 `TILE/PE_COUNT` 为 `1/1`、`3/2`、`16/8` 和 `32/16` 的配置。检查比较全部 PE 的第一乘数、第二乘数、累加值、操作码寄存状态和完整结果，并检查深度卷积的反馈选择。

额外的算术证明遍历两种通道有效性，操作码保持为不受限制的三位输入，因此覆盖八种操作与两种有效性的 16 种组合。第一个周期使能输入建立有效状态，后续周期允许任意使能和数据。

```bash
python3 test/vector_pe_b_select/run_formal.py --out build/vector_pe_b_select
```

已经完成接入证明时，可以通过 `--engine-summary` 指定其 `summary.json`。入口会核对 RTL、测试脚本与参考版本，并继续执行第二乘数选择检查。
