# 偏置与帧完成的输入发送控制

输入发送控制并行准备数据、部分和、计算状态、输出空间和偏置地址条件。权重驻留与输入驻留的通道地址分别完成分组比较，比较分组、数据流资格及输入准备条件共同形成发送候选。无需读取偏置的情况使用独立候选。三个候选与帧模式、帧内完成状态及直接执行的输出完成状态在末级组合选择中合并。

`npu_controller.p_external_ia_issue` 的默认值为零，保留控制器的独立使用方式。矩阵引擎启用该参数，并将实际组合资格送回控制器；状态机中的偏置和资源检查继续使用原有条件。配置输入可以在任意周期变化，验证不依赖运行期间配置保持不变。

部分和存储通过 `frame_accept_permit` 接收当前执行模式的限制，默认值为一。状态更新统一使用 `frame_accept && frame_accept_permit`。读取控制提前准备请求状态和接受资格，原始接受脉冲在末级参与读取选择。全部状态和存储更新保持原有周期。

## 结构与综合

`measure.py` 连接实际控制器、矩阵引擎的帧完成与量化条件、输出容量条件、部分和读取选择，以及生产参数的 `ia_ps_channel_ram`。全部外部输入和输出均经过测量寄存器，路径延伸至真实推断存储的同步控制端口。

参考提交为 `8009b2f7`。

| 项目 | 参考设计 | 当前设计 |
| --- | ---: | ---: |
| 逻辑 LUT | 1,330 | 1,341 |
| 触发器 | 2,256 | 2,256 |
| 推断 RAMB36 | 34 | 34 |
| 推断 DSP | 0 | 0 |
| 完整连接最长组合路径 | 14 级 | 10 级 |
| 偏置基址及两种通道来源 | 14 级 | 9 级 |
| 帧完成来源 | 11 级 | 9 级 |
| 模式及帧位置来源 | 11 级 | 10 级 |

四个新增模块均为普通可综合 RTL：`npu_bias_channel_match` 检查通道模加关系，`npu_bias_issue_reduce` 合并比较分组与发送资格，`npu_bias_issue_optional` 准备无需地址检查的发送条件，`npu_bias_issue_select` 完成最终选择。组合层次用于保持独立候选及末级选择，代码不实例化 LUT、BRAM 或 DSP 原语。

组合级数按完整映射网表的连接关系统计。150 MHz 的单元延迟和连线延迟由目标器件的 Vivado 整机报告确定。

## 功能验证

`run.py --section control` 比较完整控制器的全部公开输出与真实内部寄存器。检查包含默认发送方式与外部资格方式，`REG_WIDTH` 为 8、16、28、29、32、64，并覆盖通用 RTL 与 FPGA 条件编译，共 24 个配置。组合中间信号不作为内部状态对应条件。

`run.py --section combinational` 检查偏置地址零值、偏置需求和完整发送资格。地址位宽为 1、2、3、8、16、28、29、32、40、64。形式检查允许全部输入任意取值；四态仿真覆盖地址回绕、两种数据流、模式选择、未知地址及未知完成条件，两个条件编译模式共完成 1,338,880 项比较。

`run_binding.py` 核对矩阵引擎的实际端口及参数连接，并检查其余功能表达式保持一致。帧内未完成条件与原完成表达式的互补关系通过形式验证和全部 4,194,304 项四态组合检查。

`run_ps.py` 比较部分和帧存储的公开输出、内部状态和全部存储内容，覆盖生产、紧凑、内部存储、轮转存储及非二幂帧数配置。实际缓冲器连接与帧存储的其余功能表达式同时检查。读取选择的七项输入穷举全部四态组合，两个条件编译模式共完成 32,768 项比较。

生产与紧凑配置的四项检查采用完整时序等价证明。内部存储、轮转存储及非二幂帧数配置的六项检查采用真实状态的一步归纳证明：先将两侧全部寄存器和存储位一一对应，再令当前状态任意取值，比较全部数据、时钟、复位、使能输入和公开输出。寄存器类型、控制极性、逐位复位值及初始值同时检查。该关系在任意相同当前状态下成立，因此保持后续每个周期的状态和输出一致。复现脚本统一提供这一完整状态转移检查。

全部检查共包括 24 个控制器形式配置、20 个偏置形式配置、1 项帧完成关系、2 项读取选择关系和 10 个部分和完整状态配置；四态比较合计 5,565,952 项。四态输入位宽由明确声明或 Python 参数计算。

上述控制修改不增加寄存器或流水周期。`validation.json` 记录实际通过的配置、源码摘要及检查日志摘要，`measurement.json` 保存完整连接的资源和路径结果。

## 复现命令

```bash
python test/bias_frame_issue/run.py --section control --out /tmp/bias_issue_controller
python test/bias_frame_issue/run.py --section combinational --out /tmp/bias_issue_combinational
python test/bias_frame_issue/run_binding.py --out /tmp/bias_issue_binding
python test/bias_frame_issue/run_ps.py --out /tmp/bias_issue_ps --jobs 2
python test/bias_frame_issue/measure.py --out /tmp/bias_issue_measurement
```

依赖包括带 Slang 的 Yosys、Icarus Verilog，以及仓库的综合和路径统计脚本。源码摘要在验证结束时再次检查，确保结果对应同一组 RTL 文件。
