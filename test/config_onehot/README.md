# 配置幂次检查

`onehot_check` 判断输入是否只有一位置位；`p_allow_zero=1` 时同时接受零。`p_width` 为正整数，检查结果是组合输出。

输入按五位分组，每组分别计算非零标志和至少两位置位标志，再用三叉树合并结果。模块使用命名生成块、明确位宽及普通布尔表达式，各编译配置的功能一致。

## 验证

13 种位宽为 1、2、5、6、8、16、17、31、32、33、64、65、128。每种位宽分别检查是否接受零，并在通用和 FPGA 编译配置下证明全部输入，共 52 项 SAT。参考表达式为输入与其减一结果的按位与，同时显式处理零值。

```bash
python3 test/config_onehot/run.py --out build/config_onehot
```

添加 `--synthesize` 可对 32 位参考表达式与当前实现运行相同设置的独立综合。四态行为由 [公共算术检查](../resource_neutral_arithmetic/README.md) 验证。
