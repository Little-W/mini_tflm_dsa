# VCE 共享 IA/PS 存储测试

`vector_shared_store` 将 VCE 的权重请求接到现有 IA 端口零，将完整的 512 位部分和行接到四个 PS 端口。模块只保存配置、错误和读取有效状态，读取数据直接来自物理 RAM 的同步输出。

## 接口与时序

权重地址以 128 位字为单位，写掩码的每一位选择一个字节。PS 地址以 512 位行为单位，每次写入完整的 16 个 INT32 元素。读请求和写请求均在上升沿采样，接口没有背压。一次有效读取在采样沿之后给出 `o_weight_read_valid` 或 `o_ps_read_valid`，并返回对应数据；连续请求可连续返回。有效信号持续一个周期。在配置和端口所有权保持不变时，数据保持到相应空间的下一次读取。

| 周期 | 调用方请求 | 时钟沿后的结果 |
| --- | --- | --- |
| 0 | `i_cfg_valid=1`，提供 IA 存储块数量 | 保存分配，全部物理访问被抑制 |
| 1 | 写权重或完整 PS 行 | 数据写入物理 RAM |
| 2 | 读取已写入的地址 | 同步读取数据和有效信号同时返回 |
| 3 | 无读取 | 返回有效信号清零，RAM 输出保持 |

调用方可以在读取返回后暂缓发出下一次读取，直接使用保持的 RAM 输出等待量化模块接受。矩阵任务和 VCE 任务在顶层选择物理端口所有者，配置必须在访问前完成。

## 地址映射

配置允许 1、2 或 4 个 IA 存储块，并且至少保留 4 个 PS 存储块。权重地址必须小于 `IA 存储块数 × p_bank_bytes / 16`。VCE 的 PS 行号必须小于 `p_bank_bytes / 16`。

| 存储模式 | PS 端口 `c` 的物理接口地址 |
| --- | --- |
| 固定通道，`p_fixed_ps_channels=1` | `row` |
| 轮转映射，`p_fixed_ps_channels=0` | `c × (p_bank_bytes / 16) + row` |

固定通道模式由 `ia_ps_channel_ram` 将四个同地址端口分配到独立存储段。轮转映射模式使用分配给 PS 的前四个物理存储块。两种模式均复用现有容量。`o_ia_shared_write_data` 与权重写入数据一致，用于连接 `p_shared_write_stage` 的共享写数据端口。

## 错误与恢复

同一空间中，同地址的有效读写请求不能同时发出。发生同地址冲突或地址越界时，适配器拒绝该空间本周期的读写，置位 `o_error`。另一个空间的合法请求仍可完成；之后的请求由错误状态阻止。权重写掩码为零时，该写请求不占用物理端口。

合法的 `i_cfg_valid` 清除本地错误并设置新分配。`i_flush` 取消读取有效状态、清除本地错误并使配置失效，因此恢复访问前需要重新配置。禁用期间不提交请求。物理 RAM 的 `capacity_fault` 由顶层独立汇总。

## 运行

```bash
python3 test/vector_shared_store/run.py --out build/vector_shared_store
```

可以通过 `--verilator` 指定可执行文件，通过 `--profiles` 指定测试组合。每个组合格式为 `bank_bytes:banks:fixed_ps_channels:shared_write_stage`。例如：

```bash
python3 test/vector_shared_store/run.py \
  --out build/vector_shared_store \
  --profiles 2048:7:0:1 2048:7:1:1 2048:8:1:1
```

默认组合覆盖 2 KiB、4 KiB、8 KiB 存储块，6 至 9 个物理存储块，两种 PS 地址映射，以及共享写数据通路。每个组合依次使用全部合法 IA 分配，验证完整地址范围、随机字节掩码、AXI32/AXI64 对应的写入分段、连续读取、不同地址读写并行、数据保持、配置切换、错误恢复和复位。

测试参考模型按物理存储块编号和块内地址保存数据。测试还让另一个任务通过原有 RAM 端口写入数据，再由 VCE 读取，检查两者共享同一存储内容。运行记录包含源文件 SHA-256、编译命令、仿真器版本、执行文件 SHA-256 和各项检查数量，保存在输出目录的 `summary.json`。
