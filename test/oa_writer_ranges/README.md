# 输出写回范围比较

`oa_writer` 在已有请求准备周期中保存行、列及复用分组的范围结果。`oa_writer_compare` 使用分段无符号比较计算这些结果，保留原来的比较位宽、严格小于关系和减法借位的四态传播。计数器、地址寄存器、DMA 请求和传输周期保持一致。

五个比较分别检查下一行与全部行、下一行与当前分组边界、下一列与全部列、下一分组与全部行，以及合并写回的下一列字节偏移与输出宽度。普通 RTL 的两个独立差值由综合工具推断算术资源。

## 验证

`run.py` 使用完整写回模块，通用模式显式取消 `SYNTHESIS` 和 `XILINX_FPGA`，FPGA 模式显式定义两者。参考提交为 `016d9854cf0524b04e7a59f6df13a47b630e686b`。

- 七组参数分别在两种编译模式下证明全部公开输出和共同状态逐周期等价，共通过 14 项证明、31,627 个比较位。外部输入和握手不受限制。
- 三组参数分别在两种模式下进行四态仿真，共检查 154,170 个时钟周期、308,334 次完整输出比较，覆盖未知配置、数据未知位、配置重载及接收暂停。
- 完整生产参数分别在两种模式下运行 256 个事务场景。每种模式均完成 147,833 个周期，发出 4,636 条 DMA 命令，其中包含 927 次合并分组启动、119 次任务完成和 101 次传输期间配置重载。
- 模块头及端口中文注释检查通过。

## 完整模块测量

参数为 `VLEN=16`、`BUS_WIDTH=64`、`COUNT_WIDTH=29`、`REG_WIDTH=32`。两份设计采用相同的 `physical-cost` 映射，最大 LUT 输入数为 8，延迟目标为 6,667 ps，连线代价为 300 ps。

| 指标 | 参考实现 | 当前实现 | 变化 |
|---|---:|---:|---:|
| 名义 LUT 数量 | 1,254 | 1,132 | −122 |
| 触发器数量 | 929 | 929 | 0 |
| 自动推断的 DSP 数量 | 4 | 9 | +5 |
| RAMB36 / RAMB18 数量 | 0 / 0 | 0 / 0 | 0 |
| 最长寄存器间组合路径级数 | 10 | 10 | 0 |

资源和路径数据属于完整模块的布局前映射结果。`measurement.json` 保存参数、资源、路径和网表摘要；`validation.json` 保存验证结果与源文件摘要。完整 SoC 的资源及连接路径由整机报告提供。

## 复现

```bash
python3 test/oa_writer_ranges/run.py --out build/oa_writer_ranges/verification
python3 test/oa_writer_ranges/measure.py --out build/oa_writer_ranges/measurement
```

运行环境需要配置 PyYosys、Slang、Icarus Verilog 和 Verilator。
