# 请求索引移位控制验证

`conv_im2col_request_index` 在直接描述符模式中，用短像素模式生成有效右移位数。完整像素模式的移位数为零，两个完整索引共用相同的移位控制。输入控制含有未知值时，保留条件选择的逐位四态合并结果。

## 功能检查

`run.py` 从提交 `8b3728c008e6093095c8ade34aa4516145bc6005` 提取完整参照模块，与当前模块进行无输入约束的组合等价证明。覆盖坐标宽度 16、35、48，直接或寄存描述符模式，以及是否定义 `SYNTHESIS`，共 12 组检查。

四态仿真直接提取当前源文件和参照源文件中的索引变换表达式，比较两路完整 32 位结果。8192 组输入覆盖所有 70 个输入位的 `X` 和 `Z`，并包括零值、全一值、零移位和最大移位。

运行命令：

```sh
python3 test/frontend_index_shift/run.py --out build/frontend_index_shift --measure
```

需要可用的 `pyosys`、`read_slang`、`iverilog` 和 `vvp`。综合使用仓库的 `scripts/fpga/open_fpga_synth.py`，按普通 RTL 推断结构。

## 综合结果

测量使用三十五位坐标、直接描述符模式，全部真实输入和输出均连接寄存器。两组测量使用相同包装模块和工具设置。

| 项目 | 参照版本 | 当前版本 |
| --- | ---: | ---: |
| 逻辑 LUT | 809 | 761 |
| 触发器 | 989 | 989 |
| DSP | 0 | 0 |
| 寄存器之间最长组合单元数 | 8 | 8 |

`measurement.json` 保存检查配置、源码摘要和测量结果。组合单元数量用于结构分析；器件频率仍需使用目标器件的布局布线时序报告确认。
