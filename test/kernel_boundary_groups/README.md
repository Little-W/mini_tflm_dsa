# 权重加载器的分组边界比较

权重加载器使用相邻两位的进位关系比较下一个分组序号与总分组数，每六个比较结果独立归并。相邻相等检查保留组合模块边界，完成资格继续包含无符号大小比较和最大计数回绕条件。

未来分组选择与当前分组完成检查共享相同的定宽数学关系。未知输入通过完整加法比较表达式处理；状态更新、地址输出和请求事件均保持原有周期。

## 验证

4 种分块尺寸与计数位宽分别运行通用和 FPGA 配置，共 8 项完整控制器状态等价证明。外部输入未附加限制，公开输出与全部共有状态逐周期一致。

14 项任意输入算术证明覆盖 1、2、4、16、29、32、64 位计数及两种配置；114,688 次严格四态比较覆盖相邻边界、回绕、零和 X/Z 输入。
