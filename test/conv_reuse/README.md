# 卷积窗口复用与实际外部读取核验

```bash
python test/conv_reuse/run.py
```

本测试直接编译 `rtl/npu/conv/` 的生产 RTL。判断是否多读使用实际 AXI `ARVALID && ARREADY` 次数，以及 `RVALID && RREADY` 对应的每个有效字节地址；缓存 hit/miss 统计没有被用作通过条件。日志保留每次 AR 和每个被读取字节的累计次数。运行时生成测试数据，工具版本写入当次报告；所有输出位于 `build/conv_reuse/`。

## 真实前端测试

测试使用 SIZE=4、2 sets、2 ways、16 字节行，直接按卷积数学公式核对每个 IA 输出，同时记录输入总线流量。

| 阶段 | 实际输入读取字节 | 实际 AR 接受次数 | 核验内容 |
|---|---:|---:|---|
| 3×3 输入上的首批重叠 3×3 窗口 | 9 | 2 | 9 个输入字节各读一次 |
| 再次提交完全相同的 tile | 0 | 0 | 驻留数据复用 |
| 提交新的重叠窗口 tile | 0 | 0 | 新窗口复用已读数据 |
| 同地址、内容改变、新任务 | 9 | 2 | 失效后重新读取，输出匹配新内容 |
| 旁路模式首次读取一个末尾部分 word | 3 | 3 | 3 个有效字节用窄读取得 |
| 旁路模式下另一 tile 使用相同 word | 0 | 0 | 前端 word buffer 跨 tile 保留 |
| 旁路模式先换 word 再回访 | 4 | 4 | 仅一个保持寄存器时，回访需要重读 |
| 全部为 padding 的 tile | 0 | 0 | 校正后的零直接生成 |

合计 8 个 tile、25 个实际输入读取字节、11 次 AR 接受。总数包含多个任务和主动旁路阶段；驻留复用阶段单独断言为 0 字节、0 次 AR。初次读取逐字节断言最大次数为 1；新任务重新读取后逐字节次数为 2。最终累计地址次数也逐项核验，结果见 `build/conv_reuse/frontend.log` 和 `build/conv_reuse/status.json`。

## 直接缓存测试

同样使用生产 `conv_read_cache`，配置 2 sets、2 ways、16 字节行，以少量地址构造可解释的冲突。

| 阶段 | 新增外部字节 | 新增 AR |
|---|---:|---:|
| 冷读 A，行首被输入分配区间裁剪 | 13 | 2 |
| A 的同 word、其他 3 个 word | 各 0 | 各 0 |
| 同 set 的 B | 16 | 1 |
| 再访问 A，使其成为最近访问的一路 | 0 | 0 |
| 同 set 的 C，逐出 B | 16 | 1 |
| A 仍然驻留 | 0 | 0 |
| 回访已经逐出的 B | 16 | 1 |
| 末尾缓存行，被分配结束地址裁剪 | 13 | 2 |
| 同地址新任务，内容改变 | 13 | 2 |

共 12 个逻辑请求、87 个实际读取字节、9 次 AR 接受。强制 AR 停顿 7 周期，并在每个 cache response 上保持反压 9 周期，确认不会重复发起读取，返回数据也保持稳定。初次冷行 13 个字节各读一次；最终所有分配内字节的次数均按上述访问序列逐项检查。

## 可保证的行为

- 同一任务内，前端保持寄存器命中相同 32 位 word 时不发送缓存请求，因而不增加外部读取。该寄存器跨 tile 保留。
- 缓存行有效且标签命中时，缓存只访问本地 RAM，不进入填充状态，不产生 AR。上述同 word、同 line 的不同 word、重复 tile 和重叠窗口均直接检查这一点。
- 缓存是阻塞式结构，填充和响应完成前不接收另一请求。一次填充完成后的同 line 请求成为命中；当前设计没有多个并行 miss 的合并队列。
- 每次 line fill 只读取“缓存行与整个输入张量分配区间的交集”。首尾窄读和边界裁剪避免读取分配之外的字节。
- padding 和归约尾部直接生成校正后的零，不产生输入读取。
- 新任务配置失效全部标签和前端 word buffer；同地址输入内容变化后必须重新读取。

## 不能据此宣称的行为

当前结构不能保证完整卷积中每个输入字节总共只读一次。容量或 set 冲突导致逐出后，会重新填充；主动旁路只保留最后一个 word，跨 word 回访也会重读。缓存行填充还可能预取本次窗口暂不需要的字节。

分组卷积按完整 NHWC 输入分配范围裁剪缓存行，行中可以包含当前 group 不使用的通道；这是实际读取流量，需要在整层统计中体现。当前 NMSIS 分发为每个 batch/group 单独启动任务，因此不承诺跨 batch/group 保留缓存。默认分发使用行缓存，旁路由配置选择，尚无自动稀疏访问选择策略。

本次核验未发现命中、AR 等待或返回等待导致的非预期重复读取。以上限制属于当前容量、替换、任务失效和填充策略的行为；整层流量仍应结合真实 NPU 地址轨迹评估。

## IA tile RAM 与原始输入缓存的容量和用途

`rtl/npu/loaders/ia_loader_cache_mgr.sv` 使用 SIZE 个独立的 RAM bank；每个 bank 的地址宽度为 `ceil(log2(CACHE_BLOCKS * SIZE))`。`rtl/common/pseudo_dual_port_ram.v` 的实际数组深度为地址宽度对应的 2 的幂。因此数据数组容量为：

```text
SIZE * 2^ceil(log2(CACHE_BLOCKS * SIZE)) * DATA_WIDTH / 8 字节
```

默认 `CACHE_BLOCKS=4`、`DATA_WIDTH=16` 时：

| SIZE | 一个 IA slot | 四个 IA slots | 默认原始输入缓存数据 |
|---|---:|---:|---:|
| 4 | 32 B | 128 B | 1024 B |
| 8 | 128 B | 512 B | 1024 B |
| 16 | 512 B | 2048 B | 1024 B |

这些是 RTL 数组的数据位容量，不是 FPGA BRAM 宏的实际占用。当前默认原始输入缓存为 32 sets、2 ways、16 B 行：另外有 184 B 标签、8 B valid、4 B LRU，合计 196 B 基础元数据。几何替换还声明每行 32 bit next-use 和一个 16 B transient buffer；完整逻辑存储分项可运行 `test/conv_replacement/cost/audit.py` 查看，不含物理宏取整。运行时切换 s8/s16 数据格式不会改变 IA RAM 的编译期宽度。公式中的深度取整也不代表支持任意非 2 的幂 slot 数量：现有 slot 指针用二进制自然回绕，不能仅修改参数就宣称这种配置正确。

IA RAM 保存已经展开、加入 input offset 的 s16 矩阵 tile，按列分 bank，以对角节拍向阵列供数。`ia_reuse_num` 指一组保留的行 tile 数；这些 tile 再按 `w_reuse_num` 对应的输出列 tile 循环发送。它不是按原始输入地址标记的窗口缓存。原始输入缓存保存尚未展开的 s8 字节，以输入地址 tag 查找，供不同卷积窗口共享。

默认 R=2 时，四个 slots 可分别容纳当前组两个 tile 和预取组两个 tile。最后一次发送后释放的 slot 可能立即被下一次预取占用。即使某个 slot 暂时空闲，同一 bank 的读口仍由阵列发送路径使用，写口仍由 tile 填充路径使用；空闲地址不会增加 RAM 端口。共用存储需要新增所有权、端口仲裁和 tag 失效机制，或改变 bank 结构，并评估对阵列持续供数的影响。直接将已展开 IA 数据当作原始输入缓存还需要原始地址到 tile 元素的映射、padding 区分和 slot 生命周期管理。

因此不能仅凭 IA 中出现空 slot 就删除原始输入缓存，也不能据此证明某个固定容量最优。减小缓存 sets 或选择旁路的效果，应通过真实整层轨迹比较外部字节、重复读取和总周期；上述小型测试只证明驻留命中的零流量行为与明确的逐出后重读行为。

关于直接读取已展开 IA 数据的可实现方案、元数据逆映射、读口仲裁与覆盖时序，见 [IA_REUSE_DESIGN_REVIEW.md](IA_REUSE_DESIGN_REVIEW.md)。该文是只读设计评审，提出的 IA 读回功能尚未实现。

真实模型的几何分析即时读取仓库 TFLite，并编译真实 C tiling oracle，不启动 RTL：

```sh
python3 test/conv_reuse/analyze_ia_geometry.py
```

默认生成的模型清单和规划结果位于 `build/conv_models/`，几何分析位于
`build/conv_reuse/real_layer_ia_geometry.json`。需要模型解析依赖，见
`test/conv_models/README.md`。可用 `--models`、`--driver-tiling` 指定本次已生成
文件；可选的 `--stress-summary` / `--driver-auto-summary` 用于核对另一次显式
指定的 RTL 运行。正常分析不依赖历史实验目录，也不把几何条件解释为 RTL
命中率或已实现的 IA 读回功能。
