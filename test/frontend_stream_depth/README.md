# 流式请求字地址

连续读取的下一字地址采用固定步长加一。各五位分组独立形成进位条件，避免通用加法器的串行进位；字内地址保持为零。含未知位的输入采用分组进位的传播规则，输出周期保持不变。

`run.py` 从实际 `conv_im2col_stream.sv` 提取地址计算区域，与固定参考提交逐位比较。四组数据字宽度分别对应 4、8、16、32 字节；形式检查不限制地址取值，四态检查每组包含 16,644 个输入。

```sh
python test/frontend_stream_depth/run.py --out build/frontend_request_address --map
```

64 位读取配置的独立输入和输出寄存器包装测量结果：逻辑 LUT 从 11 增至 44，CARRY4 从 8 降至 0，完整组合级数从 7 降至 4，触发器均为 58。目标器件时序需结合布局布线结果。
