# AXI 双项缓冲存储验证

`soc_axi_pingpong_chan` 保留两个逻辑数据槽、独立的读写位置和非空、满状态。FPGA 编译条件下，位宽达到 24 位的通道使用普通 SystemVerilog 数组描述单写口、异步读口存储，由综合工具推断分布式存储。窄通道及通用、ASIC 编译条件使用两个数据寄存器。

每个逻辑槽保存一个写入标志。复位清除这两个标志，尚未写入的槽读取常零存储行；收到新数据后，读地址选择对应的数据行。运行中复位、无效周期的数据输出、连续接收、连续发送、满状态和同时接收发送均保持原有行为。该实现没有直接实例化 FPGA 逻辑或存储原语。

## 执行

```bash
python test/soc_pingpong_storage/run.py --out build/pingpong_storage
python test/soc_pingpong_storage/measure.py --out build/pingpong_storage_area
```

验证程序从 `--reference` 指定的 Git 提交读取参照模块，保存两份完整源码及 SHA256。验证位宽为 1、2、23、24、34、35、36、54、64、67、73 和 128 位，覆盖实现选择阈值的两侧。

形式检查比较全部公开输出、两个逻辑槽的可见值、读写位置以及占用状态。模型从一次有效复位开始，随后输入数据、复位和握手输入均自由变化；完成初始状态检查及状态归纳证明。通用与 FPGA 综合编译条件分别执行十二组检查，共二十四组全部通过。

四态仿真在通用、FPGA 和 FPGA 综合三种编译条件下分别运行 100,000 个周期。输入数据和全部控制信号均包含 `X`、`Z` 激励，共完成 7,200,036 次完整输出与状态比较。
