# 向量共享存储访问资格

地址相等判断按三个地址位并行计算，各组结果共同确定同地址冲突。读端口和写端口分别按照自身请求生成访问许可，范围检查与另一端口的冲突检查保持并行。

普通 `case` 在请求明确为零或一时选择相应的资格表达式。块首默认赋值保留完整表达式，未知请求继续使用相同的四态行为。配置、刷新、错误保持、返回有效信号以及全部数据和地址的采样边沿保持相同。

## 验证结果

- 12 组存储参数的完整模块等价证明通过，共检查 20,860 个状态及连接位；功能输入未施加限制。
- 12 组参数分别执行 4,096 个四态时钟周期，共完成 3,047,424 次输出比较。测试包含地址冲突、配置切换、刷新、复位和含未知值的控制输入。
- 生产共享存储向量回归通过 616 项任务和 170,743 个数值输出，同时检查权重预取、返回内容、写入阶段和错误处理。
