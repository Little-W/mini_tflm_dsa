# 向量写回源分组选择

`vector_banked_writeback` 接收连续排列的 32 位结果字。完整字输出依次选择各字节，INT8 输出选择每个结果字的低字节；不足一个分组的部分保持补零。每个固定分组先根据输出格式选择字节，再由当前源组号读取，存储体写入、请求接收和总线发送的周期保持原有安排。

格式控制为 X 或 Z 时，条件运算逐位合并两种格式的数据。组号包含 X 或 Z 时，数组索引保留未知结果。结果数据中的高阻态和所有补零分组均参与四态比较。

## 完整模块比较

```sh
python test/vector_source_selection/run.py \
  --repo /path/to/mini_tflm_dsa \
  --reference-rev 685a48415e1848e108552f1bea5072636fe0b9ad \
  --out /tmp/vector_source_selection
```

入口从 `--repo` 读取当前 RTL 与参考提交，在 `--out` 中保存源码摘要、完整模块证明、四态仿真和结果。`--reference-rev` 的默认值为上述提交；已有完整通过记录可加 `--reuse-passed`，入口会核对源码、证明脚本和仿真源码的一致性。

运行环境需要 Python 3、支持 `read_slang` 的 Pyosys，以及可通过 `PATH` 调用的 `iverilog` 和 `vvp`。

形式比较直接读取指定 Git 提交中的完整模块与当前模块，对全部公开输入保持自由，比较可匹配状态及全部公开输出。11 组参数覆盖 `TILE=1/2/3/16/64`、`BUS_WIDTH=32/64/128`、两种合并策略和额外的字节计数位宽。

测量时使用的 `190fbea0` 中该模块与 `685a4841` 中的文件逐字节相同。输出摘要记录实际读取的提交和完整文件 SHA256。

四态仿真使用两个完整模块实例。先通过同一组号遍历所有组号、格式控制的四态组合及 16 组数据图样，再恢复内部状态更新，为全部公开输入施加相同序列，每组参数运行 4,096 个时钟周期并逐半周期比较。供 Icarus 使用的源码将状态枚举表示为相同 2 位编码的逻辑类型和常量，全部控制表达式保持原样。

## 生产参数映射

`TILE=16`、`BUS_WIDTH=64`、`COUNT_WIDTH=7`、`p_coalesce_bytes_only=1` 使用相同的 Yosys `synth_xilinx -family xc7 -noiopad -noclkbuf -abc9 -flatten` 流程。

| 项目 | 参考模块 | 当前模块 |
|---|---:|---:|
| 逻辑 LUT | 1,097 | 1,061 |
| 寄存器 | 189 | 189 |
| 推断的 RAMB18 | 8 | 8 |
| 寄存器到寄存器最大组合级数 | 8 | 8 |
| 输入到寄存器最大组合级数 | 10 | 10 |
| 寄存器到输出最大组合级数 | 5 | 5 |
| 输入到输出最大组合级数 | 4 | 4 |

源选择涉及的路径在同一完整网表中测量，终点限定为实际存储体的数据输入端。

| 起点 | 参考模块组合级数 | 当前模块组合级数 |
|---|---:|---:|
| `result_words` | 6 | 5 |
| `request_byte_output` | 6 | 5 |
| `copy_source_q` | 6 | 6 |
| `copy_active` | 5 | 6 |
| `copy_offset_q` | 4 | 4 |

组合级数包含完整模块内实际连接的 LUT、进位单元、选择器和存储读出边界。该测量用于结构比较，工作频率由器件布局布线后的时序报告确定。
