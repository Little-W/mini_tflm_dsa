# 帧分块数量计算

`npu_frame_row_tiles` 计算帧行数加入分块余量后的分块数量，完整保留 32 位回绕及独立配置的移位量。对于尺寸与移位量一致的二的幂分块，高位数值通过 `conditional_increment` 加入低位余数产生的进位。其他参数组合沿用完整定宽算术表达式。

`conditional_increment` 以四位为一组计算进位传播条件。各组前缀条件独立归并，各结果位直接组合当前数值、组内条件及低位组条件。计算全部为组合逻辑，矩阵配置和 IA 加载器仍在原有时钟边沿接收数据。

## 验证

15 项任意输入形式检查覆盖 0 至 2³¹ 的分块尺寸、独立移位配置和 1 至 64 位的条件加一。753,664 次严格四态比较覆盖零、完整回绕、分块边界和 X/Z 输入。检查同时核对矩阵父模块的全部连接及其余功能代码。

```bash
python3 test/frame_row_tiles/run.py --out /tmp/frame_row_tiles
python3 test/frame_row_tiles/measure.py --out /tmp/frame_row_tiles_mapping
```

## 组合路径测量

测量包含帧行数寄存器、帧模式选择、IA 加载器尾组行数计算及结果寄存器。生产参数为 `SIZE=16`、`COUNT_WIDTH=29`。

| 项目 | 参考实现 | 当前实现 |
|---|---:|---:|
| 逻辑 LUT | 58 | 84 |
| 触发器 | 98 | 98 |
| 最长寄存器间组合路径 | 13 级 | 9 级 |

`measurement.json` 保存实际映射输入、资源统计、完整路径及映射功能检查结果；完整 SoC 使用相同 RTL 进行独立测量。
