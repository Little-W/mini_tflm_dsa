# 输出分组计数

输出分组计算将行分块数和复用次数分别限制为 `OA_FIFO_BANKS + 1`，然后求最小值。该上界完整保留可写入容量及超出容量的判断信息。行分块数的向上取整只使用容量计数所需的位宽。

运行全部输入的组合等价证明并生成测量电路：

```sh
python3 test/output_group_depth/run.py --out build/output_group_depth
```

测试直接提取实际顶层声明、组合赋值和配置阶段的寄存器输入。22 组参数覆盖 4、8、16、32、64 位配置字段，以及容量等于或超出字段表示范围的边界。配置和运行时序保持原有周期。

生产配置对应 32 位字段和 32 个输出银行。相同普通 RTL 映射设置下，该寄存器间电路使用 40 个逻辑 LUT、70 个触发器，最长路径为 8 个组合单元。完整 SoC 的结构限制和器件时序通过各自的综合报告检查。

`measurement.json` 保存提取源文件的摘要、证明结果和映射统计。
