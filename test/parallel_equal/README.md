# 完整坐标的分组相等判断

`parallel_equal` 将完整操作数按三位分组，各组同时比较，最后归并为一个相等结果。模块保留各组的组合边界，保持确定不相等位和未知位的完整四态传播。

矩阵权重预取使用该模块比较列坐标和归约坐标。任务、帧和预测有效条件在最后一级参与组合，全部寄存器更新周期及预取事件保持一致。

## 验证

- 9 组任意输入形式检查覆盖 1、2、3、4、16、31、32、64、128 位比较。
- 589,824 次严格四态比较同时核对相等结果与预测资格，覆盖相等、单个位不等、未知模式以及逐位 X/Z 输入。
- 自动核对矩阵模块的完整坐标连接、四个有效条件及其余功能代码。

```bash
python3 test/parallel_equal/run.py --out /tmp/parallel_equal
python3 test/parallel_equal/measure.py --out /tmp/parallel_equal_mapping
```

64 位坐标及四个有效条件的独立寄存模块使用 29 个逻辑 LUT，最长寄存器间组合路径为 5 级。源文件摘要、映射设置与路径保存在 `measurement.json`，功能检查结果保存在 `validation.json`。
