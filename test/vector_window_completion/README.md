# 向量窗口接收完成条件

窗口完成时检查已接收数量与当前响应数量之和是否等于有效通道数。计算采用 `add_equal` 的逐位进位一致性关系，直接生成比较结果。接收计数保持三十二位，当前响应数量保持三位，包含计数回绕时的完整行为。

错误响应、末次响应及公共错误优先级保持原有处理次序。数量寄存器仍在原时钟边沿更新，完成条件没有增加流水级。

## 验证

`run.py` 从实际 `vector_engine.sv` 提取实例连接，并使用实际 `add_equal.sv`。五组检查分别采用 1、2、5、6、7 位有效通道数量，全部计数值和响应数量均为自由输入。所有比较通过。

生产数量宽度的独立测量在输入与输出各增加一级测量寄存器，共使用 18 个逻辑 LUT 和 41 个寄存器。寄存器之间最长组合路径为 4 级。参考加法比较采用相同测量结构，使用 13 个逻辑 LUT、41 个寄存器和 12 级组合路径。
