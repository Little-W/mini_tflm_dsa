# 统一寄存 PE 验证

`vector_pe` 在 `i_en` 有效的时钟边沿同时保存操作码和操作数。乘加、求和、极值以及有符号和无符号乘法共享同一个模块；暂停期间保存的操作码和运算结果保持不变。

最大值与最小值比较先检查累加值高半字和输入符号扩展。高半字相等时比较低半字，其余情况由累加值符号确定次序。默认配置在纯乘法接收边沿保存零累加值；开启 `p_accumulator_preselected` 时，调用方提供已经准备好的累加输入。

## 验证范围

- 扩展乘法开关与累加预选开关的四种参数组合，比较完整 32 位结果。
- 两种扩展乘法配置下的累加预选等价性，同时检查命名参数和位置参数实例。
- 全部八种操作码、任意输入数值和使能暂停。
- 随机数据逐位注入 `X/Z`，覆盖操作码、两个乘数、累加值及未知使能。
- 寄存状态归纳证明比较完整原始输入保存后的选择结果；独立算术证明比较全部 32 位运算结果。
- 四态参考模型在使能边沿保存完整原始输入，再执行独立参考运算。

```bash
python3 test/vector_extremum/run.py --source-root . --out build/vector_extremum
```

输出目录包含源码 SHA256、参考版本、形式日志、四态检查数量和结果摘要。寄存状态与累加预选证明在第一个周期使能输入以建立有效的寄存内容，后续周期的使能和数据不加限制。
