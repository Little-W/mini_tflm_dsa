# 向量极值与乘加验证

`vector_pe` 使用十六位有符号乘法与三十二位累加值完成乘加和加法。最大值、最小值先比较累加值的高半字与输入的符号扩展；高半字相等时比较低半字，高半字不等时由累加值符号决定次序。

`registered_vector_pe` 在 `i_en` 有效的时钟边沿保存操作数。操作码由调用方保存，寄存操作数同时供乘加和极值选择使用。`p_accumulator_preselected` 指定调用方是否已在纯乘法周期提供零累加值。各模块使用相同的普通 RTL 算术表达式。

## 验证范围

- 两种累加值预选配置的完整寄存模块等价证明。
- 两种累加值预选配置的扩展有符号、无符号乘法等价证明。
- 所有操作码的随机值及逐位注入 `X/Z`，共 276,480 次四态比较。

形式证明不限制输入数值，寄存模块的使能可在任意周期变化。

```bash
python3 test/vector_extremum/run.py \
  --source-root . --reference ef0dc75342997721bdc4110b2841445df962018e \
  --out build/vector_extremum
```

输出目录保存各模块源码摘要、参考版本、形式日志和四态检查结果。
