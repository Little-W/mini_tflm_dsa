# ASIC 生产配置与报告脚本检查

执行 `python3 test/asic_profile/check.py`，检查 `npu_r16_150` 配置及不同端点报告逻辑。输出默认保存在 `build/asic_profile_test`。

检查使用真实的输入准备脚本和 Tcl 解释器。DC 集合命令由确定性的命令模型提供，测试包含重复端点、负保持裕量、面积超限和有条件的 SRAM 双时钟弧。结果的 `dc_executed` 始终为 `false`。

测试验证以下内容：

- 实际容量、十六路并行度、150 MHz、RAW 和部分和空间参数。
- 输入副本 SHA-256、原始约束内容和公共比较模块文件列表。
- `prepare-only` 状态、Tcl 字符串和生成的运行环境。
- 建立及保持报告各 5,000 个不同端点，裕量排序和逐引脚输出。
- `CLKA→CLKB` 与 `CLKB→CLKA` 的条件弧及同源时钟连接。
- 工具不支持独立库弧查询时的完整库报告输出。
- 面积、保持时间未达标及警告上下文的保留。
- 既有配置默认值和生产端点数量参数检查。

实际综合命令和报告说明见 [150 MHz 完整 NPU ASIC 综合配置](../../docs/asic_npu_r16_150.md)。
