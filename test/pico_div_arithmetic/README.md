# RV32M 除法算术验证

输入符号变换、余数递减和输出符号变换使用完整定宽算术表达式。商与余数先选择数值，再共用一次结果符号变换。扩展余数差的最高位表示借位，除数高位的非零判断与该借位并行完成。硬件资源由综合工具推断。

## 检查内容

- 两种形式验证配置比较完整除法模块的全部公开输出和共同状态。
- 四组 CPU 参数覆盖生产配置、压缩指令及中断、两周期运算和精简配置，共证明 11,038 个等价位。
- 20,000 个任意内部状态周期比较 15 个寄存器，共 300,000 次四态比较。
- 4,580 个数值案例覆盖 DIV、DIVU、REM 和 REMU，包含零除数、符号边界及随机操作数。数值由独立整数模型计算，逐周期比较参考实现的输出和握手。
