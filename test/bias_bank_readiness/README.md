# 偏置存储体读取资格

`bias_bank_readiness` 分别检查两个存储体的起始块、缓存块和当前块之间的模加关系。缓存有效、所属存储体、执行选择和驻留状态并行形成各存储体的读取资格；块号比较结果在最后一级与这些资格归并。向量缓存命中和偏置有效资格分别输出，加载、读取、缓存更新及计算启动的周期保持一致。

两个存储体的索引比较使用普通可综合 RTL。输入驻留模式直接使用对应存储体的驻留资格；权重驻留模式同时要求向量缓存有效、存储体一致和块号一致。未知存储体编号保留原有数组索引和算术比较的四态传播。

## 验证结果

- 1、2、3、5、8、17、32 位块索引分别在通用模式和 FPGA 模式下完成全部输入的组合等价证明，共 14 项。输入值没有附加限制。
- 两种编译模式合计执行 195,072 次四态比较，覆盖随机已知值、逐位 `X/Z`、未知存储体选择和未知有效标志。
- 完整 `bias_loader_buffer` 使用四组容量和接口参数，在两种编译模式下完成 8 项状态等价证明，共比较 82,622 个公开输出、状态及存储位。
- 两个存储体的容量、同步存储读写行为和缓存数据保持不变。

## 完整加载器测量

参照提交为 `ee8e2fc6`。参数为 `SIZE=16`、`DATA_WIDTH=32`、`BUS_WIDTH=64`、`REG_WIDTH=32`、`COUNT_WIDTH=29`、`GROUP_BLOCKS_MAX=32`。两份设计采用相同的 `physical-cost` 映射、6,667 ps 延迟目标及 300 ps 连线代价。

| 指标 | 参考实现 | 当前实现 |
|---|---:|---:|
| 名义 LUT 数量 | 1,226 | 1,229 |
| 完整模块最长寄存器间组合路径 | 10 | 10 |
| 执行存储体寄存器到后续寄存器的最长组合路径 | 6 | 6 |
| 当前块编号到 `bias_valid` | 5 | 3 |

完整 SoC 的资源和跨模块路径另由整机映射报告统计。上述级数来自连接图分析，目标器件的实际频率需要布局布线时序分析。

## 复现命令

```bash
python3 test/bias_bank_readiness/run.py --out build/bias_bank_readiness/verification
python3 test/bias_bank_readiness/measure.py --out build/bias_bank_readiness/measurement
```

`validation.json` 保存形式检查和四态测试结果，`measurement.json` 保存实际映射参数、资源、路径和源文件摘要。
