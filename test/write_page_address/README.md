# AXI 写入分页的地址计算

`axi_write_page_guard` 将页内字序号与剩余拍数相加，同时计算下一页的页号。
当前突发到达页末时，直接组合页号和页内地址；未到达页末时，采用页内求和结果。
分页长度、地址更新和状态转换仍在原有时钟边沿完成。

页余量保留非整字地址的低位信息。页内传输资格直接使用 `AWLEN` 表示的最后
一拍位置进行判断。宽总线参数继续使用原有 13 位表达式的截断语义。
地址运算保留模 `2**ADDR_W` 的回绕行为。

## 完整模块等价

`run_formal.py` 从提交 `2297cb12deac56b476f9a2a656da4038a9d8a75c`
读取比较源文件，对全部状态和公开输出执行 SAT 与时序归纳。23 组参数、
77,469 个状态及信号位全部通过。证明使用任意二态输入，包含无效周期输出、
非整字地址和全部握手组合，没有额外的地址范围或协议假设。

参数覆盖 12、16、32、40、64 位地址，8 至 32768 位的所有二次幂数据宽度，
以及 1、2、4、8 个在途写入事务。生产配置为 32 位地址、64 位数据和
4 个在途写入事务。

## 数值与协议验证

`run_protocol.py` 在 32/64 位总线和 1/4 个在途事务的四组配置下，分别测试
连续传输、随机反压、正常响应和错误响应，共执行 16 次独立模拟。
RTL 的握手稳定性、计数范围和物理分页断言同时启用。

测试覆盖 1 至 256 拍突发、恰好到达页末、跨页拆分、32 位地址回绕、
零字节写掩码、部分字节写掩码、满并发以及首个非零错误响应的保留。
独立字节存储模型逐次核对物理写入和原始逻辑命令的地址、数据及掩码。
共完成 4,096 个逻辑命令、5,968 个物理突发、128,480 拍数据，检查
584,208 个写入字节，并核对 168 次逻辑错误响应。

## 普通 RTL 综合

两份源文件使用相同的参数和综合选项，直接推断普通 RTL 算术。
完整寄存器数据和控制图的结果保存在 `measurement.json`。

| 数据宽度 | 比较版本逻辑 LUT | 当前逻辑 LUT | 比较版本最长级数 | 当前最长级数 |
|---|---:|---:|---:|---:|
| 32 位 | 185 | 178 | 17 | 7 |
| 64 位 | 183 | 178 | 17 | 7 |

两组均保留 61 个寄存器，DSP 和存储资源均为零。
局部组合级数用于检查本模块的结构；整机组合路径以及器件的频率和实际
LUT 使用量仍由整合后的综合与 Vivado 实现报告确认。

## 复现

在仓库根目录运行，环境中需要提供 Pyosys、Slang 和 Verilator：

```bash
python test/write_page_address/run_formal.py --out build/write_page_address/formal
python test/write_page_address/run_protocol.py --out build/write_page_address/protocol --verilator verilator-modern
python test/write_page_address/measure.py --out build/write_page_address/measurement
```

协议测试顺序编译四组配置，保留日志和可执行文件，并移除已完成的编译对象。
综合脚本在每组完成后压缩中间网表。
