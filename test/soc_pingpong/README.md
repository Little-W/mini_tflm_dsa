# AXI 两项缓冲的数据选择

`soc_axi_pingpong_chan` 的每两个相邻输出数据位共用一个 `LUT6_2`。两个数据位分别使用 `O5`、`O6`，共同使用读取位置选择信号。奇数位宽的最后一个数据位采用普通二选一逻辑。通用仿真与 ASIC 分支保留行为描述。

两个数据寄存器、读写位置、占用计数、同步复位和所有握手条件保持原有定义。无效输出周期仍返回所选数据寄存器的当前内容；复位后两个数据寄存器为零。AXI 和 AXI-Lite 封装的字段打包及实例连接保持一致。

## 功能检查

参考提交为 `2f06471c`。形式比较使用 Yosys 附带的官方 `LUT6_2` 功能模型，检查 1、2、34、35、36、54、64、67、73 位配置的全部公开输出和全部寄存状态。共 1,170 位比较通过，输入没有附加取值限制。

四态仿真同时运行上述九种配置，完成 100,000 个周期和 1,800,009 次完整比较，覆盖同步复位、连续填满、连续排空、同时接收和发送、随机暂停以及未知数据位。比较包含无效周期的数据输出。

## 独立综合

采用 Yosys 0.71、`synth_xilinx -family xc7`，开启 `SYNTHESIS=1`，不插入输入输出缓冲器和时钟缓冲器。所有配置的最长组合结构为 1 个单元，未使用 DSP 或块 RAM。

| 数据位宽 | 参考逻辑 LUT | 当前逻辑 LUT | 减少 | 触发器 |
| --- | ---: | ---: | ---: | ---: |
| 2 | 10 | 9 | 1 | 8 |
| 35 | 43 | 26 | 17 | 74 |
| 64 | 72 | 40 | 32 | 132 |
| 73 | 81 | 45 | 36 | 150 |

表中为独立模块的映射原语数量；完整 SoC 的物理位置数量由整机布局统计。所有运行结果、源码摘要和模型摘要保存在 [measurement.json](measurement.json)。

## 重复运行

在仓库根目录执行，确保 Python 可以导入 `pyosys`，并可运行 Icarus Verilog：

```bash
python3 test/soc_pingpong/verify.py --out build/soc_pingpong
python3 test/soc_pingpong/synthesis.py --out build/soc_pingpong_synthesis
```

`verify.py` 可通过 `--iverilog` 和 `--vvp` 指定仿真程序。两个脚本均接受 `--reference`，默认比较 `2f06471c`。
