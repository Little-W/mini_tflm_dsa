# 中止资格寄存

中止资格与任务中止状态在同一个时钟边沿更新。复位和完成事件接收时清除资格，检测到任务故障时置位，在排空、复位和等待完成接收期间保持。DMA 直接使用这一位寄存结果。

状态次序、错误码、配置捕获和公开握手周期保持一致。验证脚本从实际源代码提取完整状态过程，包含卷积配置和部分和配置的捕获逻辑。

## 验证

- 三组配置宽度的完整状态等价证明，共 671 个等价位。
- 50,000 个四态输入周期，在时钟边沿前后各比较一次全部输出，共 100,000 次 551 位比较。

```sh
python test/npu_abort_state/run.py --out /tmp/npu_abort_state
```
