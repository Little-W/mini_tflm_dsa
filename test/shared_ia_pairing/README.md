# IA 第二端口的存储选择

`ia_ps_channel_ram` 的 `p_paired_ia_ports` 参数用于两块 IA 存储的生产连接。有效的第二端口请求访问物理块 1；紧凑行和向量任务使用第一端口。物理块 0 的写数据直接来自第一端口，第二端口的有效返回数据直接来自物理块 1。默认参数保留通用端口映射。

各读写端口按三种地址排列并行比较行号，配置选择比较结果。这样保留原有容量、地址范围、并发访问、字节掩码、冲突检查和错误状态，同时减少宽数据选择逻辑。`NPU_SIM_ASSERT` 在实际生产连接检查第二端口的有效使能、两块 IA 配置和地址最低位。

## 独立映射

| 项目 | 参考设计 | 当前设计 |

使用七个 8 KiB 存储块、共享写数据阶段及非空写入资格，采用普通 RTL 推断和相同的映射选项。`measurement.json` 保存资源、参数及源码校验值。

## 验证范围

- 默认模式的 8 组参数完成所有物理存储命令、配置状态、返回选择状态和错误输出的时序归纳证明。首个采样周期复位，后续输入和复位自由。
- 默认模式的 4 组参数共完成 65,536 次四态比较，包含 X/Z 控制、地址和掩码。
- 实际 `ia_loader_cache_mgr` 在三种总线及紧凑格式参数下，证明第二端口有效请求的地址最低位恒为一；全部外部输入自由，一步归纳成功。
- 实际 `vector_shared_store` 证明向量任务不使用第二个 IA 端口。生产容量检查表达式证明有效宽格式配置至少分配两块 IA 存储。
- 专用模式的 4 组参数在有效第二端口请求使用两块 IA 配置且地址为奇数的条件下，完成全部存储命令、配置状态、错误输出和返回选择状态的等价证明。首次有效第二端口读取后，其返回选择恒为物理块 1。
- 实际 NPU 的 FPGA 配置完成 96 项数值任务，覆盖 WS/IS、s8/s16、分组地址、容量边界、非法配置、错误恢复和输出写回。紧凑模式完成 38 项功能任务及 12 项分组地址任务；所有实际第二端口断言通过。

存储形式模型比较每个有效物理命令的地址、数据和掩码，并比较同步返回选择。生产者端口性质、组合配置性质和专用模式的访问条件分别记录。实际存储返回数据由数值任务检查。

## 运行

```sh
python test/shared_ia_pairing/run_control.py --source-root . --out /tmp/shared_ia_control
python test/shared_ia_pairing/run_pairing.py --out /tmp/shared_ia_pairing
python test/fpga_integration/run.py --source-root . --out /tmp/shared_ia_fpga --verilator verilator --jobs 2
```

`validation.json` 记录检查参数、结果以及源码与日志校验值。
