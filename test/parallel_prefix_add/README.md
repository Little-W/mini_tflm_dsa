# 并行前缀加法

`parallel_prefix_add` 将操作数分成八位组，独立计算组内和及进位产生、传播条件。每个组边界并行归并低位条件，最后将输入进位送入各组。接口保留全部 `p_width` 个结果位和最高位进位，组合延迟为零个时钟周期。

```sh
python3 test/parallel_prefix_add/run.py --out build/parallel_prefix_add
```

全部输入的 SAT 证明覆盖 1、2、3、4、5、8、17、32、33、48、64 位参数，包含不足八位的最高组和任意输入进位。脚本同时生成输入、输出均带寄存器的参考与实现测量电路。

在相同普通 RTL 映射设置下，32 位实现使用 66 个逻辑 LUT，最长路径为 8 个组合单元；64 位实现使用 142 个逻辑 LUT，最长路径为 10 个组合单元。该结构用于需要缩短宽加法传播时间的路径，面积和结构深度随位宽及其周围逻辑变化。完整路径仍需在集成网表中检查。

`measurement.json` 保存全部证明配置、源摘要、映射参数和资源统计。
