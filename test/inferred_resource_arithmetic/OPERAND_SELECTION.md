# 偏置加法的输入选择

`select_add` 在使用 DSP 的 17 至 48 位完整模加分支中，将关闭加法表示为右操作数取零。两个偏置来源和零值共用输入选择，结果通过一次完整加法产生。使能、数据位宽、符号解释和组合输出周期保持一致。四路 12 位模加和其他宽度的实现保持各自的参数分支。

四态仿真在加法关闭时保留输入中已知的比特，未知使能使用条件表达式合并结果。综合表达式的完整二态输入范围通过独立形式检查；两种表达式在所有二态输入上等价。

## 验证

- 1、8、12、16、17、24、32、48、64、128 位宽度，各覆盖 `p_use_dsp` 和 `p_split_12bit` 的两种取值，共 40 组完整输入证明通过。形式检查定义 `SYNTHESIS`，直接检查综合使用的表达式。
- 相同 40 组参数完成 1,080,320 次四态逐位比较，覆盖两个选择信号、三个数据输入以及单个数据位中的 X/Z。
- 32 位寄存测量模块的逻辑 LUT 从 64 减少到 32，触发器保持 130，DSP 保持 1。使用同一 `xc7` 综合设置，分析图完整。该数值描述独立模块，完整 SoC 另行测量。

数值与文件 SHA256 保存在 [select_add_validation.json](select_add_validation.json)。

```sh
python3 test/inferred_resource_arithmetic/run_select_add.py \
  --reference-ref 364e2ac7 --out /tmp/select_add_operand_check
```
