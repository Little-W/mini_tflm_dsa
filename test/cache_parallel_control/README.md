# 缓存状态归并与地址比较

配置空闲状态按六位形成并行零值判断，最终合并所有分组。需求地址、预取地址和已保存地址分别形成完整相等标志，选择阶段与快照保持共用这些结果。请求队列的标签命中检查采用相同的分组相等模块。

## 资源与路径

测量采用 16 通道、64 位总线、4 KiB 缓存、128 字节缓存行、两路组相联和两个在途响应的完整 `axi_dual_block_dma`。ABC9 映射目标周期为 6.667 ns，使用相同源文件与映射参数比较两个实现。

| 项目 | 参考实现 | 当前实现 |
|---|---:|---:|
| 逻辑 LUT | 14,446 | 14,449 |
| 分布式存储 LUT | 224 | 224 |
| 触发器 | 7,688 | 7,688 |
| DSP | 61 | 61 |
| 缓存内部最长组合路径 | 12 | 11 |
| 填充组号至选择有效状态 | 12 | 10 |
| 需求地址至选择有效状态 | 11 | 10 |
| 请求数量至缓存状态 | 12 | 9 |

完整 DMA 的最长路径为 13 级，位于图像前端。组合单元数来自映射后完整连接图；器件实际时钟频率需要布局布线时序分析。

## 验证

六组完整缓存状态和公开输出等价检查全部通过，覆盖通用实现与 FPGA 综合实现、单路与双路、32/64 位总线、16/128 字节缓存行以及实际生产参数，共检查 118,983 位状态和输出。三组四态测试直接提取实际 RTL 表达式，完成 649,585 次比较。

实际缓存协议测试使用 64 位数据总线、64 位读取宽度、128 字节缓存行和 4 KiB 容量，覆盖两组队列与相联配置，每组执行 12 类场景。配置切换、读写竞争、复位、旁路访问、几何提示和预取均通过；连续命中的请求接收与响应返回间隔均为一个周期。

```bash
python test/cache_parallel_control/run.py --out build/cache_parallel_control
python test/cache_pipeline/run.py --out build/cache_parallel_protocol --profiles 2:2 1:1 --fpga --bus-width 64 --read-width 64 --line-bytes 128 --cache-bytes 4096 --jobs 1
```
