# 量化激活比较的组合深度

`requant_activation_compare` 对完整 36 位有符号结果与两个 32 位有符号激活边界进行比较。低 32 位分成四个 8 位无符号组，最高 4 位采用有符号比较。每组的相等关系与大小关系独立计算，再按最高不相等组决定完整结果。两个边界共用输入值，INT8 和 INT16 裁剪共用比较结果。

分组结果使用 `keep` 属性保留组合边界。实现采用普通 SystemVerilog 比较与归约运算，未知输入按各组关系运算的四态语义传播。数据通路保持十二个使能边沿，所有接口、数据精度、通道数量和存储容量保持一致。

## 数值与控制验证

形式检查覆盖 36 位结果及两个 32 位边界，共 100 个不受约束的定义输入位。严格小于最小边界和严格大于最大边界两项关系均通过，包括完整有符号范围、边界相等和任意最小值／最大值次序。

完整 `requant_compute_lane` 分别使用通用乘法实现和官方 Xilinx DSP48E1 功能模型运行。每个实现均检查：

| 项目 | 数量 |
| --- | ---: |
| 周期 | 1,057,997 |
| 有效结果 | 838,131 |
| 定向输入 | 524,288 |
| 随机输入 | 524,288 |
| 暂停周期 | 73,578 |
| 清空 | 3,129 |
| 复位 | 468 |
| 无效列输入 | 42,431 |
| 暂停期间清空 | 787 |

数值检查包含 INT32 正负端点、全部 128 种移位编码、INT8 和 INT16 饱和端点、相反顺序的激活边界、使能暂停与流水清空。两个实现均通过 UBSan 检查。

测量从实际 RTL 提取比较模块以及 `requant_compute_lane` 的 INT8／INT16 输出选择。采用 Yosys、ABC9 和 Xilinx 7 系列结构，全部六种 LUT 输入宽度使用单位面积代价；关闭 DSP 推断与算术重映射。参考版本为 `9a6437f4`。

## 运行

Python 环境需要 `pyosys`，其 Yosys 构建需要支持 `read_slang` 和 ABC9。Verilator 与 C++ 编译器应位于 `PATH`。

```sh
python3 test/requant_activation_timing/run.py \
  --out build/requant_activation_timing \
  --verilator verilator-modern
```

脚本依次执行形式检查、两份局部映射和两种完整算术实现的数值测试。结果目录保留 JSON 汇总、SHA-256、路径、日志与可执行文件；大型网表压缩保存，可重建的编译目录在测试完成后移除。
