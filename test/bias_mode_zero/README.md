# 偏置地址零值检查

`npu_bias_address_zero` 同时检查权重驻留和输入驻留两种模式的偏置地址。两个通道条件分别计算，模式信号在最后一级选择完整结果。

对 3 至 32 位地址，地址低两位必须为零，其余位检查通道序号是否等于基址字序号的补码。计算保留定宽模加语义，包括地址回绕。1 至 2 位地址只检查基址，大于 32 位时使用完整定宽加法比较。四态输入使用逐位进位一致性检查，保持控制器的未知值传播。

通道比较每次检查相邻两位的进位关系，每六个比较结果独立归并。最终结果由少量分组结果产生，模式信号仅选择已经完成的通道检查。

矩阵模块直接连接两种模式的通道序号，配置、握手、状态和执行周期保持一致。

## 验证

- 9 组形式检查覆盖 1、2、3、7、16、31、32、33、64 位地址；外部输入没有附加限制，同时比较逐位进位结果和定宽算术结果。
- 294,912 次严格四态比较覆盖随机值、零地址、回绕、模式未知和逐位 X/Z 输入。
- 自动核对完整矩阵模块的其余功能代码及实例端口，组合检查以外的功能代码一致。

```bash
python3 test/bias_mode_zero/run.py --out /tmp/bias_mode_zero
python3 test/bias_mode_zero/measure.py --out /tmp/bias_mode_zero_mapping
```

## 映射结果

32 位寄存输入和输出的独立模块使用 39 个逻辑 LUT、94 个触发器。完整输入到输出的最长路径为 4 级；模式寄存器到结果寄存器为 1 级。映射使用普通 RTL 推断，ABC9 的映射功能检查通过。

`validation.json` 保存形式检查、四态比较与父模块检查结果；`measurement.json` 保存源文件摘要、映射设置、资源和路径统计。完整 SoC 的资源和时序另行测量。
