# 向量输入银行读取验证

生产配置使用 `TILE=16`、`PE_COUNT=8`、`DMA_SIZE=64`。输入存储的前 32 项保存 16 位数据，第 32–63 项由 `g_unused` 固定为零。每个计算银行因此读取四行现有存储。

`g_aligned_lanes` 使用行号低两位选择四行数据，在银行交换之后应用完整行号的有效条件。完整行号包含未知位时，`always_comb` 中的 `if` 保持 `read_valid=0`，读出结果为零。该条件保留了原逐行相等比较对越界地址及 X/Z 地址的处理方式。

修改范围只包含组合读取逻辑。存储声明、写入地址、写入数据、计算通道数量、状态机及更新边沿均保持原样。

## 等价与四态检查

`run.py` 从当前 `vector_engine.sv` 与指定提交直接提取读取区域，并检查该区域之外的 RTL 内容完全一致。测试比较每个通道的输入数据和屏蔽后的 PE 操作数。

| 参数 TILE / PE_COUNT / DMA_SIZE | 比较位数 | 检查方式 |
|---|---:|---|
| 16 / 8 / 64 | 256 | 全部已定义输入的 SAT 等价 |
| 16 / 8 / 32 | 256 | 全部已定义输入的 SAT 等价 |
| 8 / 4 / 32 | 128 | 全部已定义输入的 SAT 等价 |

三组形式检查共比较 640 位输出，存储内容、完整地址、`active`、`compute_index` 和模式控制均不添加输入约束。后两组参数使用通用银行读取分支。

Icarus Verilog 对生产配置七位地址的全部 `4^7=16,384` 种 0/1/X/Z 组合进行比较。16 组控制和数据模式包含半组选择、有效通道边界、未知控制位及含 X/Z 的存储数据，总计通过 **262,144 次四态检查**。

## 局部综合结果

采用 Yosys `synth_xilinx` 与 ABC9，时序目标为 6,667 ps。面积模型仅导出最终 PE 操作数，内部银行输出另外参与完整形式比较。下表中的 LUT 数是映射单元数量。

| 小 LUT 成本 | 参考版本 LUT | 当前 LUT | 减少 LUT | CARRY4 参考 / 当前 | 端口间组合级数参考 / 当前 |
|---|---:|---:|---:|---:|---:|
| 0.75 | 410 | 279 | 131 | 11 / 10 | 6 / 6 |
| 1.0 | 406 | 275 | 131 | 6 / 6 | 5 / 5 |

两个版本均为纯组合逻辑，局部综合没有产生 FF、DSP 或存储单元。组合级数使用项目的逐位依赖分析，在输入和输出处建立统计边界；整机资源与时序由完整 SoC 流程测量。

## 运行

使用安装了 `pyosys` 的 Python 环境，并确认 Yosys 包含 `read_slang` 与 Xilinx 单元库。将 Icarus Verilog 的 `iverilog` 和 `vvp` 加入 `PATH`，在仓库根目录执行：

```bash
python test/vector_input_read/run.py --out /tmp/vector_input_read
```

默认参考提交为 `1c3dae2642b89a3c5c4cd593bd087a330cd443e5`。输出目录保存直接提取的 RTL、形式证明脚本、四态仿真程序、综合网表及日志。`summary.json` 记录源码 SHA256、检查数量、资源与内存峰值；本目录的 `measurement.json` 保存本次测量结果。
