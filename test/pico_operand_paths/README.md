# CPU 组合路径验证

CPU 使用分组关系比较、分段跳转加法及分组进位条件计算顺序地址和除法结果。所有运算保持完整的 32 位模运算语义，寄存器更新条件和指令执行周期保持不变。

有符号与无符号比较共用按三位分组的关系结果；两个符号位不同的情况下，有符号次序由符号位决定。跳转地址的两个半字使用普通加法表达式，由综合工具推断并行算术资源，再按低半字进位形成完整结果。顺序地址增加二或四，使用四位分组的传播条件计算高位。除法结果的补码根据当前位与低位是否非零形成。各组合函数对含有 `X` 或 `Z` 的输入采用标准关系或算术表达式。

## 功能和周期验证

四组完整 CPU 时序等价检查覆盖生产参数、压缩指令与中断及 64 位计数器、两周期 ALU 与比较、16 个单端口寄存器及关闭乘除法。共证明 11,680 个对应位，输入不附加限制。

CPU 实际执行包含循环、条件分支、子程序调用和返回、地址回绕及读写数据的程序。普通 RTL 模式与 `SYNTHESIS=1` 模式分别使用两个复位地址 `0x00000000` 和 `0xfffff000`。四次执行均为 4,898 周期，每次完成 717 次取指、720 次内存事务和 3,258 次等待期间的数据稳定性检查；参考和当前实现逐周期一致。

四态检查直接提取当前源码中的三个组合模块，完成 131,200 次采样和 524,800 项输出比较。操作数、符号位及压缩指令控制包含 `0`、`1`、`X`、`Z`。完整算术表达式检查另完成 240,000 项比较。

## 复现

```sh
python3 test/pico_operand_paths/run.py --out build/pico_operand_paths
python3 test/pico_operand_paths/run_four_state.py --out build/pico_operand_paths_four_state
python3 test/pico_pc_arithmetic/run_four_state.py --out build/pico_arithmetic_four_state
```

输出目录保存输入副本、逐文件 SHA-256、四组形式检查、程序、仿真日志、综合命令和映射结果。`run.py` 的 `--stages` 参数可选择 `formal`、`execution`、`mapping`。量化结果与源文件哈希保存在 [validation.json](validation.json)。
