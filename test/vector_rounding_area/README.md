# 向量舍入的逐字节进位

`vector_round_shift` 保留完整 64 位有符号结果、向下取整结果以及零至六十三位的算术右移。输入寄存与中间寄存仍由 `REGISTER_INPUT`、`REGISTER_MIDDLE` 控制。

舍入阶段先形成每个字节的进位条件，再通过八位定宽加法计算该字节的结果。每组只处理自己的八位商值和一个输入进位，寄存器位置与输出周期保持相同。定宽加法同时保留未知数据、未知进位的四态传播。

## 验证

运行以下命令，其中参考目录应包含提交 `685a48415e1848e108552f1bea5072636fe0b9ad` 的 RTL。

```bash
python test/vector_rounding_area/run.py \
  --reference-source-root /path/to/reference \
  --out /path/to/measurement
```

脚本为两份源码分别建立完整模块，检查四种寄存参数组合的全部输出。形式等价检查不限制数据、移位量或输入序列；四态仿真向数值和移位量注入 X/Z，每种配置比较 8192 个样本，共 32768 次配置样本比较。Icarus 使用的源码副本将组合过程写为 `always @*`，寄存过程与表达式保持相同。

`measurement.json` 保存已经通过检查的源文件散列、形式检查结果、四态样本数和映射结果。最终 RTL 的 SHA256 为：

```text
9148e8a5c78726610f935553c52f438264b3bacdc6c1f2baf52f03a2adbb916f
```

逻辑 LUT 减少 55，约为该模块的 13.0%。组合级数统计覆盖 LUT、进位与选择资源，连接图完整。运行脚本记录的最大常驻内存为 175488 KiB。整合后的资源数量和 150 MHz 时序由完整 SoC 测量确认。
