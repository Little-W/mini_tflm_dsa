# 综合组合边界的保留范围

公共分组加法器允许最低组的传播条件随常量输入进位化简。AXI 写数据的两级移位保留高字节边界，最低字节采用直接置零选择。读响应的一拍判断和命令完成资格允许在其消费条件中共同化简。

返回数据保留跨字判断、列地址和有效长度高段零值检查的组合边界，各通道的范围比较使用这些完整结果。相关调整只涉及综合属性，全部功能语句保持一致；对应源码摘要和独立 DMA 映射见 `response_validation.json`。

这些调整仅改变综合属性及对应的信号别名。验证程序检查全部功能语句相同，并确认属性别名没有额外功能消费者。公共加法器的 68 项任意输入形式检查和 2,226,176 次四态比较通过。

```bash
python3 test/retained_logic/run.py --out /tmp/retained_logic
```

生产参数的完整 DMA 映射得到 14,634 个名义 LUT，包含分布式存储所需的 LUT。该独立模块的最长路径为 13 级，完整 SoC 的组合路径由整机报告统一统计。资源和验证数据见 `validation.json`。
