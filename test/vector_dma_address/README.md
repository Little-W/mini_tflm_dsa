# 向量 DMA 地址共享

读取地址先根据读取种类选择起点、偏移和通道号，再执行公共加法。权重、偏置、乘数、移位参数、线性向量、Softmax 表和池化数据保持各自的地址定义与传输控制。地址输出保留三十二位回绕。

四组 DMA 访问范围分别选择起点和字节数，每组使用一个加法器生成三十三位末地址。关闭的范围输出零值，输入长度的高位保留原有截断行为。

## 验证

```sh
python3 test/vector_dma_address/run_formal.py --out build/vector_dma_shared/formal
python3 scripts/fpga/open_fpga_synth.py --cases vector_engine --out build/vector_dma_shared/synthesis
```

组合证明覆盖 BUS32、BUS64、BUS128，以及 `TILE=3、16、32` 的五种配置，每组比较 235 个输出等价位。范围配置额外比较 555 个等价位。全部输入均不施加范围约束，状态与数据允许任意编码。独立提交中两个被证明片段以外的向量引擎源码保持一致；脚本在结果中记录这一比较。所有改变的信号均为组合信号。

## 独立完整向量综合

| 项目 | 附件版本 `2f06471c` | 共享地址 |
| --- | ---: | ---: |
| 逻辑 LUT | 11,743 | 11,648 |
| 分布式 RAM LUT | 248 | 248 |
| 触发器 | 5,976 | 5,976 |
| DSP48E1 | 16 | 16 |
| 最长寄存器间组合单元数 | 18 | 18 |

两次综合均使用 `TILE=16、PE_COUNT=8、BUS_WIDTH=64`。当前最长路径仍由坐标范围与量化输出偏移决定。独立读取译码片段使用 409 个逻辑 LUT，四组范围配置片段使用 301 个逻辑 LUT；完整模块资源由上表统一统计。

`measurement.json` 保存源码摘要、全部形式结果和原始连通路径。此处记录逻辑 LUT 与结构深度，物理 LUT 位置及 150 MHz 时钟由完整器件实现检查。

与 [向量控制与分段算术](../vector_control_bounds/README.md) 组合后，完整向量引擎使用 11,805 个逻辑 LUT，最长寄存器间组合路径为 15 个单元。组合版本的全部状态及公开输出等价结果保存在该目录的 `combined_measurement.json`。
