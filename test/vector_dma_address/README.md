# 向量 DMA 地址与参数准备

普通读取依据权重、偏置、乘数、移位参数及两个线性向量来源选择地址分量。Softmax 表读取和池化读取使用与状态同时保存的读取资格。所有读取共用完整三操作数地址加法，低 32 位用作 DMA 地址，两个高位保留溢出信息。

写回地址按照任务模式选择空间偏移或向量偏移，空间位置与通道号同时参与计算。参数行步长和连续行资格在 `CHECK` 状态保存，供后续 DMA 使用。Softmax 表查询索引在接收查询请求时保存，随后保持到对应读取完成。

四组访问范围保留原有起点与 33 位末地址。读取类型、请求时刻、传输尺寸和突发长度保持一致。完整地址运算及状态资格的实现与检查见 [向量读取资格与地址运算](../vector_read_address_phase/README.md)。

## 完整子模块时序等价

```sh
python test/vector_dma_address/run_formal.py \
  --out build/vector_dma_address/formal
```

脚本从指定 Git 提交独立读取完整参考模块及其依赖，以生产 RTL 比较全部公开输出和内部寄存行为。新增读取资格按照控制模块已证明的关系连接；其他输入保持任意取值。所有复位、保持和接收条件均参与时序证明。

| 配置 | 公开输出位数 |
| --- | ---: |
| 64 位总线、16 个通道、8 个窗口通道、共享存储 | 1,699 |
| 32 位总线、16 个通道 | 1,698 |
| 128 位总线、16 个通道 | 1,700 |
| 32 位总线、3 个通道 | 1,687 |
| 64 位总线、32 个通道 | 1,704 |

`summary.json` 保存源文件摘要、参数、公开输出位数、证明比较点数及脚本摘要。`--only-production` 单独检查生产配置，`--source-root` 可指定待比较源码。

## 四态选择与运算检查

```sh
python test/vector_dma_address/check_address_four_state.py \
  --out build/vector_dma_address/four_state
```

此入口检查全部四态状态及读取类型编码，共 262,144 组来源选择；另比较 200,000 组完整 34 位地址结果，并验证实际 DSP 映射的数学关系。源代码中的寄存器更新位置和已有字段也由脚本检查。

## 突发长度编码

每拍包含 `2^BUS_SHIFT` 个字节。低八位突发长度由字节数减一后的相应位生成，每位借位条件为全部更低位等于零。表达式保留零长度及 32 位回绕行为。

```sh
python test/vector_dma_address/run_burst_formal.py \
  --out build/vector_dma_address/burst
```

该脚本检查生产函数与数学参考关系，涵盖不同总线位移量、边界数值、随机输入及未知值。
