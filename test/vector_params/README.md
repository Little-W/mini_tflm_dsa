# 向量量化参数存储验证

`vector_quant_params` 将每个通道的 32 位乘数和 6 位右移量放在公共
`regfile` 中。分组数量等于 DMA 总线的数据字数量，每个分组每周期最多
写入一个 32 位数据字，独立写入掩码保留另一类参数。存储器没有复位和
资源类型属性，异步读取在 `vector_engine` 原有的量化输入边沿被接收。

`run.py` 从参照提交与当前 `vector_engine.sv` 提取参数写入及实际实例连接，
比较完整参数状态和读取结果。第一项 SAT 检查任意相同存储状态的读取结果；
第二项 SAT 检查任意输入下的一次时钟更新继续保持全部状态和输出一致。
状态、加载类型、有效通道数、字节地址、数据和复位输入均不加范围假设。
超过存储条目数的读取地址在测试包装模块中返回零。

仿真先通过实际写入接口建立初值，再逐次检查时钟更新前后的所有读取地址。
测试覆盖复位期间保持、重复地址、非对齐字节地址、部分有效通道、全部移位量
和 32/64/128 位总线；17 条目配置还覆盖未完整填满的最后一个存储分组。

```sh
python3 test/vector_params/run.py --out build/vector_params \
  --simulate --verilator verilator-modern
```

加上 `--synthesis` 可以测量 16 条目下两种实际总线配置的资源：

```sh
python3 test/vector_params/run.py --out build/vector_params \
  --simulate --synthesis --verilator verilator-modern \
  --synth-script scripts/fpga/open_fpga_synth.py
```

六个参数配置通过完整状态 SAT，共执行 1,792,448 次读取检查。
XC7 独立模块综合结果如下，分布式存储由工具自动选择。

| 总线宽度 | 实现 | 逻辑 LUT | 分布式存储 LUT 位置数 | 寄存器 | BRAM | DSP |
|---|---|---:|---:|---:|---:|---:|
| 32 | 逐通道寄存器数组 | 401 | 0 | 608 | 0 | 0 |
| 32 | regfile 分组 | 47 | 28 | 0 | 0 | 0 |
| 64 | 逐通道寄存器数组 | 974 | 0 | 608 | 0 | 0 |
| 64 | regfile 分组 | 125 | 56 | 0 | 0 | 0 |

32 位、64 位配置分别使用 7 个、14 个 `RAM32M`。计入这些存储位置后，
打包前的 LUT 位置估算分别为 75 和 181，较参照实现减少 326 和 793。
独立模块的最长组合单元数分别为 3 和 5；该统计包含输入写地址计算和异步
读取，不包含器件布线时延。单独检查读取地址到参数输出的连接路径，两个总线
配置均经过 2 个组合单元，参照实现分别经过 3 和 4 个单元。任务状态机、
量化流水级和每周期输入数量保持不变。
