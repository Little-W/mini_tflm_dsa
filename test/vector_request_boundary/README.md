# 向量请求与结果写入的寄存控制

## 结构

共享权重配置在输入槽位清空后的周期预留下一项窗口请求。已经接收的请求继续按标签返回，计算发射仍在原有边沿保存操作数并释放槽位。私有权重配置保留同周期释放与预留的行为。

`tap_last_modulo` 与 `tap`、`taps` 同步保存。配置载入、核位置归零和递增分别计算对应的下一项末项资格；全部七处相关更新都保存同一组数值关系。比较继续使用 `add_equal`，保留定宽回绕和四态进位一致性。扩展宽度的 `tap_last_wide` 比较维持原有用途。

`state_pool_store` 与完整状态字同时保存，供极值池化结果写入直接使用。全部 89 处状态更新共同维护该标志，保持计算与写回的周期顺序。

## 功能验证

| 配置或检查 | 结果 |
| --- | --- |
| 生产配置：16 通道、8 PE、64 位总线、8 路窗口、7 个共享 RAM 银行、独立量化 | 616 项任务，170,743 个数值输出通过 |
| 通用配置：16 通道、16 PE、32 位总线、4 路窗口、私有存储、共享量化 | 616 项任务，170,743 个数值输出通过 |
| 生产配置固定等待 | 40 项任务，103,743 个输出通过 |
| 完整源码末项状态证明 | 6 组参数均完成一步归纳证明 |
| 共享与私有窗口请求资格 | 2 组全部二值输入证明通过 |
| 末项更新四态比较 | 9 种位宽，216,009 次比较通过 |
| 保存的池化状态资格 | 89 处更新，4 项 SAT 检查及 4,096 个四态控制字通过 |
| 排空条件四态比较 | 131,072 次比较通过 |

末项状态证明保留实际源码中 `tap`、`taps` 和 `tap_last_modulo` 的完整时序逻辑，其余寄存器与存储输出作为自由输入。仅第一个采样周期施加复位，后续复位、运算模式和控制输入均保持自由。参数覆盖生产配置、通用配置，以及 `MAX_TAPS=1/7/49/255`、`POOL_MAX_TAPS=1/31/256/1024/65535`。

生产回归同时检查返回权重的地址和 128 位内容、保存的权重内容、输入暂停、无效坐标跳过、跨 tap 运行、任务切换、错误恢复、写入末拍以及写回负载稳定。结果中包含 282,743 个等待输入的周期、7,546 次无效 tap 跳过和 148 个错误处理周期。

固定等待测试逐项保持相同周期数、计算次数、读写字节、突发数量、窗口请求和完成数量，总计均为 1,071,159 周期。11 项任务的同周期窗口请求与响应次数变化，任务完成时间保持相同。随机等待测试的逐项周期总和由 3,422,533 增加到 3,423,269，增加 736 周期，即约 0.0215%。

权重返回有效信号 `i_weight_read_valid` 到 `win_req_valid` 的原有六级组合依赖已经消除。池化控制到累加数据的局部最长路径从十级降到八级。权重读取地址端口的总体最长路径为五级。`report_ports.py` 仅在分析数据中标记接口边界，用于统计这些实际连接；它不修改 RTL 或综合硬件。

这些结果描述独立 `vector_engine` 实例。整机路径检查继续使用包含所有外围连接的 SoC 网表；器件实现报告用于确认 150 MHz 时序。

## 复现

从仓库根目录运行源码证明与状态控制检查：

```sh
python test/vector_request_boundary/run_formal.py --out /tmp/vector_request_formal
python test/vector_control_flags/run.py --reference-revision 0c99ca796e8a8cdd99180bcc8f8e5085abf17bca --out /tmp/vector_request_control
```

生产数值回归使用以下参数，编译与运行期间保持源码不变：

```sh
python test/vector_engine/run.py --out /tmp/vector_request_production --pes 8 --tile 16 --jobs 1 --cache-sets 16 --cache-policy 3 --cache-line-bytes 128 --bus-width 64 --window-lanes 8 --shared-storage --shared-bank-bytes 8192 --shared-bank-count 7 --shared-ia-banks 2 --check-weight-write-stage --rtl-assertions --stable-stimulus --xilinx
```

同一命令附加 `--skip-build --perf` 运行固定等待测试。通用配置使用 `--pes 16 --cache-sets 4 --bus-width 32 --window-lanes 4 --shared-quant`，保留 `--rtl-assertions --stable-stimulus`，其余存储选择与 FPGA 选项采用默认值。

`compare_cycles.py` 按执行顺序比较两个 JSON 结果，保留名称重复的测试项。固定等待结果使用 `--fixed-wait`，要求每项的周期和所有非相位统计一致。详细参数、源码校验值、形式证明记录及逐项周期差值保存在 `validation.json`。
