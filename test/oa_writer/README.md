# 输出写回控制验证

`oa_writer` 利用空闲、请求和启动状态之间的已有周期，分别计算行列递增、范围判断和下一块控制。请求获得授权时保存下一组的有效行数与合并条件，启动 DMA 时保存下一块控制。DMA 完成时根据这些结果更新当前组。配置接收、DMA 启动、完成脉冲和输出数据握手保持原有周期。

```sh
python3 test/oa_writer/run_equivalence.py
python3 test/oa_writer/run_formal.py
```

逐周期测试同时实例化当前设计和指定 Git 版本，比较全部 21 个公开输出，包括无效周期的数据、暂停、配置重载和复位期间的输出。默认参数覆盖 4、8、16、32 通道，32/64 位总线，以及 8、16、28、32 位维度计数器。每组参数运行 512 个配置，输入覆盖尾块、零维度、有限位宽回绕、WS/IS、S8/S16、合并输出和随机等待。

形式验证比较公开输出及共同的状态和控制信号，并证明请求状态下递增结果有效、启动状态下范围判断有效、写入状态下下一块信息有效。递增寄存结果直接参与块完成时的索引选择。证明从复位状态开始，使用时序归纳，不对配置数值和外部握手施加范围限制。具体结构、参数与资源结果见 `test/oa_writer_pipeline/README.md`。

结果保存在指定输出目录，记录源码摘要、参考版本和各组参数。逐周期测试还保存可执行文件摘要及 DMA 命令、完成和配置中断次数。
