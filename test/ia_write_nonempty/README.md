# 共享存储有效写命令验证

`ia_ps_channel_ram.p_ia_nonempty_writes` 表示连接到 IA 写端口的生产模块保证每个有效命令至少写入一个字节。参数默认关闭，通用实例保留对写掩码的非空检查。生产 SoC 的两个来源分别为 `ia_loader_cache_mgr` 和 `vector_shared_store`，二者均已通过这一条件的形式证明，因此该实例启用此参数。

该设置允许碰撞检查直接使用写使能和地址比较结果。实际写掩码仍控制各字节的存储写入。`NPU_SIM_ASSERT` 启用时，同时检查每个有效写命令的掩码非空条件。

## 证明范围

| 对象 | 配置 | 检查内容 |
| --- | --- | --- |
| IA 写命令 | 输出寄存级开启/关闭，DMA 数据布局开启/关闭，共 4 组 | 两个写端口的有效命令均具有非空掩码 |
| 向量写命令 | 7 个 8192 字节存储银行 | 两个 IA 写端口的有效命令均具有非空掩码 |
| 共享存储 | 2048 字节银行的 6/8 银行配置、8192 字节银行的 7/9 银行配置 | 存储命令、地址、数据、掩码、配置、故障输出及返回选择状态一致 |

生产模块证明不限制业务输入。IA 顺序证明在第一个采样边沿施加复位，之后允许任意复位序列。存储模块证明使用已经证明的有效写条件，比较全部物理存储命令；存储内容不参与控制计算，因此该证明对任意存储内容成立。

共 9 组证明通过。`validation.json` 保存源码 SHA256 和每组结果。
