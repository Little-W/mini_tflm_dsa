# 向量算术与写回组合逻辑

向量结果偏移采用二位分段的产生、传播和求和表达式，三层并行前缀提供各段进位。高三十二位的零值、全一值和符号范围与低位有符号比较并行计算，完整保留六十四位回绕及激活限幅顺序。

最近偶数舍入保留保护位、舍弃位的非零状态以及可选中间寄存器。八个字节分别计算递增输入，移位值和移位量在同一边沿保存。写回数据按各级偏移位循环选择，地址、掩码、背压保持和响应处理继续使用现有接口。读取地址的三个分量采用逐位异或和多数值形成部分和，再执行完整宽度加法。

## 检查范围

`run_formal.py` 直接使用实际生产源码，与指定参考提交进行十组形式比较。外部输入不增加取值限制。

| 检查对象 | 配置与范围 |
| --- | --- |
| 结果偏移及限幅 | 160 位相关输入，34 位结果及范围输出 |
| 六十四位最近偶数舍入 | 有中间寄存器、无中间寄存器 |
| 写回完整状态及公开输出 | TILE/总线宽度为 8/32、16/32、16/64、16/128、32/64 |
| 读取地址 | 通用算术与 DSP 配置，完整 34 位结果 |

`run_writeback.py` 使用独立的逐字节参考，覆盖字节和数据字两种模式、全部总线内起始偏移、1 至 64 字节的请求长度、随机背压和错误响应。三种总线宽度共执行 3,584 个请求，检查 116,480 个数据字节、15,680 次传输和 5,401 个背压周期。全部数值检查与十组形式比较通过。

详细记录分别保存在 `formal.json` 和 `writeback.json`，包含实际源码摘要、模型摘要及各项结果。

## 运行

```sh
python3 test/vector_boolean_logic/run_formal.py \
  --reference 653477ed --out build/vector_boolean_formal
python3 test/vector_boolean_logic/run_writeback.py \
  --verilator verilator-modern --out build/vector_boolean_writeback
```
