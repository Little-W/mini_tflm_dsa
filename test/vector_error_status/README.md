# 向量任务错误状态

`vector_engine_control` 分别计算当前执行阶段的错误状态与高优先级错误条件，`vector_engine_error_select` 统一完成任务开始清零和错误优先级选择。错误编码在原有异步复位寄存器中保存，任务开始、完成响应及各执行阶段保持原有周期关系。

## 功能验证

运行方式：

```sh
python3 test/vector_error_status/run.py --out build/vector_error_status
```

验证内容包括：

- `p_tile` 为 8、16，分别启用或关闭共享存储与共享量化的四种完整控制器配置。对全部公开输出执行时序等价证明，输入不附加限制。
- 从提交 `59a1e9f3` 的完整状态更新过程提取错误赋值及其条件。对所有状态编码、读取类型、错误来源和已有错误编码执行组合等价证明。
- 普通编译与定义 `SYNTHESIS` 两种模式合计执行 300000 次比较，覆盖未知值、高阻态、非法状态编码及多个错误同时出现的情形。

## 综合测量

16 个向量通道、8 个计算单元、64 位总线、启用共享存储和共享量化时，使用完整控制器作为测量对象。Xilinx 7 系列映射采用 6667 ps 延迟目标、300 ps 连线代价和最多 8 输入逻辑分解，测得 1143 个逻辑 LUT、1788 个 FF，最长寄存器组合路径为 9 级。任务开始输入至错误寄存器的组合路径为 1 级。

结果摘要位于运行输出目录的 `summary.json`，其中保存检查配置、源码 SHA-256 与通过状态。
