# 两级量化移位验证

`requant_shift_pipeline` 对完整 64 位有符号乘积进行右移。第一阶段处理 32、16、8 位移位并保存 43 位中间结果、溢出状态、符号及剩余移位量；第二阶段处理 4、2、1 位移位，生成有符号 34 位商与最近偶数舍入增量。低位保留保护位和所有已舍弃位的或值。

商的范围为 `[-2^33, 2^33-1]`，超出范围时保存相应边界值。移位量为 64 至 127 时输出零。使能为低时，两级寄存器均保持。

```bash
python test/requant_pipeline/run_formal.py --out build/requant_pipeline
```

形式检查使用独立的完整宽度算术右移、余数掩码和半值比较。64 位乘积、七位移位量及每周期使能均不附加数值限制；归纳检查完整商与舍入增量，并检查任意暂停后的两级延迟。
