# 向量坐标区间比较

`vector_interval_bound` 检查十七位有符号坐标是否处于左闭右开的有效区间。坐标和两个端点先转换为保持有符号次序的无符号编码，两个比较器分别按三位分组并行计算，再按固定层次归并各组结果。模块保留独立映射边界。

## 功能检查

参考源码固定为远端提交 `9e3e5d6a6f47befe6c86aceacad7999923206458`。`run.py` 在通用、`SYNTHESIS`、`XILINX_FPGA` 及两种宏同时定义的四种配置下，完成无输入限制的形式等价检查。每种配置另执行 262,144 次四态比较，共 1,048,576 次，覆盖负坐标、相等端点、反向区间、符号边界及输入中的未知值。

```sh
python3 test/vector_interval_bound/run.py --out build/vector_interval_bound
```

## 完整引擎测量

16 通道、8 个 PE、64 位总线、共享存储及本地量化配置下，完整向量引擎使用 9,794 个逻辑 LUT、6,313 个触发器、42 个 DSP48E1 和 9 个 RAMB18E1。计入分布式存储后，布局前名义 LUT 数量为 9,970。所有资源均由 RTL 推断。

展开全部模块后的连接图完整且无组合环路，寄存器间最长组合路径为 10 级。坐标区间比较采用三层比较归并及一层范围组合。该统计包含跨模块路径；150 MHz 的建立和保持裕量由 Vivado 时序报告确定。
