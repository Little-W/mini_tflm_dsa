# DMA 寄存缓冲

读地址进入保护器之前保存完整地址、突发长度、传输大小和突发类型。写数据进入分页保护器之前保存数据、字节使能和末拍标志。两个通道分别使用两项队列，输出数据由首项寄存器直接提供，源端就绪由本地容量寄存器决定。

连续接收与发送时，每个周期传递一项。下游暂停时，第二项保存已经接受的下一项内容；恢复发送后保持原有顺序。已经接受的请求和数据按总线完成顺序排空，复位清除有效状态。保护器的空闲状态包含对应缓冲是否为空。

形式证明使用独立的双项环形队列作为参考，在 1、13、45、73、129 位配置下比较容量、有效状态、首项数据和第二项数据。所有配置均通过复位检查和无界归纳；有效、就绪及数据输入不增加限制。

同一固定源码通过完整生产 NPU 的 38 项任务和 11,118 个 INT32 参考检查。真实 CPU 固件的两种执行模式各比较 6,272 个输出，数值不一致和内存保护错误均为零。

