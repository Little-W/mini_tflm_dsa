# 向量坐标范围检查

`vector_engine` 使用 34 位有符号坐标和 16 位无符号图像尺寸。当前坐标的有效条件同时要求高 18 位为零，以及低 16 位严格小于对应尺寸。

`vector_coordinate_bound` 将低位大小关系分为三位一组的生成、传播条件，再用两级三组归并完成比较。高位零值检查与低位比较并行进行。该模块使用普通组合逻辑，直接实例化两次，分别检查行坐标和列坐标。

下一列和下一行的有效条件保留完整 34 位加法语义。低 16 位加法与原坐标高 18 位的零值、全一值条件并行计算，低位进位选择对应高位条件。

## 检查范围

`run_formal.py` 直接提取当前 RTL 与参考提交 `dde5e7c9` 的三项有效条件：当前坐标、下一列、下一行。形式证明覆盖全部坐标、膨胀系数和图像尺寸输入，包含负坐标、超出图像范围和 34 位回绕，不增加输入假设。

当前坐标比较片段的相同参数独立映射结果为 26 个逻辑 LUT、零个 CARRY4、最长 3 个组合单元。该数据描述单个比较片段；完整 SoC 的最长寄存器间路径单独统计。

```bash
python test/vector_coordinate_bounds/run_formal.py \
  --reference-rev dde5e7c9 --out build/vector_coordinate_bounds
```
