# PicoRV32 算术验证

项目 CPU 位于 `rtl/soc/picorv32_npu.v`。顺序取指、直接跳转和相对分支分别使用完整的 32 位行为级加法。取指地址的选择逻辑读取已有寄存状态，并保持原有控制优先级。操作数加法、扩展减法、有符号比较、返回地址和执行计数器使用普通定宽算术表达式，`use_dsp` 属性供 FPGA 综合工具选择运算资源。

无符号减法的低 32 位用于减法指令，扩展借位用于无符号小于比较。有符号比较先翻转两个操作数的符号位，再取扩展减法的借位。CPU 的接口、指令执行周期及寄存器更新条件保持一致。

参考源文件为 `picorv32/picorv32.v`，对应上游提交 `ef203c2b0a3fb793280f5114941416c425c5b461`。测试首先校验参考文件的 SHA256，再将参考实现和项目实现保存为独立输入副本。

## 运行方式

从仓库根目录执行：

```sh
python3 test/pico_pc_arithmetic/run.py \
  --reference-source picorv32/picorv32.v \
  --candidate-source rtl/soc/picorv32_npu.v \
  --out build/pico_pc_arithmetic
```

默认依次运行形式验证、实际指令执行和完整 CPU 综合。输出目录必须为新目录。可以使用 `--stages formal execution` 选择功能检查，或使用 `--stages measure` 单独测量资源与组合深度。

形式验证和综合使用仓库的 `scripts/fpga/open_fpga_synth.py`，依赖支持 Slang 的 Pyosys。执行仿真使用 Icarus Verilog。测试程序由脚本中的 RV32I 指令编码函数生成，不需要 RISC-V 交叉编译器。

## 完整状态等价检查

两份 CPU 独立展开各自的乘除法实现及寄存器存储结构，随后对输出和公共内部状态执行逐周期等价检查。流程包括组合证明和两周期归纳证明，输入不附加约束。

| 参数组合 | 已证明的等价位数 | 结果 |
| --- | ---: | --- |
| 生产配置，32 位计数器、双端口寄存器、乘除法 | 2,724 | 通过 |
| 压缩指令、中断及 64 位计数器 | 3,045 | 通过 |
| `TWO_CYCLE_ALU=1`、`TWO_CYCLE_COMPARE=1` | 2,727 | 通过 |
| 16 个单端口寄存器，关闭乘除法和计数器 | 1,388 | 通过 |

## 实际指令执行

两份 CPU 分别运行相同的程序，并逐周期比较内存请求、有效地址、写数据、字节掩码、预取输出和异常状态。参考 CPU 的全部子模块独立更名，两个实例各自使用本实现的乘除法模块。仿真保留四态语义，并以严格相等运算检查有效输出。

程序包含 100 次累加循环、有符号和无符号分支、`JAL` 子程序调用、`JALR` 返回、`AUIPC`、读写数据以及 `JALR` 目标地址最低位清零。两个复位地址分别为 `0x00000000` 和 `0xfffff000`，后者覆盖跳转时的 32 位地址回绕。独立内存模型加入 0 至 7 周期响应延迟，并检查等待期间的原生请求负载保持稳定。

| 复位地址 | 执行周期 | 取指次数 | 内存事务 | 等待负载检查 | 累加结果 | 完成标志 |
| --- | ---: | ---: | ---: | ---: | ---: | --- |
| `0x00000000` | 4,898 | 717 | 720 | 3,258 | 5,050 | `0x55` |
| `0xfffff000` | 4,898 | 717 | 720 | 3,258 | 5,050 | `0x55` |

## 算术四态检查

```sh
python3 test/pico_pc_arithmetic/run_four_state.py --out build/pico_arithmetic_four_state
```

脚本提取当前 CPU 源文件中的实际加减法表达式，以标准定宽算术和有符号比较为参考，检查操作数、比较结果、返回地址及 64 位计数器。20,000 组二值输入和 20,000 组四态输入完成 240,000 次严格比较，控制输入同时覆盖 `0`、`1`、`X`、`Z`。

## 生产配置综合

参考实现和项目实现使用相同生产参数、相同综合脚本和相同器件映射设置。算术映射只选择 RTL 中标记的运算，总 DSP 预算为 740，寄存器间组合单元上限为 10。脚本要求两份连接图完整，并要求项目 CPU 的最长路径满足上限。

| 指标 | 上游实现 | 项目实现 |
| --- | ---: | ---: |
| 逻辑 LUT | 1,536 | 1,405 |
| 分布式存储器 LUT | 48 | 48 |
| 合并计算的名义 LUT 数 | 1,584 | 1,453 |
| 触发器 | 1,002 | 1,002 |
| DSP | 0 | 9 |
| CARRY4 | 158 | 88 |
| 最长寄存器间组合路径 | 11 | 10 |
| 连接图完整性 | 完整 | 完整 |

以上为综合映射后的资源和结构性路径统计。150 MHz 的实际时序结果由布局布线后的时序报告给出。

`validation.json` 保存当前源码 SHA256、程序 SHA256、证明结果、执行结果与综合统计。每次运行的输出目录同时保存源码副本、执行命令、日志、仿真程序及完整测量结果。
