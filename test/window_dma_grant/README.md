# 窗口读取授予验证

`axi_block_dma_arbiter` 保存已经取得窗口队列使用权的请求方。队列存在未完成窗口且当前没有其他可服务请求时，描述符之间的短暂间隔保持窗口授予；后续窗口可以直接执行接收握手。
其他请求方出现时，已有优先级计算结果在下一边沿取得授予。配置更新、任务中止和队列排空均释放对应窗口授予。普通读取的描述符寄存、返回标签和计数更新保持原有行为。

## 状态转移证明

```sh
python test/window_dma_grant/check.py --out build/window_dma_grant/formal
```

检查程序从生产文件提取实际授予寄存器的更新块，计算任意输入下的下一状态，并同时证明八项性质：

1. 普通请求方和其他状态的更新与参考提交一致。
2. 在途窗口的请求间隔保持授予。
3. 队列排空且无后续请求时恢复空闲。
4. 其他可服务请求在间隔周期取得授予。
5. 窗口描述符接收后采用原优先级结果。
6. 接收背压期间保留当前授予。
7. 复位、普通命令开始、任务中止和重新配置释放对应授予。
8. 空闲状态保存后续请求方编号。

证明没有增加输入取值限制。`validation.json` 保存生产文件、检查程序、生成的证明模块和证明日志的 SHA-256。

## 端到端协议与数值验证

```sh
python test/window_dma/run.py --fpga --out build/window_dma_grant/protocol --jobs 1
python test/dma_abort/run_read_arbiter.py --out build/window_dma_grant/read32 --bus-width 32
python test/dma_abort/run_read_arbiter.py --out build/window_dma_grant/read64 --bus-width 64
```

窗口测试运行真实仲裁器、描述队列、卷积前端、缓存和 AXI 读取模块。已完成 20 个场景，接受 915 个描述符，完成 907 个，复位取消 8 个，核对 6,572 个有效输出元素。场景包括 23 个预期错误终止响应。

S8 单拍驻留窗口的 256 个描述符在 256 个周期内返回；S16 的 128 个描述符在 128 个周期内返回。四拍窗口的同一描述符内连续返回，描述符边界最大间隔为两个周期。

普通读取测试覆盖 32 位与 64 位总线，每种配置完成 21 个场景和 1,069 项检查，包括地址背压期间的全部有效载荷稳定性、15 次描述取消、5 次完成与取消同周期释放，以及 5 次授予撤销。普通命令最小接收间隔保持两个周期。

完整算子性能由 `test/uploaded_performance` 使用固定上传环境另行测量，数值结果与周期变化分别记录。
