# 复用数量的有效位宽

输入激活复用数量的幂次检查覆盖容量参数所需位数，同时保留输出合并所需的最低五位。容量判定检查复用数量的高位和存储上界，IS输出合并检查复用数量不超过16，WS输出合并检查列数及地址步长。三处实际使用条件共同确定需要参与检查的位宽。

测试直接提取 `npu_top.sv` 中的存储容量合法性条件和两种输出合并条件，覆盖16位及32位配置数据、8种复用位宽，并对全部输入组合证明输出相同。生产参数对应7位复用数量；三项条件合并后独立综合为114个逻辑LUT、最长7级组合逻辑。相同配置下，修改前为125个逻辑LUT和7级组合逻辑。

```sh
python test/reuse_shape_width/run.py --out build/reuse_shape_width --synthesis
```
