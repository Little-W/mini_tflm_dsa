# S16 输出列配置

`vec_s16_to_fifo` 在接收输出块列配置的边沿保存各列有效位及末拍索引。输出阶段根据当前拍下标选择有效位，并为每个 16 位元素生成两个字节使能。首拍等待期间继续接收列配置，首拍完成接收后保持当前输出块的配置。数据存储、读取使能、输出周期和背压处理保持原有结构。

有效位数组覆盖拍下标能够表示的所有列位置。列数量计算采用原有 `COUNT_WIDTH`，非二次幂参数及全部输入编码的截断行为均包含在比较中。复位后的配置对应一个有效列。

## 验证范围

参考提交为 `0097b66ed57e1b8ef00e402e89dc5b274f1626be`。检查使用实际模块源码和实际银行数量控制模块，比较全部公开输出、数据存储的完整读写端口、银行计数、控制状态、列有效位与末拍索引。存储读取数据作为两侧共享的任意输入，不限制其取值。

| `VLEN` | `BANKS` | `BUS_WIDTH` |
|---:|---:|---:|
| 2 | 1 | 16 |
| 3 | 2 | 32 |
| 4 | 3 | 64 |
| 5 | 3 | 32 |
| 8 | 4 | 32 |
| 16 | 4 | 64 |
| 16 | 3 | 32 |
| 16 | 4 | 128 |

八组参数均通过复位起始状态证明和无界归纳等价证明。`write_bank < BANKS`、`read_bank < BANKS` 作为内部状态性质同时证明，不对功能输入施加假设。

四态仿真在每组参数下执行 20,000 个周期，每个时钟边沿前后严格比较公开输出与存储端口，合计 320,008 次比较。测试包含 `0`、`1`、`X`、`Z`，以及复位、首拍等待、数据接收和输出背压。

## 独立综合

生产参数为 `VLEN=16`、`BANKS=4`、`BUS_WIDTH=64`，采用仓库统一的 XC7 映射流程。

| 项目 | 参考版本 | 当前结构 |
|---|---:|---:|
| 逻辑 LUT | 238 | 250 |
| 触发器 | 56 | 71 |
| RAMB36E1 | 4 | 4 |
| DSP48E1 | 0 | 0 |
| 最长寄存器间组合单元数 | 6 | 6 |

该修改针对整机中从 S16 列配置到写通道字节使能的跨模块路径，将列数量运算移到配置接收边沿。整机效果由完整 SoC 连接图和器件实现时序分别测量。具体源码摘要、形式验证结果、四态比较结果及独立综合结果保存在 `validation.json`。
