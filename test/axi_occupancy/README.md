# AXI 双项缓冲的占用状态

`soc_axi_pingpong_chan` 使用 `occupied_q` 和 `full_q` 保存非空与满状态。`m_valid` 直接读取 `occupied_q`，`s_ready` 为 `!full_q`。两个数据寄存器及读写位置分别按照实际接收、发送事件更新。同步复位、缓冲容量、吞吐量、背压和无效周期的数据输出保持一致。

| 实际事件 | 非空状态 | 满状态 |
| --- | --- | --- |
| 仅接收 | 1 | 接收前的非空状态 |
| 仅发送 | 发送前的满状态 | 0 |
| 同时接收与发送 | 保持 | 保持 |
| 两者均未发生 | 保持 | 保持 |

占用项数等于两个状态位的无符号和。复位后，满状态始终意味着非空状态。完整通道的归纳证明同时检查这两个性质、所有数据寄存器、读写位置和全部公开输出；功能输入不受取值限制。

## 已运行的检查

- 1、2、34、35、36、54、64、67、73 位共 9 种配置的初始复位与归纳证明通过，比较 1,152 位输出及存储状态。
- 100,000 个周期、9 种位宽共 1,800,009 次完整四态比较通过，包含填满、排空、同时收发、暂停、复位和 X/Z 控制与数据。
- AXI 和 AXI-Lite 的字段打包、接口和实例连接逐字一致。

## 重复运行

```bash
python3 test/axi_occupancy/run.py --out build/axi_occupancy --measure
```

`--source-root` 指定被测源码，`--tool-root` 指定测试工具所在仓库，`--reference` 指定参考提交，`--lock-file` 指定综合进程共用的锁文件。输出包含完整证明、四态日志和综合结果。当前验证数据保存在 `validation.json`。
