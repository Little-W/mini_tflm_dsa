# 共享存储器地址碰撞判断

`ia_ps_channel_ram` 对两组 IA 读地址和两组 IA 写地址分别比较，再使用端口请求的优先级选择匹配结果。端口零优先级、字节掩码、容量错误以及存储器读写周期保持一致。

## 形式化验证与综合

```sh
python3 test/shared_ram_collision/run.py \
  --out build/shared_ram_collision --synthesize
```

程序从实际参考源码和当前源码提取优先级、地址选择、掩码选择与碰撞判断区域，对七位、八位和九位行地址执行 SAT 等价证明。输入请求、行地址和字节掩码均未增加约束，覆盖两个端口同时请求时的选择行为。

`--synthesize` 对两个版本的完整 `ia_ps_channel_ram` 运行同一综合流程，使用七个 8192 字节存储块并启用共享写数据寄存级。输出保存源码 SHA-256、证明脚本、综合参数及测量结果。

## 存储器功能检查

```sh
python3 test/ps_channels/run_memory.py \
  --out build/shared_ram_collision/memory \
  --profiles 2048:6 4096:8 8192:7 8192:9
```

该测试覆盖存储容量、读写内容、字节掩码、配置切换、同地址访问和容量错误。四种配置分别覆盖不同的行地址宽度及 IA 可分配存储块数量。

## 测量结果

| 项目 | 参考实现 | 当前实现 |
| --- | ---: | ---: |
| 逻辑 LUT | 2,061 | 2,059 |
| 触发器 | 13 | 13 |
| RAMB36 | 26 | 26 |
| 包含模块输入的最长组合单元数 | 10 | 9 |

三项无约束组合证明均通过。四种存储配置共完成 109,748 个周期的功能检查，比较 3,748,992 个字节。完整结果见 [measurement.json](measurement.json)。完整 SoC 路径由整体网表分析记录。
