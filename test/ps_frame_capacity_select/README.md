# 各帧容量预计算与比较位宽

部分和帧存储在配置更新时计算并保存各帧可用行数，请求期间并行比较当前行数和预留行数，帧编号只选择一位资格结果。比较器采用存储池乘积的有效行宽，两项请求的超宽部分共同形成范围条件。地址计算、命令接收和读写周期保持原有行为。

## 容量范围

设 `B = BANK_ADDR_BITS`、`R = ROTATION_BITS`，配置字数乘积的完整位宽为 `B + R + 2`，除以每行四个存储字后需要 `W = B + R` 位。帧起始行按原有地址位宽计算，可用行数使用多一位的差值保留符号。当可用行数非负时，它不会超过配置存储池行数，因此比较器使用低 `W` 位即可。负容量仍由完整差值的符号位拒绝。

该范围覆盖配置端口截取后的所有数值，不依赖配置有效标志。输入包含未知状态时，表达式使用原有完整容量位宽进行比较。

## 完整验证

`run.py` 比较固定远端提交 `9e3e5d6a6f47befe6c86aceacad7999923206458` 与当前完整 `ps_frame_store`。容量关系和非负容量范围作为附加输出共同证明，输入与状态不增加数值假设。检查覆盖生产、紧凑、内部存储和轮转四种配置，以及通用 RTL 与 FPGA 条件编译两种模式。

四态仿真逐周期检查全部公开输出，每种配置和编译模式运行 8,192 个周期，共 65,536 个比较周期，覆盖配置、帧接收、写入、回放及控制信号的未知状态。

```bash
python test/ps_frame_capacity_select/run.py --out /tmp/ps_capacity_validation
python test/ps_frame_capacity_select/measure.py --out /tmp/ps_capacity_measure
```
