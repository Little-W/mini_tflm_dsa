# 共享 RAM 的最终访问使能

IA 请求先形成有效端口、地址范围和碰撞结果，PS 请求先完成帧范围与物理段选择。各物理 RAM 的读写候选在局部并行归并，`memory_access_enabled` 在最终端口使能处统一生效。

`keep` 属性保留端口选择的单比特结果。配置、故障处理、同步返回状态和全部物理地址、写入数据与字节掩码保持相同。PS 返回选择继续由包含访问条件的 `ps_read_select` 控制。

## 检查结果

- 8 组参数完成完整命令与状态的无界归纳证明。首个采样周期要求复位，后续功能输入和复位均自由。
- 4 组参数各执行 8,192 个四态周期，共 65,536 次完整控制比较，包含配置、故障、碰撞和 X/Z 输入。
- 7 组真实存储数值回归完成 54,004 个周期、133,379 次读取和 113,210 次写入，检查 2,134,064 字节。
- 数值回归覆盖 2 KiB、4 KiB、8 KiB 的银行尺寸，6 至 9 个银行，以及两种共享写入阶段。
