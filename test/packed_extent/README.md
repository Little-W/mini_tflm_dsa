# 矩阵分块维度取整

`npu_packed_extent` 在任务配置接收前计算右操作数的分块维度。二的幂次大小先并行得到完整块数和尾部非零标志，再按六位分组形成加一进位。其他大小通过六十四位模加与右移计算。输出保留三十二位，完整模加、移位和类型转换语义保持一致，包括维度回绕及超过六十四位的输入类型。

两个维度独立计算，结果仍在配置接收边沿保存。后续的部分乘积、范围检查、配置状态和任务接收周期保持一致。

## 验证

```bash
python3 test/packed_extent/run.py --out /tmp/packed_extent
python3 test/packed_extent/measure.py --out /tmp/packed_extent_mapping
```

形式检查覆盖 1、5、16、32、48、64、80 位维度和多种分块大小，包含维度位宽小于分块移位量以及 31 位移位，全部外部输入均不受约束。严格四态比较同时覆盖未知模式、逐位 X/Z、最大维度和回绕值。完整任务配置模块分别在通用和 FPGA 编译方式下比较全部共有状态及公开输出。

32 位维度、16 个元素一块的独立寄存模块使用 43 个逻辑 LUT，最长寄存器间组合路径为 9 级。完整任务配置模块使用 1,260 个逻辑 LUT，其他运算的组合路径由独立模块报告和完整 SoC 报告分别记录。

`validation.json` 保存形式检查与四态比较结果，`measurement.json` 保存源文件摘要、综合设置、资源和寄存器间路径。
