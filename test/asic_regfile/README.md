# ASIC 同步存储与量化参数配置

`regfile` 提供一个写入端口、参数化读取端口和独立写入掩码。同步读取具有一个时钟周期的延迟，未使能时保持输出。存储内容不复位；上层模块通过有效状态管理数据生命周期。

## 读取模式

`p_no_change_collision` 默认为 `0`。此时同周期同地址读写返回写入前的数据。在 ASIC 实现中，每个写入分段具有独立存储，已接收的写入在下一边沿提交到 SRAM。读取未提交的写入时，从写入缓冲转发该分段并关闭对应宏的读取。因此部分写入、同步读取和输出保持均保留行为数组的周期语义。

`p_no_change_collision=1` 时，只要任一分段发生同地址写入，该读取端口的整个输出保持；其他地址和其他读取端口正常工作。ASIC 实现将各分段展开为位写入掩码，整个数据字共用存储封装。零掩码不产生写入，也不阻止读取。该模式适合装载区域与有效读取区域独立的缓冲区。

两种模式均在物理宏上禁止同地址并发读写。未知写使能、地址或掩码沿用行为数组的 `if` 语义，明确有效的分段才发生写入。非法同步读取返回未知值；非法写入不修改逻辑数据。异步读取模式保持连续地址选择，不受 `p_no_change_collision` 控制。

## SRAM 选型

逻辑深度不超过 `384` 行时使用 `128×16` 宏组合，更大深度使用 `1024×16` 宏。选型同时计入位宽填充、深度填充和读取端口复制。128 行宏要求容量利用率至少 50%，1024 行宏要求至少 25%；未达到条件的数组使用行为级存储。默认读取模式按写入分段计算利用率，保持模式按完整数据字计算利用率。

该门限使用现有宏面积作为选型参考。寄存器、地址译码、读出选择和布线开销仍须由目标工艺综合评估。FPGA 继续由行为级 RTL 推断资源，通过 `p_ram_style` 指定存储类型建议。

## NPU 存储几何

下表使用 `SIZE=16`、64 位总线和七个 8 KiB 共享 bank。IA 紧凑存储开关决定编译时可支持的最大复用数量。

| 存储 | IA 紧凑存储关闭 | IA 紧凑存储开启 |
| --- | --- | --- |
| Kernel 矩阵 | 16 个 `48×16` 列数组，寄存器实现 | 相同 |
| Bias 有效数据 | `256×64`，共 2 KiB | `512×64`，共 4 KiB |
| Bias SRAM 实现 | 8 个 `RAMTP128X16`，物理容量 2 KiB | 4 个 `RAMTP1024X16`，物理容量 8 KiB |
| Bias 容量利用率 | 100% | 50% |
| 每组 IS 移位参数 | `128×7`，行为级存储 | `128×14`，1 个 `RAMTP128X16` |
| 移位参数存储组数 | 2 | 2 |

Bias 保留 64 位逻辑存储字和逐字节写入接口，使用整字共享的 SRAM 位写入掩码。读取和写入每周期各处理一个逻辑行。同地址写入时保持读取输出，控制器保证执行所消费的数据来自已完成装载的区域。512 行配置使用较大深度宏，以减少宏面积与深度选择逻辑；容量利用率和完整 ASIC 面积分别报告。

量化参数按 DMA 顺序装载。逻辑深度不超过 128 时直接保存七位移位量；更深的表将相邻两条组合为一个 14 位数据字。两种几何使用同一个参数化存储实例，浅表的综合结果不包含成对装载控制。成对装载时暂存偶数地址的值，收到下一条后写入完整数据字；组末不足两条时，未使用的高半字复制有效值。读取低地址位随同步存储采样，选择对应的七位量。原始参数观察输出与算术参数分别保存，观察接口不受打包影响。

Kernel 的三个物理分块包括两个预取槽位和一个活动发送槽位，完整矩阵数据为 1.5 KiB。存储器以槽位编号交换管理装载与发送，具体调度和 FPGA 资源比较见 `test/kernel_asic_storage/README.md`。

## 验证

`validation.json` 保存实际运行的源文件摘要和逐配置结果。验证包括 ASIC 功能模型与独立行为参考的四态比较、宏数量检查，以及任意访问序列的存储归纳证明。ASIC 功能模型保存全部位，并在物理宏同时读写相同地址时终止仿真。

形式检查选择任意固定合法地址，比较全部数据位、同步读取周期、输出保持和宏端口冲突条件；生产读写输入不附加约束。共同初值用于二态归纳，未初始化存储和未知输入通过四态检查。

```sh
python3 test/asic_regfile/run.py --out build/asic_regfile
python3 test/asic_regfile/run.py --rtl --simulation-only --out build/rtl_regfile
python3 test/asic_regfile/run_formal.py --out build/asic_regfile_formal
```

`run_formal.py --profiles` 接受 `width:depth:write_unit:read_ports[:no_change]`。偏置模块的有效数据比较和参数打包的完整量化比较分别位于 `test/bias_sram_storage`、`test/requant_parameter_packing`。
