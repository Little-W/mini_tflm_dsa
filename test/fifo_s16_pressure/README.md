# 十六位输出容量反馈检查

本目录验证 `vec_s16_to_fifo` 的容量状态保存和完整发送资格表达式。参考提交为 `4927debfa8eb4edf068a21fe41bfc1a32b473c1c`，被验证的 RTL 提交为 `92d1c609d57eea25b39b4831ab10d1bdbfd1ad26`。

## 实现关系

当前写入存储体、下一写入存储体的占用状态，以及当前存储体是否已有部分结果，都在原存储状态更新边沿保存。每个候选首先处理同拍输出释放，再处理当前写入完成；写入完成时选择后续两个候选状态。原有结果接收、数据 RAM 访问和输出有效周期保持一致。

`fifo_s16_issue_full` 并行准备完整计数比较、格式选择及当前分组的输出需求，在末级生成控制器使用的容量阻塞条件。公开关系为：

```systemverilog
o_issue_full =
    (i_full_select ? fifo_full_flag : i_other_full) && i_output_pending;
```

`fifo_full_flag` 的原公开含义保持一致。完整计数的模回绕和未知输入传播均纳入检查。八位专用构建使用输出流水线原有容量结果与 `i_output_pending` 组合，保持相同的选择关系。

## 功能验证

| 检查 | 覆盖内容 | 结果 |
|---|---|---:|
| 完整状态归纳 | 10 组向量宽度、存储体数量及总线宽度，分别启用两种容量阈值模式 | 20 项通过 |
| 四态时序比较 | 1,100 个真实输入位，每位包含 0、1、X、Z；20 种参数配置 | 13,616 个周期，15,794,560 次比较通过 |
| 32 位数据写回 | 真实数据 RAM、逐字节结果、有效掩码、行结束、反压和逐周期公开输出 | 81 组，12,392 字节通过 |
| 64 位数据写回 | 同上，十六位 FIFO 使用生产配置的 4 个存储体 | 81 组，12,392 字节通过 |
| 实际父模块连接 | 矩阵引擎及输出流水线新增端口、其余功能表达式和实际模块展开 | 普通 32 位、普通 64 位、八位专用 64 位均通过 |

归纳比较包含所有共同寄存状态、全部存储体行数、公开输出，以及数据 RAM 的读写使能、地址和写入数据。RAM 返回值是两份设计共同的任意输入，未施加数据限制；数据 RAM 实现保持一致，真实数据存储由数值测试覆盖。首次复位后全部功能输入均可任意变化。

新增保存状态与当前存储状态之间的关系、有效读写存储体编号均作为待证明输出参与归纳。四态检查还记录实际写入、输出释放、同拍写入完成与释放、存储体循环推进，以及占用状态下的输入周期。

`run_binding.py` 逐项检查实际 `npu_matrix_engine`、`npu_output_pipeline` 和十六位 FIFO 的新增连接，并将容量反馈表达式之外的功能记号与参考提交比较。该检查同时展开三种实际矩阵引擎配置。

## 连接后的组合路径

`connected_measure.sv` 连接真实十六位 FIFO、控制器、偏置发送资格、部分和读取选择，以及 7 个 8,192 字节物理分组的共享 RAM。所有外部功能输入和输出均有测量寄存边界。十六位 FIFO 参数为 `VLEN=16`、`BANKS=4`、`BUS_WIDTH=64`，启用预先计算的容量阈值。

| 完整连接范围 | 参考版本 | 当前版本 |
|---|---:|---:|
| 逻辑 LUT | 1,512 | 1,523 |
| 最长寄存器到寄存器组合路径 | 12 级 | 10 级 |
| 以十六位 FIFO 内部状态为起点 | 12 级 | 10 级 |
| 以输出格式为起点 | 11 级 | 10 级 |
| 以当前分组输出资格为起点 | 10 级 | 10 级 |
| 以八位 FIFO 容量输入为起点 | 9 级 | 10 级 |

两份技术映射均通过 ABC9 功能验证；完整连接图没有未分类单元或组合环。统计包含数据寄存器、时钟使能和实际 RAM 同步端口。

该连接测量把八位 FIFO 容量作为独立寄存输入，没有包含八位 FIFO 内部计算。最终整机报告需要继续检查该输入在实际父模块中的完整来源。此处记录结构级数，150 MHz 的器件及布线延迟由最终物理时序报告核对。

## 复现命令

在仓库根目录运行。Python 环境需要 `pyosys`、Slang 插件；四态检查使用 Icarus，数值检查和实际模块展开使用 Verilator。

```bash
python test/fifo_s16_pressure/run_formal.py --out /tmp/fifo_s16_formal
python test/fifo_s16_pressure/run_four_state.py --out /tmp/fifo_s16_four_state
python test/fifo_s16_pressure/run_numeric.py --bus-width 32 --out /tmp/fifo_s16_bus32
python test/fifo_s16_pressure/run_numeric.py --bus-width 64 --out /tmp/fifo_s16_bus64
python test/fifo_s16_pressure/run_binding.py --out /tmp/fifo_s16_binding
python test/fifo_s16_pressure/measure.py --out /tmp/fifo_s16_measure
```

数值及展开脚本支持 `--verilator` 指定可执行文件。各入口支持 `--source-root` 指定被检查仓库，`--reference` 指定参考提交。测量脚本使用 6,667 ps 映射目标、300 ps 连接延迟模型，以及最多 8 输入的 LUT 分解；完整资源统计按映射后的实际单元计算。

`validation.json` 保存检查统计、日志摘要、参考提交和参与检查的文件 SHA-256；`measurement.json` 保存资源、完整路径和各输入来源的最长路径。原始输出目录还保留完整日志、综合输入清单和可重新分析的网表。
